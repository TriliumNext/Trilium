Renamed: "Clone" is now "Copy" in the tree menu, with a tooltip explaining that it pastes as a clone ([#12230](https://github.com/TriliumNext/Trilium/pull/12230), by @adoriandoran); the "Boolean" promoted attribute type is now "Checkbox" ([#11738](https://github.com/TriliumNext/Trilium/issues/11738)); "Open note custom" is now "Open with", with a portal-based app picker on Linux, macOS support and a clearer notification when the note changed ([#7258](https://github.com/TriliumNext/Trilium/issues/7258), [#12418](https://github.com/TriliumNext/Trilium/issues/12418)).
