**The text editor became a block editor.** Notes inside notes: [editable transclusion](https://github.com/TriliumNext/Trilium/pull/11926) edits included text and code notes in place with the full editor, [live excerpts](https://github.com/TriliumNext/Trilium/pull/11925) quote blocks of another note and save edits back to their source, and [block references](https://github.com/TriliumNext/Trilium/pull/12069) link to a paragraph, heading, table or range of blocks and open scrolled to it. Layout and media: [multicolumn layouts](https://github.com/TriliumNext/Trilium/pull/11958), [drawing canvases](https://github.com/TriliumNext/Trilium/pull/11829) sketched in place, [files attached](https://github.com/TriliumNext/Trilium/pull/11795) in one step as inline embeds or links, YouTube and web audio or video embeds, one [link dialog](https://github.com/TriliumNext/Trilium/pull/12358) for web links, note links and anchors, and a block handle with slash commands.
