On new installations, following the link under the cursor moved from <kbd>Ctrl</kbd>+<kbd>Enter</kbd> to <kbd>Alt</kbd>+<kbd>Enter</kbd>, so <kbd>Ctrl</kbd>+<kbd>Enter</kbd> on a link in a to-do item no longer both opened the link and toggled the item. Existing installations keep their shortcut, which can be changed in Options → Keyboard shortcuts.
