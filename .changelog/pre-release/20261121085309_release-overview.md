Links can now point at a heading or an anchor instead of a whole note, in text and Markdown notes as well as in PDF, EPUB, Word and OpenDocument files. The Outline tab lists the headings of those files too, with a filter and a way to copy a reference to any of them. Text notes also gain collapsible headings, aside blocks and a scrollbar that marks search results and colored text.

Vim users can now bring their habits to text notes, with a Vim mode that understands paragraphs, lists, tables and embedded content. Trilium also starts noticeably faster, on desktop and on phones.

Android gets its first stable release, with its APK on the GitHub release. It syncs with a server of the same version and installs beside the nightly build, so moving from the nightly means syncing again or restoring a backup.
