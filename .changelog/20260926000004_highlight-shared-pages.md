title: Shared pages look like the app
closes: [11979, 11981, 12001]

A note shared to the web rendered in a theme of its own, and a shared collection appeared as a plain list of its children. Shared pages now use a [theme built from the app's own look](https://github.com/TriliumNext/Trilium/pull/11979), in light and dark, and a shared board, table, calendar or other collection renders with the same view it has inside Trilium.

Drawings appear as theme-aware SVG pictures instead of a download link, and every block of a shared note has a public link, copied from its block handle, that opens the page scrolled to that block.
