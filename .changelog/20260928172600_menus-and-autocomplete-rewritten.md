Context menus and note autocomplete were rewritten from scratch. Menus gain [keyboard navigation](https://github.com/TriliumNext/Trilium/issues/1166) and better accessibility, no longer [clip](https://github.com/TriliumNext/Trilium/issues/5294), and the note tree menu is more compact. [Autocomplete](https://github.com/TriliumNext/Trilium/issues/5134) has a modern design, the command palette, link and relation pickers, `@`-mentions in text and Markdown notes and attribute value suggestions.
