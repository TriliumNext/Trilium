**🛡️ Permissions for AI tool calls**  
Before the AI reads or changes your notes, the chat shows what it is about to do, and you can allow or deny it. If you trust a tool, you can allow it for the rest of the chat. The Tools menu also has three modes: always ask, ask only before changes, or never ask. This works with both API keys and subscription providers such as Claude Code, Codex, GitHub Copilot and Antigravity.
