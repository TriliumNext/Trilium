A Note map is a note type which displays a standalone version of the feature of the same name: Note Map (Link map, Tree map). Consult that page for more information on how the note map works and what it displays.

Once created, the note map will display the relations between notes. Only the notes that are part of the parent of the note map will be displayed (including their children).

Root note

The root note defines the starting point of the graph, from which the relations and the hierarchy are derived from.

There are three possible root notes:

  • The default root note is the parent note of the note map.
  • To use the currently hoisted note instead, set the mapRootNoteId label to hoisted.
  • To use a specific note instead, set mapRootNoteId to the Note ID of the desired note.
