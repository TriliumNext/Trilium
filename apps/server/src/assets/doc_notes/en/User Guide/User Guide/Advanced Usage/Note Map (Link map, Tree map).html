Note map is a visualization of connections between notes. This provides an insight into a structure ("web") of notes.

There are two types of note map:

  • Link Map, which shows relations between notes.
  • Note Map, which shows the hierarchical tree structure.

Accessing the note map

The note map comes into multiple flavors:

  • To access the note map for the current note:
    • On the New Layout, the note map is available in the Connections tab in the Right Sidebar.
    • On the old layout, the note map is a tab in the Ribbon.
  • To display a full-screen note map, there is a dedicated note type with the same name.
  • To view the global note map (of all the notes in the knowledge base), there is a dedicated Note map button in the Launch Bar.

Terminology and structure

  • Each note is represented as a node in the graph, with the title displayed underneath.
    • When the map is zoomed out, the title can still be viewed by hovering over the node.
    • The icon and color of the note are respected.
  • The root node is the reference point for which the relations and hierarchical structure are displayed.
    • When accessing the note map through the Ribbon or the Right Sidebar (new layout), the root node is the current note.
    • When using a dedicated Note Map note, the root note can be either the parent note, the currently hoisted note or a specific note. See the note type documentation for more information.

Interaction

  • Nodes can be dragged around, but they will return to their original position once released.
    • To have the notes remain in the same position as they were dragged, press the Fix nodes button. The position of the notes is not saved, so it will return to normal once you navigate to another note or restart the application.
  • When hovering over a node, the adjacent relations and nodes are highlighted.
  • On a link map, right-click a relation. Fold as loves(John, Mary) turns the two notes and the line into that one node. An edge that names several relations, such as loves, knows, or a relation running the other way between the same two notes, first asks which one, in a search. The choices read loves(John, Mary) and knows(Mary, John). The menu is then that relation's: Fold as loves(John, Mary). That statement becomes its own node, the other relation stays on the line, and only a relation of the folded statement is drawn from the new node. A relation attached to one of them folds as that statement, such as cause(knows(John, Mary), Event X). An edge drawn from another edge is named with that edge, such as Fold as leadsTo(likes(A, B), Chaos). The folded node shows relations of that fact, such as cause(loves(John, Mary), Event X), and not the other relations of John or Mary. The same menu lists every reification that already includes this relation, such as cause(loves(John, Mary), has(Mark, Jealousy)), and opens that note. The reification note is not drawn as its own circle on this map. While the facts are still edges, a relation between them is drawn between those edges, and the other fact's notes are shown with it. Open it, and the map is about that note: the relations of the fact are shown, including another reification one step away. Folding an edge that is drawn from another edge folds that edge first, and the one you asked for last, so it is the node that remains. Right-click the folded node. Expand opens that one edge into its two ends, which may themselves still be folded, and Remove reification removes the note for that relation. The relation stays. Click one of those notes to open it. Click the folded node to create the note, if it does not exist yet, and open it. A fold of another fold, such as leadsTo(likes(A, B), Chaos), opens the same way. Open … on its menu goes to that note when it already exists. On that note, or on any other reification drawn on the map, right-click it. Show the two notes opens that one level into its two ends, and the edge's menu has Show as one note to put that level back. A reification that appears among those ends can be opened the same way. Remove reification removes the note. Click either note to open it. The same menu also reaches the relation itself, as a concept rather than one statement: Go to loves opens that note when it exists, and Connect loves to a note points the name at a note you pick, or at one you create there, the same way @ does.
  • The distance between nodes can be adjusted via the slider in the bottom-left. Similarly, this value is not saved.
  • Archived Notes are generally ignored by the note map in order to reduce clutter. There is one exception: if the root note is also archived, then all archived notes are displayed too.

Link Map

The link map is a visualization of links and Relations incoming to and outgoing from a particular note.

The map indicates the following types of relations:

  • Internal (reference) links between notes.
  • Relations

The link map will also show unlinked notes that are part of the hierarchy as a cloud of unconnected dots. On the New Layout, the sidebar deliberately omits this in order to save some space, but they will be revealed once the map is maximized.
