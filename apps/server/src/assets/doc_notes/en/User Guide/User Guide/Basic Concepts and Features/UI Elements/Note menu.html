The note menu contains various actions and configurations for the current note. It can be found in the Note buttons area (to the right of the Title).

Every split has a note menu of its own, which acts on the note displayed in that split. Entries that don't apply to the current note are still listed but grayed out, while entries that only exist for some notes (described in Note-specific entries) appear only on those notes.

Navigating the note

  •  Search in note opens the Search in note bar, to find and replace text inside the current note. On the desktop application, the same bar opens with Ctrl+F.
    • It is available on Text, Code, Mind Map and Spreadsheets notes, Collections, PDF files, and any note displayed as Note source.
  •  Note attachments switches the note to the list of its Attachments, where they can be uploaded, opened, downloaded, renamed or deleted.
  •  Note map opens the Connections tab of the Right Sidebar, which shows the Note Map (Link map, Tree map) centered on the current note.

Note properties

The toggles in this section take effect immediately:

  •  Shared publishes the note via Sharing, by cloning it into the Shared Notes tree.
    • Turning it off removes the clone from that tree. If the note exists only as a shared note, Trilium asks for confirmation, since unsharing it deletes it.
    • The toggle is unavailable on the root note, on the Shared Notes note itself, and on system notes.
  •  Protect the note encrypts the note, turning it into one of the Protected Notes. If no protected session is active, Trilium asks for the password first. Only the current note is affected, not its children.
  •  Bookmark adds the note to the Bookmarks that are displayed in the Launch Bar, or removes it from them.
  •  Template marks the note as one of the Templates (by adding the #template label), which makes it available when creating a new note.
  •  Full width lets the note use the whole width of the window instead of the limit set in Content width by adding the #fullContentWidth label. It is not listed for note types that are always displayed at full width.

The two submenus in this section:

  •  Note type changes the type of the note to any of the Note Types; the current one is checked. If the note already has content, Trilium asks for confirmation first, since the content generally doesn't carry over. Converting between note types.
    • For a Code note, the language is chosen in the Status bar instead.
  •  Editable controls when the note opens as read-only (see Read-Only Notes):
    • Auto (the default): the note is editable, unless it is long enough to be opened as read-only automatically.
    • Read-only: the note always opens as read-only, but can still be edited after pressing Edit note.
    • Always Editable: the note is always editable, regardless of its length.

Importing, exporting and printing

  •  Import files opens the import dialog, which imports files as children of the current note. See Import & Export. It is unavailable on Saved Search notes.
  •  Export note opens the export dialog with Only this note selected; select This note & all descendants there to export the whole subtree.
  • Print note… prints the note. On the desktop application this entry reads Print/export to PDF… and can also save the note as a PDF file. See Printing & Exporting as PDF, including which note types and collections can be printed.

Some note types add their own export formats right below Export note:

  • Export as image, on Mermaid Diagrams and Mind Map notes, downloads the diagram as PNG (raster) or SVG (vector).
  • Export to Excel (.xlsx) and Export to CSV (.csv), on Spreadsheets, download the spreadsheet in those formats.

Revisions

These entries manage the Note Revisions of the note:

  • Note revisions… opens the revisions dialog, where previous versions can be previewed, compared with the current one, downloaded or restored.
  • Save revision saves a revision of the note right away, instead of waiting for the next automatic snapshot.
  • Save named revision… also saves a revision right away, but first asks for a short description of the changes, which is shown in the revisions dialog.

Note-specific entries

The following entries only appear on some notes:

  • Edit note appears at the top of the menu when the note is currently read-only. It enables editing until the note is closed.
  • Word wrap appears at the top of the menu on Code notes, and sets whether long lines wrap in this note:
    • Auto (the default) follows Options → Code Notes → Wrap lines in code notes.
    • On and Off override it for this note only, by setting the #wrapLines label.
  • Convert into attachment appears on an image note that has no children and a single parent. After a confirmation, it turns the image into an attachment of its parent note and opens it there. See Attachments.
  • Re-render note appears on a Render Note, and runs its script again to refresh the output.
  • Board properties appears on a Kanban Board, and configures its columns, card attributes and card templates.

Advanced

The Advanced submenu groups the actions that are needed less often:

  • Open note externally (desktop application only) saves the note to a temporary file and opens it in the application that the operating system associates with it. Trilium watches the file, and offers to upload the modified version back into the note. It is unavailable on Collections and Saved Search notes.
  • Open note custom (desktop application only, Windows and Linux) works like Open note externally, but lets you pick the application to open the file with.
  • Note source shows the Note source, the content of the note exactly as it is stored.
  • Convert to Markdown Note (on text notes) and Convert to Text Note (on Markdown notes) switch the note between rich text and Markdown. After a confirmation, Trilium saves a revision and converts the content; the revision allows going back if some formatting was lost. See Converting between note types.

  • Compress images opens a dialog that reduces the size of the images in the note. It lists the images found and how much space they take, and offers to:

    • Resize the images larger than a chosen size.
    • Keep, or compress, JPEG images.
    • Keep, optimize, or convert to JPEG the PNG images.
    • Process child notes as well, to include the images of the notes beneath this one.

    Compressing cannot be undone. Images can also be compressed automatically on upload, see Images.

  • View OCR text (on image and file notes) shows the text extracted from the note via Text Extraction (OCR). If the note has not been processed yet, the dialog offers to Process OCR.
  • Open note on server (desktop application only, listed when Synchronization is configured) opens the same note on the sync server, in the web browser.

Deleting the note

Delete note opens the deletion dialog for the current note and its subtree. The dialog lists the notes that will be deleted and the relations that will be broken, and offers to:

  • Also delete the other clones of the note, if it is cloned elsewhere. Otherwise, only the current placement is removed and the note stays in its other locations. See Cloning Notes.
  • Erase permanently instead of the usual soft deletion. This cannot be undone and reloads the application.

Notes deleted without erasing can be brought back, see Restoring Deleted Notes.

Limitations

  • The note menu is not available on launchers.
  • On the notes of Options and of the in-app help, most entries are grayed out, since these notes cannot be imported into, exported, deleted or have revisions.
  • The Note properties section is only listed when the note itself is displayed, not its Attachments or its Note source.
  • In Quick edit, Search in note, Note map, Full width and Convert into attachment are not listed.

Mobile support

On the Mobile Frontend, the note menu opens as a sheet from the bottom of the screen. Besides the entries above, it contains the items that the desktop layout places elsewhere:

  • Backlinks and Note paths, at the top, which open the Backlinks and the other locations of the note.
  • The custom buttons of the note type (such as Download on a File).
  • Insert child note, which creates a note under the current one.
  • Create new split and Close this pane, to manage the Split View.
  • Note attributes, which opens the attributes of the note.
  • On Text notes, the content language (see Content language & Right-to-left support); on Code notes, the language of the code.
  • Note info and Similar Notes.
  • Note map opens the map in a popup instead of the right sidebar.
