Введение

Node.js — это кроссплатформенная среда выполнения JavaScript с открытым исходным кодом. Она позволяет запускать JavaScript вне браузера, создавать инструменты командной строки и выполнять серверные сценарии, которые формируют содержимое динамических веб-страниц до отправки страниц в браузер пользователя.
