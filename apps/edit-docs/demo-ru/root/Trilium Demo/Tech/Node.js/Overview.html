Обзор

Node.js позволяет создавать веб-серверы и сетевые инструменты на JavaScript с помощью набора модулей, реализующих основные функции платформы. Модули обеспечивают работу с файловой системой и вводом-выводом, сетевыми протоколами (DNS, HTTP, TCP, TLS/SSL и UDP), двоичными данными (буферами), криптографией, потоками данных и другими базовыми возможностями.
