Выпуски

Новые основные выпуски Node.js формируются из ветки master на GitHub каждые шесть месяцев. Версии с чётными номерами выпускаются в апреле, а с нечётными — в октябре. После выхода новой нечётной версии предыдущая чётная переходит на этап долгосрочной поддержки (LTS) и получает 18 месяцев активной поддержки с даты присвоения ей статуса LTS.
