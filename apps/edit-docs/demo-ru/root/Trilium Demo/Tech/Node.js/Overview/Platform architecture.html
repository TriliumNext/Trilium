Архитектура платформы

Node.js переносит событийно-ориентированную модель программирования в веб-серверы и позволяет создавать быстрые серверные приложения на JavaScript. Разработчики могут создавать масштабируемые серверы без использования потоков, применяя упрощённую модель обработки событий, в которой функции обратного вызова сообщают о завершении задач. [31]
