История

История Linux началась в 1991 году как личный проект финского студента Линуса Торвальдса, задумавшего создать новое свободное ядро операционной системы. С тех пор ядро Linux непрерывно развивалось. После публикации исходного кода в 1991 году проект вырос от небольшого набора файлов на языке C, распространявшихся по лицензии, запрещавшей коммерческое распространение, до версии 4.2.3, выпущенной в 2015 году и содержащей более 18 миллионов строк кода под лицензией GNU General Public License версии 2.
