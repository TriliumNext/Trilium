Сочетания клавиш Unity

  • Удерживайте Super — откроется панель запуска со списком сочетаний клавиш
  • Удерживайте Super, затем нажмите 1, 2, 3 и так далее до 0, чтобы открыть приложение или переключиться на него. Цифра соответствует положению значка на панели запуска сверху вниз.
    • Если добавить Shift, откроется новый экземпляр приложения, даже если оно уже запущено.
    • Удерживание клавиши также удобно, когда нужно открыть панель запуска, но не вызывать Dash.
  • Super + T — открыть корзину.
  • Alt + F1 — переместить фокус клавиатуры на панель запуска. Используйте стрелки для навигации: Enter запускает приложение, а стрелка вправо открывает быстрые списки, если они предусмотрены.
  • Ctrl + Alt + T — открыть окно терминала.
