Режимы запуска Bash

Оболочка входа в систему

При запуске в режиме оболочки входа Bash читает и выполняет пользовательские файлы профиля: /etc/profile и один из файлов ~/.bash_profile, ~/.bash_login или ~/.profile (в указанном порядке — используется первый доступный для чтения файл).

При завершении оболочки входа Bash читает и выполняет команды из файла ~/.bash_logout, если он существует.

Зачем нужен отдельный режим оболочки входа? Некоторые действия и наборы переменных имеют смысл только при первоначальном входе пользователя в систему. Поэтому все оболочки UNIX® имеют (или должны иметь) режим входа.

Способы запустить Bash в режиме оболочки входа:

  • первый символ argv[0] — дефис (-): классические оболочки UNIX® запускаются из программы входа в систему
  • Bash запущен с параметром -l
  • Bash запущен с параметром --login

Способы проверить, запущена ли оболочка в режиме входа:

  • параметр оболочки login_shell установлен

Связанные параметры:

  • --noprofile отключает чтение всех файлов профиля

Интерактивная оболочка

При запуске Bash в интерактивном режиме, но не в режиме входа, он читает и выполняет команды из ~/.bashrc. Например, в этом файле удобно задавать псевдонимы команд: они должны быть определены в каждой оболочке, поскольку не наследуются от родительской оболочки.

Возможность использовать общесистемный файл /etc/bash.bashrc или аналогичный файл rc характерна для поставщиков и дистрибутивов, которые выпускают собственную модифицированную версию Bash. Классический способ использовать общесистемный файл rc — подключать /etc/bashrc из файла ~/.bashrc каждого пользователя.

Способы проверить, запущена ли оболочка в интерактивном режиме:

  • специальный параметр $- содержит букву i (строчную латинскую i)

Связанные параметры:

  • -i принудительно включает интерактивный режим
  • --norc отключает чтение файлов запуска (например, /etc/bash.bashrc, если он поддерживается, и ~/.bashrc)
  • --rcfile задаёт другой файл запуска вместо /etc/bash.bashrc и ~/.bashrc

Режим совместимости с sh

При запуске Bash в режиме совместимости с SH он старается как можно точнее воспроизводить поведение старых версий sh при запуске, одновременно соблюдая стандарт POSIX®. Если это оболочка входа, читаются файлы профиля /etc/profile и ~/.profile.

Если это не оболочка входа, используется переменная окружения ENV : её значение вычисляется, а полученное имя файла используется в качестве файла запуска.

После чтения файлов запуска Bash переходит в режим совместимости с POSIX® (для выполнения команд, а не для запуска).
