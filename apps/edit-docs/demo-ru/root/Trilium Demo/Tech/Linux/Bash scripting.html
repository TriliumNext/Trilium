Сценарии Bash

Bash — командная оболочка и язык команд Unix, созданные Брайаном Фоксом для проекта GNU в качестве свободной альтернативы оболочке Bourne. Впервые выпущенная в 1989 году, Bash широко распространилась и стала оболочкой входа в систему по умолчанию во многих дистрибутивах Linux и в macOS компании Apple (ранее OS X). Версия Bash доступна и для Windows 10.
