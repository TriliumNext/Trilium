Тадж-Махал, Индия

Знаменитый индийский Тадж-Махал (с персидского — «Корона дворцов») — великолепный мавзолей из белого мрамора на берегу реки Ямуны в городе Агра. Он также входит в список семи чудес света. Император Великих Моголов Шах-Джахан построил мавзолей в память о любимой жене Мумтаз-Махал, умершей при родах в 1631 году. Центральную мраморную гробницу окружает территория площадью около 17 гектаров с садами, мечетью, гостевым павильоном и бассейном.[1]
