3. Блоки кода с подсветкой синтаксиса

Примечание: Чтобы подсветка синтаксиса работала, необходимо указать язык программирования.

Пример без подсветки синтаксиса:

function greet(name) {

  return `Hello, ${name}!`;

}

console.log(greet("Trilium"));

JavaScript с подсветкой синтаксиса:

// JavaScript example

function greet(name) {

  return `Hello, ${name}!`;

}

console.log(greet("Trilium"));

Пример на Python:

def factorial(n):

    return 1 if n <= 1 else n * factorial(n - 1)



print(factorial(10))

Пример на SQL:

SELECT title, dateCreated

FROM notes

WHERE type = 'markdown'

ORDER BY dateCreated DESC;

9. Вложенная подсветка синтаксиса (код внутри блоков кода)

Панель исходного кода Trilium поддерживает вложенную подсветку синтаксиса. Например, можно подсвечивать HTML внутри блока кода Markdown:

<!DOCTYPE html>

<html lang="en">

<head>

  <meta charset="UTF-8">

  <title>Trilium</title>

</head>

<body>

  <h1>Hello from HTML inside Markdown!</h1>

</body>

</html>

  • Третий пункт

  2. Второй шаг
