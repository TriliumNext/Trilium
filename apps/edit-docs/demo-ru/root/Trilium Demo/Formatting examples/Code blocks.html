Блоки кода

Блоки кода позволяют вставлять небольшие фрагменты программного кода прямо в текстовые заметки. По желанию можно включить или отключить перенос строк в таких блоках.

Для блоков кода также предусмотрена подсветка синтаксиса. При создании блока приложение пытается автоматически определить язык программирования. Если это не удаётся, язык можно выбрать вручную. Цветовую схему подсветки можно настроить в параметрах. 

function helloWorld() {







	alert("Hello world");







}

Для больших фрагментов кода лучше использовать заметку типа «Код» со встроенным полноценным редактором CodeMirror. Пример такой заметки:  Пользовательский обработчик запросов.
