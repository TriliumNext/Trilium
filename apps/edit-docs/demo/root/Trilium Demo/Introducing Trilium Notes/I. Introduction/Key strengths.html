Key strengths

🔑 Key strengths

  • No vendor lock-in: notes are fully exportable to Markdown or HTML.
  • Self-host your own Trilium server on a VPS, Raspberry Pi, or NAS, or even run it on your laptop.
  • Or simply use the desktop application (Windows, Linux, macOS).
  • Fully hackable: create your own UI themes, add features to the editors, or write custom widgets.
