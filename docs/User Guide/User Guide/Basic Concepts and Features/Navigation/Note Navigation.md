# Note Navigation
One of the Trilium's goals is to provide fast and comfortable navigation between notes.

## Backwards and forward

To move back and forward in the history of viewed notes, press <kbd>Alt</kbd>+<kbd>←</kbd> and <kbd>Alt</kbd>+<kbd>→</kbd>, or use the <span class="tn-icon bx bx-left-arrow-alt"></span> and <span class="tn-icon bx bx-right-arrow-alt"></span> buttons to the left of the <a class="reference-link" href="../UI%20Elements/Tabs.md">Tabs</a>.

This works identically to browser backwards / forwards, it's actually using built-in browser support for this.

To go several notes back or forward at once, right-click one of the buttons or press and hold it. The back button lists the notes before the current one and the forward button the notes after it, the nearest first. Each entry shows the note's title, with the path of its parent notes at the end of the row. Selecting a note goes straight to it.

The _Go to Previous Note_ and _Go to Next Note_ launchers of the <a class="reference-link" href="../UI%20Elements/Launch%20Bar.md">Launch Bar</a> list the same notes, below the launch bar's own items.

## Jump to note

This is useful to quickly find and view arbitrary notes - click on `Jump to` button on the top or press <kbd>Ctrl</kbd> + <kbd>J</kbd> . Then type part of the note name and autocomplete will help you pick the desired note.

See <a class="reference-link" href="Jump%20to%20%26%20command%20palette.md">Jump to Note</a> for more information.
