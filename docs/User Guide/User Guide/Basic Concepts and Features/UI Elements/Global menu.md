# Global menu
The global menu configures the current window (zoom, keeping the window on top), switches the theme and offers access to some more advanced options.

![](Global%20menu_image.jpg)

## Accessing the global menu

See [Vertical and horizontal layout](Vertical%20and%20horizontal%20layout.md) since the position of the global menu is changed based on which layout has been selected.

## Switching the theme

The _Theme_ submenu changes the look of the application without opening the <a class="reference-link" href="Options.md">Options</a>. A check mark at the end of a row shows the active choice. The submenu is not shown on mobile; change the theme from <a class="reference-link" href="Options.md">Options</a> → _Appearance_ there.

*   Under _Color scheme_, choose _System_ to follow the light or dark mode of the operating system, or _Light_ or _Dark_ to use one regardless.
*   Under _Theme_, choose _Modern_ (the default theme) or one of the custom themes, each shown with the icon of its note. Switching to _Modern_ keeps the current color scheme.

A custom theme brings its own colors, so the color schemes are unavailable while one is active. The legacy theme is not listed; select it from <a class="reference-link" href="Options.md">Options</a> → _Appearance_ instead.

For more about the built-in and custom themes, see <a class="reference-link" href="../Themes.md">Themes</a>.
