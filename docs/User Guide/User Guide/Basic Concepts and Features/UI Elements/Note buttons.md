# Note buttons
The note buttons is an area at the top-right of a note with a few buttons:

*   <span class="tn-icon bx bx-dots-horizontal-rounded"></span> which offers commands for the note or its subtree, such as import, export, viewing the [Note source code](../../Advanced%20Usage/Note%20source.md) or [Attachments](../Notes/Attachments.md).
*   <a class="reference-link" href="Split%20View.md">Split View</a> controls
    *   <span class="tn-icon bx bx-dock-right"></span> to open a new split
    *   <span class="tn-icon bx bx-chevron-right"></span>/<span class="tn-icon bx bx-chevron-left"></span> to move the pane around
    *   <span class="tn-icon bx bx-x"></span> to close the pane.
*   On some note types such as <a class="reference-link" href="../../Note%20Types/File.md">File</a> and images, there are dedicated buttons (e.g. <span class="tn-icon bx bx-download"></span> to download the file locally).
