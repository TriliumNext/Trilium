# AI chat tab
Once the <a class="reference-link" href="../../../AI.md">AI</a> integration is activated, a _Chat_ entry will appear in the <a class="reference-link" href="../Right%20Sidebar.md">Right Sidebar</a>.

*   Unlike the dedicated note type, the side bar has optional access to the current note, making it easy to ask for information or modifications to a note without having to search for the note first.
    *   To toggle whether the current note is visible to the AI, simply click on the file icon at the bottom of the chat interface.
*   On the top-right of the sidebar there are three buttons:
    *   <span class="tn-icon bx bx-plus"></span> creates a new conversation.
    *   <span class="tn-icon bx bx-history"></span> goes to a previous conversation.
    *   <span class="tn-icon bx bx-dots-vertical-rounded"></span> opens a menu to rename or delete the current conversation, or to save it as a dedicated note in the <a class="reference-link" href="../../../Advanced%20Usage/Advanced%20Showcases/Day%20Notes.md">Day Notes</a>, which turns it into a dedicated chat note.

> [!NOTE]
> The sidebar chats are stored in the <a class="reference-link" href="../../../Advanced%20Usage/Hidden%20Notes.md">Hidden Notes</a> and can be seen in the _AI Chat History_ section.

## Mobile

On mobile, the chat is the _AI chat_ tab of the note panel (see <a class="reference-link" href="../Right%20Sidebar.md">Right Sidebar</a>). Its buttons are in the header of the sheet:

*   <span class="tn-icon bx bx-plus"></span> on the left creates a new conversation.
*   The title of the current conversation, in the middle, lists the previous conversations when tapped.
*   <span class="tn-icon bx bx-dots-vertical-rounded"></span>, next to the close button, opens the same menu as on desktop.
