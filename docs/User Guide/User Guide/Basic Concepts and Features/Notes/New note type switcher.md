# New note type switcher
When an empty <a class="reference-link" href="../../Note%20Types/Text.md">Text</a> note is created, a note type switcher will appear below the inline <a class="reference-link" href="Title.md">Title</a>. Apart from changing the note type, it's also possible to apply a [template](../../Advanced%20Usage/Templates.md):

*   <span class="tn-icon bx bxl-markdown"></span> _Markdown_ and <span class="tn-icon bx bx-pen"></span> _Canvas_ switch the note to that type in one click.
*   <span class="tn-icon bx bx-code"></span> _Code_ lists the scripting notes (_Custom CSS_, _Widget_ and _Backend script_), then the enabled code languages.
*   <span class="tn-icon bx bx-book"></span> _Collection_ and <span class="tn-icon bx bx-copy-alt"></span>_Template_ list the collections and the templates.
*   <span class="tn-icon bx bx-dots-vertical-rounded"></span> _All types_ displays the same menu as _Insert note after_ in the <a class="reference-link" href="../UI%20Elements/Note%20Tree/Note%20tree%20contextual%20menu.md">Note tree contextual menu</a>, with every note type and template.

Typing while the <span class="tn-icon bx bx-code"></span> _Code_, <span class="tn-icon bx bx-copy-alt"></span> _Template_ or <span class="tn-icon bx bx-dots-vertical-rounded"></span> _All types_ menu is open narrows it down to the matching entries.

The switcher will disappear as soon as a text is entered.
