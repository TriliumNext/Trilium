# Note badges
Note badges appear near the fixed note title and indicate important information about the note such as whether it is read-only. Some of the badges are also interactive.

<figure class="image"><img style="aspect-ratio:910/49;" src="Note badges_image.png" width="910" height="49"></figure>

The following badges are available:

*   <span class="tn-icon bx bx-lock-alt"></span> **Read-only badge**, which will be shown if the note is not editable due to either automatic read-only or manual read-only. Clicking on the badge will temporarily edit the note. On the pages of the built-in user guide, which cannot be edited, the badge does nothing when clicked.
*   <span class="tn-icon bx bx-share-alt"></span> **Share badge**, which will indicate that the current note is shared. The badge will also indicate if the share is on the local network (for the desktop application without <a class="reference-link" href="../../Installation%20%26%20Setup/Synchronization.md">Synchronization</a> set up) or publicly accessible (for the server).
*   <span class="tn-icon bx bx-globe"></span> **Web clip badge**, which will indicate if the note was clipped using the <a class="reference-link" href="../../Installation%20%26%20Setup/Web%20Clipper.md">Web Clipper</a>. The badge acts as a link, so it can be clicked on to navigate to the page or right clicked for more options. When the clipper also saved the page's description, its author, or the dates it was published and last updated, clicking the badge shows these details instead, with a link to the page at the top.
*   <span class="tn-icon bx bx-play"></span> **Execute badge**, for [scripts](../../Scripting.md) or [saved SQL queries](../../Advanced%20Usage/Database/Manually%20altering%20the%20database/SQL%20Console.md) which have an execute button or a description.
*   <span class="tn-icon bx bx-copy-alt"></span> **Template badge**, for <a class="reference-link" href="../../Advanced%20Usage/Templates.md">Templates</a> (including workspace templates, for which the badge reads _Workspace template_). Notes created from a template inherit its attributes, so the badge is a reminder that changing them affects every such note. Clicking the badge switches the template between being offered everywhere and only while hoisted into its workspace, the latter only for a template inside a workspace (see <a class="reference-link" href="../Navigation/Workspaces.md">Workspaces</a>). It also opens _Template properties..._, where the default title and location of new notes are set.
*   For <a class="reference-link" href="../Active%20content.md">Active content</a> (e.g. scripts, styles), a dedicated badge will be shown indicating the type of note and with an option to easily enable or disable it.
