# Aside blocks
An aside block sets content apart from the main text of a note, in a box that the main text can wrap around. It can hold any kind of content, such as formatted text, lists, tables or images, except another aside block.

## Inserting an aside block

*   In the <a class="reference-link" href="Formatting%20toolbar.md">Formatting toolbar</a>, go to _Insert_ → <span class="tn-icon cke cke-trilium-aside"></span> _Aside_.
*   Alternatively, type `/aside` and press <kbd>Enter</kbd>, as described in <a class="reference-link" href="Slash%20Commands.md">Slash Commands</a>.

Any content selected before inserting is moved out of the main text and into the new aside block.

## Positioning

By default, an aside block is aligned to the right, and the main text wraps around it. While the cursor is inside an aside block, a toolbar appears above it; its _Box position_ button changes where the block sits and whether the text wraps around it:

*   Under _Wrap text_, <span class="tn-icon cke cke-object-inline-left"></span> _Align left_ and <span class="tn-icon cke cke-object-inline-right"></span> _Align right_ place the block at that side of the note and let the text run beside it.
*   Under _Break text_, <span class="tn-icon cke cke-object-left"></span> _Align left_, <span class="tn-icon cke cke-object-center"></span> _Align center_ and <span class="tn-icon cke cke-object-right"></span> _Align right_ place the block on lines of its own, at that side of the note.

In the mobile layout, an aside block takes the full width of the note, so the text does not wrap around it and the block cannot be resized.

## Resizing

Only the width of an aside block can be changed; its height always fits its content. To resize the block, place the cursor inside it and drag the handle at its bottom corner.

## Removing an aside block

*   To remove the aside block but keep its content, click the <span class="tn-icon cke cke-remove"></span> _Remove aside_ button in its toolbar. The content returns to the main text, where the block was.
*   To delete the block together with its content, click the handle at its top-left corner to select it, then press <kbd>Delete</kbd>.
