# Руководство пользователя
Trilium — это решение с открытым исходным кодом для ведения заметок и организации личной базы знаний. Используйте его локально на компьютере или синхронизируйте с собственным сервером, чтобы иметь доступ к заметкам где угодно.

> [!TIP]
> Эту же документацию можно открыть локально в приложении Trilium Notes, нажав F1.
