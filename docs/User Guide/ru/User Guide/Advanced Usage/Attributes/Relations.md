# Отношения
Отношение похоже на [метку](Labels.md), но вместо текстового значения ссылается на другую заметку.

## Типичные сценарии использования

*   **Отношения метаданных для личного использования**: например, связь заметки-книги с заметкой-автором.
    Это можно сочетать с <a class="reference-link" href="Promoted%20Attributes.md">Продвигаемыми атрибутами</a>, чтобы сделать их отображение более удобным.
*   **Конфигурация**: для настройки некоторых заметок, таких как <a class="reference-link" href="../../Note%20Types/Render%20Note.md">Render Note</a>, или настройки <a class="reference-link" href="../Sharing.md">Публикации</a> или <a class="reference-link" href="../Templates.md">Шаблонов</a> (см. список ниже).
*   **Скриптинг**: привязка скриптов к событиям или условиям, относящимся к заметке.

## Создание отношения в визуальном редакторе

1.  Откройте <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Right%20Sidebar/Attributes%20tab.md">Вкладку атрибутов</a> в <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Right%20Sidebar.md">Правой боковой панели</a>.
2.  Нажмите кнопку <span class="tn-icon bx bx-plus"></span> (_Добавить новый атрибут_) справа от раздела _Собственные атрибуты_.
3.  Выберите _Добавить новое отношение_.

В визуальном редакторе задайте нужное имя и _Целевую заметку_ (заметку, на которую нужно указать). В отличие от меток, отношения не могут существовать без целевой заметки.

Дочерние заметки могут наследовать это отношение — нажмите на отношение и отметьте _Наследуемый_. Подробнее см. <a class="reference-link" href="Attribute%20Inheritance.md">Наследование атрибутов</a>.

> [!TIP]
> Альтернативно нажмите <kbd>Alt</kbd>+<kbd>L</kbd> — откроются детали атрибута (тот же вид, что и при нажатии на существующий атрибут) в <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Status%20bar.md">Строке состояния</a>.

## Создание отношения вручную

В <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Status%20bar.md">Строке состояния</a> нажмите кнопку <span class="tn-icon bx bx-list-check"></span>, чтобы показать список атрибутов.

*   Чтобы создать отношение с именем `myRelation`:
    1.  Нажмите на поле ввода, чтобы сфокусировать его.
    2.  Введите `~myRelation=@`.
    3.  После этого должен появиться список автодополнения.
    4.  Введите заголовок заметки, на которую нужно указать, и нажмите <kbd>Enter</kbd> для подтверждения (или щёлкните нужную заметку).
    5.  Альтернативно скопируйте заметку из <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20Tree.md">Дерева заметок</a> и вставьте её после знака `=` (в этом случае без `@`).
*   Чтобы создать наследуемое отношение, выполните те же шаги, но вместо `~myRelation` напишите `~myRelation(inheritable)`.

## Предопределённые отношения

Эти отношения поддерживаются и используются внутренне Trilium.

| Метка | Описание |
| --- | --- |
| `runOn*` | См. <a class="reference-link" href="../../Scripting/Backend%20scripts/Backend%20Events.md">Серверные события</a> |
| `template` | Атрибуты заметки будут наследоваться даже без родительско-дочерних отношений; содержимое заметки и её поддерево будут добавлены в экземпляры заметок, если они пусты. Подробности см. в документации. |
| `template:newNoteDefaultParent` | Задаётся на заметке-шаблоне и указывает заметку, под которой размещаются заметки, созданные из шаблона, когда не выбрано иное местоположение; при нескольких значениях заметка клонируется в каждую цель. См. <a class="reference-link" href="../Templates.md">Шаблоны</a>. |
| `inherit` | Атрибуты заметки будут наследоваться даже без родительско-дочерних отношений. См. <a class="reference-link" href="../Templates.md">Шаблоны</a> для схожей концепции. См. <a class="reference-link" href="Attribute%20Inheritance.md">Наследование атрибутов</a> в документации. |
| `renderNote` | Заметки типа <a class="reference-link" href="../../Note%20Types/Render%20Note.md">Render Note</a> будут отображаться с использованием кодовой заметки (HTML или скрипт), и с помощью этого отношения необходимо указать, какую заметку следует отображать |
| `widget` | Используется в контексте пользовательских <a class="reference-link" href="../../Scripting/Frontend%20Basics/Launch%20Bar%20Widgets.md">виджетов панели запуска</a> для ссылки на виджет, который будет отображён. |
| `shareCss` | CSS-заметка, которая будет внедрена в страницу публикации. CSS-заметка также должна находиться в опубликованном поддереве. Рассмотрите также `shareHiddenFromTree` и `shareOmitDefaultCss`. |
| `shareJs` | JavaScript-заметка, которая будет внедрена в страницу публикации. JS-заметка также должна находиться в опубликованном поддереве. Рассмотрите `shareHiddenFromTree`. |
| `shareHtml` | HTML-заметка, которая будет внедрена в страницу публикации в местах, заданных меткой `shareHtmlLocation`. HTML-заметка также должна находиться в опубликованном поддереве. Рассмотрите `shareHiddenFromTree`. |
| `shareTemplate` | Встраиваемая JavaScript-заметка, которая будет использоваться как шаблон отображения опубликованной заметки. При отсутствии используется шаблон по умолчанию. Рассмотрите `shareHiddenFromTree`. |
| `shareFavicon` | Заметка favicon, которая будет установлена на опубликованной странице. Обычно вы хотите задать её на корне публикации и сделать наследуемой. Заметка favicon также должна находиться в опубликованном поддереве. Рассмотрите `shareHiddenFromTree`. |
