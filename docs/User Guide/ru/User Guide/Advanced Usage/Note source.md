# Исходный код заметки
## Понимание исходного кода различных заметок

Внутренне структура содержимого каждой заметки различается в зависимости от <a class="reference-link" href="../Note%20Types.md">Типов заметок</a>.

Например:

*   Заметки <a class="reference-link" href="../Note%20Types/Text.md">Текст</a> внутренне представлены как HTML, используя представление <a class="reference-link" href="Technologies%20used/CKEditor.md">CKEditor</a>. Обратите внимание, что из-за пользовательских плагинов некоторые HTML-элементы специфичны только для Trilium, например замечания (admonitions).
*   Заметки <a class="reference-link" href="../Note%20Types/Code.md">Код</a> — это простой текст, внутренне представленный как есть.
*   Заметки <a class="reference-link" href="../Collections/Geo%20Map.md">Геокарта</a> содержат только минимальную информацию (видовой экран, масштаб) в виде JSON.
*   Заметки <a class="reference-link" href="../Note%20Types/Canvas.md">Холст</a> представлены как JSON, с собственной информацией Trilium вместе с внутренним JSON-представлением формата [Excalidraw](Technologies%20used.md).
*   Заметки <a class="reference-link" href="../Note%20Types/Mind%20Map.md">Mind Map</a> представлены как JSON во внутреннем формате [MindElixir](Technologies%20used.md).

Обратите внимание, что некоторая информация также хранится как <a class="reference-link" href="../Basic%20Concepts%20and%20Features/Notes/Attachments.md">Вложения</a>. Например, заметки <a class="reference-link" href="../Note%20Types/Canvas.md">Холст</a> используют возможность вложений для хранения пользовательских библиотек, а вместе с <a class="reference-link" href="../Note%20Types/Mind%20Map.md">Mind Map</a> и другими подобными типами заметок хранится SVG-представление содержимого для использования в других возможностях, таких как включение в другие заметки, публикация заметок и т.д.

Вот часть HTML-представления этой заметки, как оно хранится в базе данных (но отформатированное).

```
<h2>
	Understanding the source code of the different notes
</h2>
<p>
	Internally, the structure of the content of each note is different based on the&nbsp;
	<a class="reference-link" href="../Note%20Types.md">
		Note Types
	</a>
	.
</p>
```

## Просмотр исходного кода

Просмотреть исходный код заметки можно, открыв контекстное меню в <a class="reference-link" href="../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20menu.md">Меню заметки</a> и выбрав _Исходный код заметки_.

![](Note%20source_image.png)

Исходный код будет отображён в новой вкладке.

Для некоторых типов заметок, таких как текстовые заметки и JSON-заметки, исходный код также форматируется для более лёгкого чтения.

## Изменение исходного кода

Изменить исходный код заметки напрямую возможно, но не через функцию _Исходный код заметки_.

Для этого:

1.  Измените тип заметки с реального типа (например, Canvas, Geo Type) на Код (простой текст) или соответствующий формат, такой как JSON или HTML.
2.  Подтвердите предупреждение об изменении типа заметки.
3.  Появится исходный код, внесите нужные изменения.
4.  Измените тип заметки обратно на реальный тип.

> [!WARNING]
> В зависимости от внесённых изменений существует риск, что заметка не будет отображаться корректно. Лучше сохранить ревизию перед любыми большими изменениями.
>
> Если заметка отображается некорректно, измените исходный код снова или вернитесь к предыдущей ревизии. Поскольку обработка ошибок для неожиданных изменений может быть не всегда идеальной, может потребоваться обновить приложение.
