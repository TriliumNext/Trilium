# Безопасный режим
Безопасный режим включается установкой переменной окружения `TRILIUM_SAFE_MODE` в истинное значение, обычно `1`.

В каждом артефакте есть скрипт `trilium-safe-mode.sh` (или `.bat`) для его включения.

Что он делает:

*   Отключает типы элементов запуска `customWidget` в `app/widgets/containers/launcher.js`.
*   Отключает запуск скриптов `mobileStartup` и `frontendStartup`.
*   Показывает корневую заметку вместо ранее сохранённой сессии.
*   Не выполняет <a class="reference-link" href="../Note%20Types/Saved%20Search.md">Сохранённый поиск</a> при его открытии; нажмите _Искать сейчас_, чтобы выполнить его.
*   Отключает запуск скриптов `backendStartup`, `hourly`, `daily` и проверки скрытого поддерева.
