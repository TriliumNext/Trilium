# Заголовок заметки по умолчанию
При создании новой заметки её имя по умолчанию — «new note». В некоторых случаях может быть полезно иметь другой или даже динамический заголовок заметки по умолчанию.

Для этого случая Trilium (начиная с v0.52) поддерживает [метку](Attributes.md) `#titleTemplate`. Можно создать такую метку для заданной заметки, присвоить ей значение, и это значение будет использоваться как заголовок по умолчанию при создании дочерних заметок. Как и другие метки, её можно сделать наследуемой для рекурсивного применения, а можно даже поместить на корневую заметку, чтобы она применялась глобально повсюду.

Как пример использования, представьте, что вы собираете прочитанные за год книги так:

*   Книги 2022
    *   Neal Stephenson: Anathem, 2008
    *   Franz Kafka: Die Verwandlung, 1915

Тогда родительской заметке «Книги 2022» можно присвоить метку `#titleTemplate="[Имя автора]: [Название книги], [Год издания]"`.

И все дочерние заметки «Книги 2022» будут создаваться с исходным заголовком «\[Имя автора\]: \[Название книги\], \[Год издания\]». Здесь нет искусственного интеллекта — идея в том, чтобы просто подсказывать вам вручную заполнить части информации в заголовке заметки.

## Заголовки, задаваемые шаблоном

Шаблон может называть создаваемые из него заметки, где бы они ни создавались. Для этого добавьте заметке-шаблону метку `#template:titleTemplate`, например `#template:titleTemplate="Встреча ${now.format('YYYY-MM-DD')}"` на шаблоне _Встреча_.

*   Она применяется и когда шаблон выбран явно, и когда он приходит из `~child:template` родителя. См. <a class="reference-link" href="Templates.md">Шаблоны</a>.
*   Она имеет приоритет над `#titleTemplate` родителя. Заголовок, набранный пользователем, всегда побеждает.
*   Она может наследоваться от предков шаблона в дереве (например, от папки с несколькими шаблонами), при этом метка, принадлежащая самому шаблону, имеет приоритет. Заметка, созданная из шаблона и позже помеченная как шаблон, не сохраняет заголовок этого шаблона.
*   Её значение вычисляется так же, как `#titleTemplate`, с `parentNote` в качестве родителя новой заметки.

## Динамическое значение

Значение `#titleTemplate` вычисляется в момент создания заметки как JavaScript-строка, то есть его можно обогатить с помощью интерполяции строк JS динамическими данными.

Второй внедряемой переменной является `parentNote`, дающая доступ к родительской [`FNote`](../Scripting/Script%20API/Frontend%20API.md).

См. также <a class="reference-link" href="Templates.md">Шаблоны</a>, предоставляющие схожие возможности, включая содержимое заметки по умолчанию.

### Примеры

*   Представьте, что вы собираете инциденты простоя серверов и пишете заметки. Это выглядит так:
    *   Инциденты
        *   2022-05-09: Сбой системы
        *   2022-05-15: Задержка резервного копирования
    *   Можно автоматизировать присвоение даты, присвоив родительской заметке «Инциденты» метку `#titleTemplate="${now.format('YYYY-MM-DD')}: "`. При каждом создании новой дочерней заметки шаблон заголовка вычисляется с внедрённым объектом [now](https://day.js.org/docs/en/display/format).
*   Чтобы использовать атрибут родителя в заголовке новых заметок: `#titleTemplate="Собрание сочинений ${parentNote.getLabelValue('authorName')}"`
*   Чтобы отразить заголовок родительской заметки: `${parentNote.title}`
