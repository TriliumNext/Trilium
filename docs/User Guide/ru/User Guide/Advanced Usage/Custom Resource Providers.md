# Пользовательские поставщики ресурсов
Пользовательский поставщик ресурсов позволяет сделать любой файл, импортированный в Trilium (изображения, шрифты, таблицы стилей), публично доступным по URL.

Возможный сценарий использования — добавить пользовательский шрифт вместе с темой.

## Шаги создания пользовательского поставщика ресурсов

1.  Импортируйте файл, например изображение или шрифт, в Trilium перетаскиванием.
2.  Установите [метке](Attributes/Labels.md) `#customResourceProvider` значение `hello`.
3.  Чтобы проверить работу, откройте в браузере `<protocol>://<host>/custom/hello` (где `<protocol>` — `http` или `https` в зависимости от вашей настройки, а `<host>` — хост или IP вашего сервера Trilium). Если вы запускаете приложение TriliumNext без сервера, используйте `http://localhost:37840` как базовый URL.
4.  Если всё прошло хорошо, на предыдущем шаге браузер должен был скачать файл, загруженный на первом шаге.

Вместо `hello` именем может быть:

*   Путь, например `fonts/Roboto.ttf`, который будет доступен через `<host>/custom/fonts/Roboto.ttf`.
*   Как более продвинутый сценарий — регулярное выражение для сопоставления нескольких маршрутов, например `hello/.*`, которое будет доступно через `/custom/hello/1`, `/custom/hello/2`, `/custom/hello/world` и т.д.

## Использование в теме

Например, если у вас есть пользовательский шрифт, который должна импортировать тема, сначала загрузите файл шрифта в Trilium и присвойте ему атрибут `#customResourceProvider=fonts/myfont.ttf`.

Затем измените CSS темы, указав:

```css
@font-face {
	font-family: customFont;
	src: url("/custom/fonts/myfont.ttf");
}

div {
	font-family: customFont;
}
```
