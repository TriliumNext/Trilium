# Карта заметок (Link map, Tree map)
Карта заметок — это визуализация связей между заметками. Она даёт представление о структуре («паутине») заметок.

Есть два типа карт заметок:

*   Link Map — показывает отношения между заметками.
*   Карта дерева (Tree Map) — показывает иерархическую структуру дерева.

## Доступ к карте заметок

Карта заметок существует в нескольких вариантах:

*   Карта заметок доступна на <a class="reference-link" href="../Basic%20Concepts%20and%20Features/UI%20Elements/Right%20Sidebar/Connections%20tab.md">Вкладке связей</a> в <a class="reference-link" href="../Basic%20Concepts%20and%20Features/UI%20Elements/Right%20Sidebar.md">Правой боковой панели</a>, в разделе _Карта заметок_.
    *   К ней также можно перейти через <a class="reference-link" href="../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20menu.md">Меню заметки</a> → _Карта заметок_, что сфокусирует боковую панель на нужном разделе.
*   Для показа полноэкранной карты заметок существует [специальный тип заметок](../Note%20Types/Note%20Map.md) с тем же именем.
*   Для просмотра глобальной карты заметок (всех заметок базы знаний) в <a class="reference-link" href="../Basic%20Concepts%20and%20Features/UI%20Elements/Launch%20Bar.md">Панели запуска</a> есть специальная кнопка _Карта заметок_.

## Терминология и структура

*   Каждая заметка представлена _узлом_ графа, с заголовком под ней.
    *   При отдалении карты заголовок всё равно можно увидеть, наведя курсор на узел.
    *   <a class="reference-link" href="../Basic%20Concepts%20and%20Features/Notes/Note%20Icons%20%26%20Colors.md">Значок и цвет</a> заметки учитываются.
*   Корневой узел — точка отсчёта, для которой отображаются отношения и иерархическая структура.
    *   При доступе к карте заметок через <a class="reference-link" href="../Basic%20Concepts%20and%20Features/UI%20Elements/Right%20Sidebar.md">Правую боковую панель</a> корневым узлом является текущая заметка.
    *   При использовании отдельной заметки <a class="reference-link" href="../Note%20Types/Note%20Map.md">Карта заметок</a> корневой заметкой может быть либо родительская заметка, либо текущая [поднятая](../Basic%20Concepts%20and%20Features/Navigation/Note%20Hoisting.md) заметка, либо конкретная заметка. Подробнее см. документацию типа заметок.

## Взаимодействие

*   Узлы можно перетаскивать, но после отпускания они вернутся в исходное положение.
    *   Чтобы заметки оставались в том положении, куда их перетащили, нажмите кнопку _Зафиксировать узлы_. Положение заметок не сохраняется, поэтому оно вернётся к обычному при переходе к другой заметке или перезапуске приложения.
*   При наведении курсора на узел подсвечиваются соседние отношения и узлы.
*   Расстояние между узлами можно регулировать ползунком в левом нижнем углу. Это значение также не сохраняется.
*   Для масштабирования используйте колёсико мыши, щипок на сенсорном экране или кнопки <span class="tn-icon bx bx-plus-circle"></span> и <span class="tn-icon bx bx-minus-circle"></span> в правом нижнем углу.
    *   Чтобы вернуть всю карту в видимую область, нажмите кнопку <span class="tn-icon bx bx-scan"></span> _Вписать в вид_ рядом с ними.
    *   Кнопки масштаба не показываются на мобильных устройствах, где вместо этого используется щипок. Кнопка _Вписать в вид_ показывается всегда.
*   <a class="reference-link" href="../Basic%20Concepts%20and%20Features/Notes/Archived%20Notes.md">Архивные заметки</a> обычно игнорируются картой заметок, чтобы уменьшить загромождение. Есть одно исключение: если корневая заметка также архивная, то отображаются и все архивные заметки.

## Link Map

<img src="Note Map (Link map, Tree map)_image.png" width="1425" height="1093">

Link Map — это визуализация ссылок и <a class="reference-link" href="Attributes/Relations.md">Отношений</a>, входящих в конкретную заметку и исходящих из неё.

Карта указывает следующие типы отношений:

*   <a class="reference-link" href="../Note%20Types/Text/Links/Internal%20(reference)%20links.md">Внутренние (ссылочные) ссылки</a> между заметками.
*   <a class="reference-link" href="Attributes/Relations.md">Отношения</a>

Link Map также покажет несвязанные заметки, входящие в иерархию, в виде облака несоединённых точек. На <a class="reference-link" href="../Basic%20Concepts%20and%20Features/UI%20Elements/Right%20Sidebar.md">Правой боковой панели</a> это намеренно опускается, чтобы сэкономить место, но они будут показаны при разворачивании карты на весь экран.

## См. также

*   Помимо возможности карты заметок, доступной из любой заметки, также можно создать специальную заметку, которая будет отображать отношения в полноэкранном режиме. Подробнее см. <a class="reference-link" href="../Note%20Types/Note%20Map.md">Карта заметок</a>.
*   <a class="reference-link" href="../Note%20Types/Relation%20Map.md">Карта отношений</a> — схожая концепция с некоторыми отличиями:
    *   карта заметок генерируется автоматически, а карта отношений должна создаваться вручную
    *   карта отношений — это тип заметки, а link map — просто виртуальная визуализация
