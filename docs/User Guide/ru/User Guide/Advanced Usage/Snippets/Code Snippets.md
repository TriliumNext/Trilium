# Кодовые фрагменты
Кодовые фрагменты тесно связаны с <a class="reference-link" href="../Templates.md">Шаблонами</a>, но вместо определения содержимого целой заметки фрагмент — это переиспользуемый кусок кода, который легко вставить в заметку <a class="reference-link" href="../../Note%20Types/Code.md">Код</a>.

## Создание кодового фрагмента

В <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20Tree.md">Дереве заметок</a>:

1.  Щёлкните правой кнопкой по заметке, куда вы хотите поместить фрагмент.
2.  Выберите _Вставить дочернюю заметку_.
3.  Выберите _Ещё_ → _Кодовый фрагмент_.

Затем просто введите нужный код в заметку и установите правильный языковой режим.

Заголовок заметки становится заголовком фрагмента. Опционально вы можете добавить описание в разделе <a class="reference-link" href="../Attributes/Promoted%20Attributes.md">Продвигаемые атрибуты</a>.

## Вставка фрагмента

Чтобы вставить фрагмент, введите <kbd>/</kbd>, а затем первые буквы его заголовка, затем выберите его из списка. Ввод `/snippet` перечисляет все фрагменты, доступные в заметке. Это также работает во включённой кодовой или Markdown-заметке, редактируемой на месте, см. <a class="reference-link" href="../../Note%20Types/Text/Include%20Note.md">Включение заметки</a>.

> [!IMPORTANT]
> Перечисляются только кодовые фрагменты, чей языковой режим совпадает с текущей кодовой заметкой. Например, CSS-кодовая заметка показывает только CSS-фрагменты, а не JavaScript. Исключение — фрагменты с режимом «Обычный текст», которые доступны в заметках <a class="reference-link" href="../../Note%20Types/Markdown.md">Markdown</a> и в любой кодовой заметке независимо от её языкового режима.

## Ограничения

*   В отличие от <a class="reference-link" href="../Templates.md">Шаблонов</a>, фрагменты нельзя ограничить конкретной [рабочей областью](../../Basic%20Concepts%20and%20Features/Navigation/Workspaces.md).
