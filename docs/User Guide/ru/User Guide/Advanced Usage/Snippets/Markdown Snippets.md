# Markdown-фрагменты
Markdown-фрагменты тесно связаны с <a class="reference-link" href="../Templates.md">Шаблонами</a>, но вместо определения содержимого целой заметки фрагмент — это переиспользуемый кусок Markdown-текста, который легко вставить в заметку <a class="reference-link" href="../../Note%20Types/Markdown.md">Markdown</a>.

## Создание Markdown-фрагмента

В <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20Tree.md">Дереве заметок</a>:

1.  Щёлкните правой кнопкой по заметке, куда вы хотите поместить фрагмент.
2.  Выберите _Вставить дочернюю заметку_.
3.  Выберите _Ещё_ → _Markdown-фрагмент_.

Затем просто введите нужное содержимое в заметку.

Заголовок заметки становится заголовком фрагмента. Опционально вы можете добавить описание в разделе <a class="reference-link" href="../Attributes/Promoted%20Attributes.md">Продвигаемые атрибуты</a>.

## Вставка фрагмента

Чтобы вставить фрагмент, введите `/snippet` и выберите его заголовок из выпадающего списка.

Здесь также перечисляются <a class="reference-link" href="Code%20Snippets.md">Кодовые фрагменты</a> с языковым режимом «Обычный текст».

## Ограничения

*   В отличие от <a class="reference-link" href="../Templates.md">Шаблонов</a>, фрагменты нельзя ограничить конкретной [рабочей областью](../../Basic%20Concepts%20and%20Features/Navigation/Workspaces.md).
