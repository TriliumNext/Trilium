# Пользовательский шаблон публикации
> [!NOTE]
> Эта тема создания шаблонов публикации считается продвинутой и требует знаний JavaScript/EJS.
>
> Шаблон публикации по умолчанию должен покрывать большинство обычных случаев.

Для полного контроля над HTML-структурой опубликованной страницы — сверх того, что позволяют пользовательские CSS, JS или HTML-фрагменты, — можно полностью заменить шаблон страницы с помощью отношения `~shareTemplate`.

Для этого:

1.  Создайте <a class="reference-link" href="../../Note%20Types/Code.md">кодовую</a> заметку с языком _Embedded JavaScript_ (EJS).
2.  Чтобы опубликованная заметка применила вновь созданный шаблон, добавьте отношение `~shareTemplate`, указывающее на заметку, созданную на шаге (1). Используйте <a class="reference-link" href="../Attributes/Attribute%20Inheritance.md">Наследование атрибутов</a>, чтобы применить его к нескольким опубликованным заметкам.

Есть два важных ограничения:

*   Поскольку EJS-шаблоны выполняют произвольный серверный JavaScript, `~shareTemplate` вступает в силу только когда серверный скриптинг включён. Если он отключён (см. <a class="reference-link" href="../../Scripting/Security.md">Безопасность</a>), отношение игнорируется и используется шаблон по умолчанию. По той же причине **применяйте шаблоны только из доверенных заметок**.
*   Заметка с шаблоном должна быть частью опубликованного поддерева (как `~shareCss`, `~shareJs`), чтобы её можно было загрузить. Чтобы она не показывалась в навигации, примените к ней `#shareHiddenFromTree`.

## Содержимое шаблона публикации

Используйте [исходный шаблон](https://github.com/TriliumNext/Notes/blob/develop/packages/share-theme/src/templates/page.ejs) как образец при создании нового шаблона публикации.

## Доступные переменные

Ваш шаблон рендерится с объектом контекста, предоставляющим заметку и её окружение рендеринга. Наиболее полезные значения:

| Переменная | Описание |
| --- | --- |
| `note` | Отображаемая заметка. Используйте её для чтения атрибутов (`note.getLabelValue(...)`), `note.title`, дочерних заметок и т.д. |
| `content` | Уже отрендеренное HTML-содержимое заметки в виде строки. |
| `header` | Дополнительный HTML для размещения в заголовке документа для этой заметки (используется некоторыми типами заметок). |
| `isEmpty` | `true`, когда у заметки нет собственного содержимого. |
| `head` | Значения `<head>` страницы: `title` (заголовок заметки, за которым следует заголовок сайта), `description` (`#shareDescription`), `noIndex` (`#shareDisallowRobotIndexing`) и `openGraph` с `url`, `domain`, `image`, `color` и `card` (`summary_large_image` с изображением, `summary` без). Значение, чья метка не задана, равно `null`. `metaTags` перечисляет метатеги `<meta>` description, OpenGraph и Twitter заданных значений, каждый с `attribute` (`name` или `property`), `key` и `content`. |
| `logo` | Логотип сайта над деревом навигации и, на узком экране, в заголовке: `href` (`#shareRootLink`, иначе корневая страница сайта), `image` (изображение `~shareLogo` или `null`), `icon` (классы значка корневой заметки сайта, показываемые при отсутствии `image`), а также `width` и `height` для изображения. |
| `navigation` | Дерево навигации сайта: его видимые страницы, каждая с `title`, `href`, `isExternal`, `type`, `icon`, `isActive` (показываемая страница), `isExpanded` (эта страница или один из её предков) и `children`. |
| `contentClasses` | Классы элемента содержимого: `type-<тип заметки>`, `ck-content` для текстовых и Markdown-заметок, `full-height` для заметки, занимающей всю страницу (такой как PDF, веб-представление, календарь, геокарта или изображение), и `no-content`, когда у заметки нет собственного содержимого. |
| `childLinks` | Ссылки на видимых дочерних заметок, каждая с `title`, `href`, `isExternal`, `type`, `icon` (его классы значка), `excerpt` (его `#shareDescription` или начало текста с разрывом строки между абзацами, или `null`) и `children` (при отсутствии excerpt — первые десять видимых дочерних заметок, каждая с `title`, `href`, `isExternal` и `icon`). Пусто для заметки, не являющейся коллекцией, текстовой или кодовой заметкой, для заметки, занимающей всю страницу, и с `#hideChildrenOverview`. |
| `childLinksLayout` | Как шаблон по умолчанию размещает `childLinks`: `list` для коллекции с видом «список», иначе `grid`. |
| `prevNext` | Страницы до и после заметки в дереве навигации как `previous` и `next`, каждая с `title` и `href`, или `null`. Оба `null` для заметки, занимающей всю страницу. |
| `language` | Языки страницы: `page` с `lang` и `dir` языка приложения и `content` с теми же параметрами языка содержимого заметки, или `null`, когда они совпадают. |
| `lastUpdated` | Когда заметка была изменена в последний раз, как `iso` для элемента `<time>` и как `text` на языке приложения, или `null`, как и для заметки, занимающей всю страницу. |
| `showTitle` | Показывает ли шаблон по умолчанию заголовок заметки над содержимым. Всегда `true`. |
| `titleIcon` | Классы значка заметки, которые шаблон по умолчанию показывает рядом с заголовком в собственной строке для заметки, занимающей всю страницу; `null` для любой другой заметки. |
| `snippets` | HTML фрагментов `~shareHtml` для каждого места, например `snippets["head:end"]`. Каждое место присутствует, пустое, если фрагмент туда не помещён. |
| `subRoot` | Корень опубликованного поддерева как `{ note, branch }` — удобно для заголовка или логотипа всего сайта. |
| `cssToLoad` / `jsToLoad` | Массивы URL таблиц стилей / скриптов, которые внедрила бы тема по умолчанию (включая всё, добавленное через `~shareCss` / `~shareJs`). |
| `faviconUrl` / `logoUrl` | Разрешённые URL favicon и логотипа. Без `~shareLogo` `logoUrl` — логотип Trilium. |
| `fontPreloads` | Значковые шрифты для предзагрузки, каждый с `href` и `type` (медиатип шрифта): Boxicons и наборы значков, используемые логотипом, деревом навигации или подстраницами. Шаблон по умолчанию добавляет `<link rel="preload" as="font" crossorigin>` для каждого, чтобы значки не появлялись только после первой отрисовки. |
| `isStatic` | `true` во время экспорта статического HTML, `false` при живом рендере сервера. |
| `t` | Функция перевода `i18next`. |
| `utils` | Вспомогательные утилиты, такие как `slugify()` и `stripTags()`. |

## Обработка ошибок

Если ваш шаблон выбрасывает ошибку при рендеринге, Trilium журналирует ошибку и тихо откатывается к шаблону по умолчанию, так что сломанный шаблон никогда не роняет опубликованную страницу.

## Разделение шаблона на части (partials)

Шаблон может подключать другие EJS-заметки как части. Создайте их как **дочерние заметки** заметки с шаблоном (каждая также `code` / `application/x-ejs`) и ссылайтесь на них по заголовку:

```
<%- include("header") %>

<main>
    <h1><%= note.title %></h1>
    <%- content %>
</main>

<%- include("footer") %>

```

Здесь `header` и `footer` — заголовки дочерних заметок шаблона. Разрешены только прямые дочерние заметки, и они должны быть EJS-кодовыми заметками.
