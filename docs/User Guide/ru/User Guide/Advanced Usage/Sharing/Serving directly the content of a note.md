# Отдача содержимого заметки напрямую
При доступе к опубликованной заметке Trilium рендерит её как веб-страницу. Иногда желательно отдавать содержимое напрямую, чтобы его можно было использовать в скрипте или скачать пользователю.

| Заметка, отображаемая как веб-страница (HTML) | Заметка, отображаемая в исходном формате |
| --- | --- |

## Добавлением атрибута к заметке

Просто добавьте атрибут `#shareRaw`, и заметка всегда будет отдаваться _в исходном виде_ при доступе из URL публикации.

## Изменением URL

Добавьте `?raw` к URL, чтобы отобразить заметку в исходном формате независимо от того, добавлен ли на заметке атрибут `#shareRaw`.
