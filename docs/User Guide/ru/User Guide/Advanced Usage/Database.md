# База данных
Ваши данные Trilium хранятся в базе данных [SQLite](https://www.sqlite.org), которая содержит все заметки, структуру дерева, метаданные и большую часть конфигурации. Файл базы данных называется `document.db` и хранится в стандартном [Каталоге данных](../Installation%20%26%20Setup/Data%20directory.md) приложения.

## Демонстрационные заметки

При первом запуске Trilium предоставит набор заметок, демонстрирующих различные возможности приложения.

Подробнее см. <a class="reference-link" href="Database/Demo%20Notes.md">Демонстрационные заметки</a>.

## Ручное изменение базы данных

Trilium предоставляет большую гибкость и вместе с ней возможности для продвинутых пользователей его настраивать. Если вам нужно исследовать или изменить базу данных напрямую, можно использовать инструмент вроде [SQLite Browser](https://sqlitebrowser.org/), работая непосредственно с файлом базы данных.

См. [Ручное изменение базы данных](Database/Manually%20altering%20the%20database.md) для получения дополнительной информации.

## Как сбросить базу данных

Если вы хотите начать заново и:

*   Создать и переключиться на новую пустую базу знаний
*   Использовать другую базу знаний, синхронизируемую с сервером или десктопным приложением
*   Восстановить резервную копию

Перейдите в <a class="reference-link" href="../Basic%20Concepts%20and%20Features/UI%20Elements/Options.md">Настройки</a> → _База данных_ и нажмите кнопку _Начать сначала_. Вам будет предложено перезапустить приложение с возможностью сделать резервную копию текущей базы данных перед продолжением.

> [!IMPORTANT]
> Для веб-клиента Trilium не может перезапуститься автоматически. Вам нужно будет вручную перезапустить сервер/контейнер, а затем перезагрузить веб-приложение.

После перезапуска появится экран настройки. Вы можете сделать резервную копию существующей базы данных, а затем пройти меню настройки как при новой установке. Существующая база данных будет перезаписана только после выбора создания новой базы данных, синхронизации с сервером или восстановления из резервной копии.

### Устаревший способ

Если вы экспериментируете с Trilium и хотите вернуть его в исходное состояние, вы можете сделать это, удалив текущую базу данных. При перезапуске приложения будет создана новая база данных с исходными демонстрационными заметками.

Чтобы удалить базу данных, просто перейдите в [каталог данных](../Installation%20%26%20Setup/Data%20directory.md) и удалите файл `document.db` (и любые другие файлы, начинающиеся с `document.db`).

Если вам не нужно сохранять конфигурацию, которая может храниться в файле `config.ini`, можно просто удалить всё содержимое [каталога данных](../Installation%20%26%20Setup/Data%20directory.md), чтобы полностью вернуть приложение в исходное состояние. Также можно рассмотреть [конфигурацию](Configuration%20\(config.ini%20or%20environment%20variables\).md), чтобы задавать все значения `config.ini` вместо этого как переменные окружения.
