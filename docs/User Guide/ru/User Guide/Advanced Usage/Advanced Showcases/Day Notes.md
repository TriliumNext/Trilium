# Заметки дня
Распространённый шаблон ведения заметок: многие заметки привязаны к определённой дате — например, задачи, которые нужно выполнить в определённый день, протоколы встреч, ваши мысли и т.д., и всё это вращается вокруг даты, когда это произошло. Поэтому имеет смысл создать «рабочее пространство дня», которое объединит все заметки, относящиеся к определённой дате.

Для этого Trilium предоставляет концепцию «заметки дня». Trilium полуавтоматически генерирует одну заметку для каждого дня. Под этой заметкой можно сохранять все относящиеся к ней заметки.

Выберите существующую заметку дня — в строке меню появится виджет календаря. Выберите любой день, чтобы создать заметку для этого дня.

![](Day%20Notes_image.jpg)

Этот шаблон хорошо работает также благодаря возможности [Клонирования заметок](../../Basic%20Concepts%20and%20Features/Notes/Cloning%20Notes.md) — заметка может появляться в дереве в нескольких местах, поэтому помимо размещения под заметкой дня её можно отнести и к другим заметкам.

## Демонстрация

![](Day%20Notes_image.png)

Вы можете видеть структуру заметок дня под заметкой «Дневник» (Journal): есть заметка для всего 2025 года, под ней — «03 - March», которая содержит «09 - Monday». Это наша «заметка дня», в которой есть немного текста и несколько дочерних заметок (некоторые из них из [Менеджера задач](Task%20Manager.md)).

Также заметьте, что у этой заметки дня есть [продвигаемый атрибут](../Attributes/Promoted%20Attributes.md) «вес», в котором можно отслеживать ежедневный вес. Эти данные затем используются в [Трекере веса](Weight%20Tracker.md).

## Отредактированные заметки

Когда заметка дня открыта, под её <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/Notes/Title.md">Заголовком</a> появляется сворачиваемый раздел с заметками, отредактированными в этот день.

## Заметки недели и квартала

Заметки недели и квартала по умолчанию отключены, так как для некоторых это может быть слишком. Чтобы включить их, задайте атрибуты `#enableWeekNote` и `#enableQuarterNote` на корневой заметке календаря, которая определяется меткой `#calendarRoot`. Заметка недели зависит от опции первой недели года. Будьте осторожны, если у вас уже созданы заметки недель: они не изменятся автоматически, что может привести к дубликатам.

## Шаблоны

Trilium предоставляет функциональность [шаблонов](../Templates.md), которую можно использовать вместе с заметками дня.

На корне журнала (заметка с меткой `#calendarRoot`) можно определить одно из следующих отношений:

*   yearTemplate
*   quarterTemplate (если задан `#enableQuarterNote`)
*   monthTemplate
*   weekTemplate (если задан `#enableWeekNote`)
*   dateTemplate

Все это отношения. Когда Trilium создаёт новую заметку года, месяца или даты, он смотрит на корень и прикрепляет соответствующее отношение `~template` к вновь созданной заметке. Так можно, например, создать свой ежедневный шаблон с флажками для ежедневных дел и т.п.

### Переход со старого использования шаблонов

Если вы использовали Дневник (Journal) до версии v0.93.0, ранее, вероятно, использовался шаблон `~child:template=`.  
Чтобы перейти на новую систему:

1.  Настройте новый шаблон в корневой заметке календаря.
2.  С помощью [Массовых действий](../Bulk%20Actions.md) удалите `child:template` и `child:child:template` со всех заметок под Journal (корнем календаря).
3.  Убедитесь, что все старые шаблоны полностью удалены, чтобы избежать конфликтов с новой настройкой.

## Шаблон именования

Можно настроить заголовок генерируемых заметок журнала, задав атрибуты `#datePattern`, `#weekPattern`, `#monthPattern`, `#quarterPattern` и `#yearPattern` на корневой заметке календаря (с меткой `#calendarRoot`). Замены в шаблонах именования совместимы «снизу вверх»: каждый уровень может использовать замены своего уровня и всех уровней выше. Например, `#monthPattern` может использовать замены месяца, квартала и года, а `#weekPattern` — недели, месяца, квартала и года. Но использовать замены недели в `#monthPattern` нельзя.

### Шаблон даты

Можно настроить заголовок генерируемых заметок даты атрибутом `#datePattern` на корневой заметке календаря (с меткой `#calendarRoot`). Возможные значения:

*   `{isoDate}` даёт дату в формате ISO 8061 (например, «2025-03-09» для 9 марта 2025)
*   `{dateNumber}` даёт число вида `9` для 9-го дня месяца, `11` для 11-го дня месяца
*   `{dateNumberPadded}` даёт число вида `09` для 9-го дня месяца, `11` для 11-го дня месяца
*   `{ordinal}` заменяется порядковой датой (например, 1st, 2nd, 3rd) и т.д.
*   `{weekDay}` даёт полное название дня (например, `Monday`)
*   `{weekDay3}` заменяется первыми 3 буквами дня, например Mon, Tue и т.д.
*   `{weekDay2}` заменяется первыми 2 буквами дня, например Mo, Tu и т.д.

По умолчанию — `{dateNumberPadded} - {weekDay}`

### Шаблон недели

Также можно настроить заголовок генерируемых заметок недели атрибутом `#weekPattern` на корневой заметке календаря. Варианты:

*   `{weekNumber}` даёт число вида `9` для 9-й недели года, `11` для 11-й недели года
*   `{weekNumberPadded}` даёт число вида `09` для 9-й недели года, `11` для 11-й недели года
*   `{shortWeek}` даёт короткую строку недели вида `W9` для 9-й недели года, `W11` для 11-й недели года
*   `{shortWeek3}` даёт короткую строку недели вида `W09` для 9-й недели года, `W11` для 11-й недели года

По умолчанию — `Week {weekNumber}`

### Шаблон месяца

Также можно настроить заголовок генерируемых заметок месяца атрибутом `#monthPattern` на корневой заметке календаря. Варианты:

*   `{isoMonth}` даёт месяц в формате ISO 8061 (например, «2025-03» для марта 2025)
*   `{monthNumber}` даёт число вида `9` для сентября и `11` для ноября
*   `{monthNumberPadded}` даёт число вида `09` для сентября и `11` для ноября
*   `{month}` даёт полное название месяца (например, `September` или `October`)
*   `{shortMonth3}` заменяется первыми 3 буквами месяца, например Jan, Feb и т.д.
*   `{shortMonth4}` заменяется первыми 4 буквами месяца, например Sept, Octo и т.д.

По умолчанию — `{monthNumberPadded} - {month}`

### Шаблон квартала

Также можно настроить заголовок генерируемых заметок квартала атрибутом `#quarterPattern` на корневой заметке календаря. Варианты:

*   `{quarterNumber}` даёт число вида `1` для 1-го квартала года
*   `{shortQuarter}` даёт короткую строку квартала вида `Q1` для 1-го квартала года

По умолчанию — `Quarter {quarterNumber}`

### Шаблон года

Также можно настроить заголовок генерируемых заметок года атрибутом `#yearPattern` на корневой заметке календаря. Варианты:

*   `{year}` даёт полный год (например, `2025`)

По умолчанию — `{year}`

## Реализация

Trilium имеет специальную поддержку заметок дня в виде [серверного Script API](https://triliumnext.github.io/Notes/backend_api/BackendScriptApi.html) — см., например, функцию getDayNote().

Заметки дня (а также года и месяца) создаются с меткой — например `#dateNote="2025-03-09"`, которую затем могут использовать другие скрипты для добавления новых заметок в заметку дня и т.п.
