# Извлечение текста (OCR)
Оптическое распознавание символов (OCR) — это процесс извлечения текста из изображений или PDF.

## Встроенная поддержка

Начиная с v0.103.0 в Trilium есть встроенная поддержка OCR. Извлечённый текст может:

*   Интегрироваться с <a class="reference-link" href="../Basic%20Concepts%20and%20Features/Navigation/Search.md">Поиском</a>, чтобы быстро находить изображение или файл по фрагментам текста.
*   Интегрироваться с возможностью <a class="reference-link" href="../AI.md">ИИ</a>, позволяя агенту обращаться к содержимому нетекстовой заметки.
*   Доступаться вручную для других целей (например, копирование в заметку или отправка куда-либо).

## Поддерживаемые форматы

OCR в Trilium поддерживает следующие форматы:

### Изображения

*   Поддерживаются как [отдельные заметки-изображения](../Note%20Types/File.md), так и [вложения в текстовых файлах](../Note%20Types/Text/Images.md).
*   Поддерживаемые форматы:
    *   JPEG
    *   PNG
    *   GIF (только неанимированные)
    *   BMP
    *   WebP
*   Обратите внимание, что эта возможность лучше всего работает для отрендеренного компьютером текста, а не рукописного.
*   Лежащая в основе технология — Tesseract.js.

### PDF

Извлечение из PDF поддерживает:

*   PDF с текстовой информацией (например, PDF, созданный браузером или текстовым процессором), из которых текст извлекается напрямую.
*   Отсканированные PDF и другие PDF, текст которых нельзя выделить (такие как документы, чей текст был превращён в кривые), из которых текст извлекается через процесс OCR.
*   Смешанные PDF, содержащие и текст, и изображения с текстом.

Обратите внимание, что OCR-извлечение ограничено 50 страницами на PDF; страницы, содержащие текстовую информацию (не как изображение), этому ограничению не подвержены.

> [!NOTE]
> Извлечение текста из отсканированных PDF с помощью OCR появилось в v0.106.0. Если отсканированный PDF уже обрабатывался более ранней версией, обработайте его повторно индивидуально через _Обработать OCR_; пакетная обработка обрабатывает только файлы, которые ещё не прошли OCR.

### Документы Office

Текст будет извлечён из следующих форматов файлов:

*   Документы Microsoft Word
*   Документы Microsoft Excel
    *   Только сырой текстовой информации; структура ячеек не сохраняется.
    *   Значения извлекаются в сыром виде, поэтому поиск по датам не будет работать. Альтернатива OpenDocument извлечёт корректно отформатированное значение.
*   Документы Microsoft PowerPoint
*   Альтернативы OpenDocument перечисленных форматов (Text, Spreadsheet, Presentation), созданные редакторами вроде LibreOffice и OpenOffice.
*   [Rich Text Format (RTF)](https://en.wikipedia.org/wiki/Rich_Text_Format), начиная с v0.104.0.
*   [EPUB](https://en.wikipedia.org/wiki/EPUB), начиная с v0.104.1.

## Настройка и запуск OCR

OCR можно настроить, открыв <a class="reference-link" href="../Basic%20Concepts%20and%20Features/UI%20Elements/Options.md">Настройки</a> → <a class="reference-link" href="#root/_hidden/_options/_optionsMedia">Медиа</a> и найдя раздел _Извлечение текста (OCR)_.

Есть три способа запустить OCR:

*   Включив _Автообработку новых файлов_, которая обработает только заметки или вложения, созданные после включения опции; существующие файлы останутся необработанными.
*   Нажав _Начать пакетную обработку_, которая обработает все существующие заметки.
*   Вручную запросив извлечение текста для изображения или файла независимо от того, включена ли автоматическая обработка.

### Минимальная уверенность

При извлечении текста из изображения существует определённый уровень уверенности, указывающий, выглядит ли извлечённый текст релевантным.

Когда минимальная уверенность установлена на низкий процент, извлечение текста может неверно интерпретировать символы и рисунки, давая искажённый текст.

Если качество извлечённого текста для заметки или вложения ниже минимальной уверенности, OCR отбрасывается.

## Управление языками

OCR должен знать язык содержимого, чтобы работать корректно. Причина в том, что для каждого языка нужны свои данные, которые требуется загрузить, а акценты и другие символы не будут поддерживаться языком по умолчанию.

Чтобы настроить языки, поддерживаемые OCR, просто откройте <a class="reference-link" href="../Basic%20Concepts%20and%20Features/UI%20Elements/Options.md">Настройки</a> → <a class="reference-link" href="#root/_hidden/_options/_optionsLocalization">Язык и регион</a> и настройте _Языки содержимого_.

Когда языки содержимого не определены, используется _Язык_ пользовательского интерфейса.

После этого изменения автоматическая обработка или ручная повторная обработка будут учитывать новые языки.

Чтобы принудительно задать распознавание на определённом языке для конкретной заметки, используйте [атрибут](Attributes.md) `language`, аналогично [языку содержимого текста](../Note%20Types/Text/Content%20language%20%26%20Right-to-left%20support.md). Для <a class="reference-link" href="../Basic%20Concepts%20and%20Features/Notes/Attachments.md">Вложений</a> вручную изменить язык нельзя.

> [!NOTE]
> Обученные данные для каждого языка не поставляются с Trilium, так как это потребовало бы значительного объёма, который может быть иначе не нужен. Вместо этого обученные данные загружаются автоматически через [Tesseract.js](https://github.com/naptha/tesseract.js/).
>
> Загруженные обученные данные расположены в <a class="reference-link" href="../Installation%20%26%20Setup/Data%20directory.md">Каталоге данных</a>, в каталоге `ocr-cache`.

## Просмотр извлечённого содержимого для одной заметки

Чтобы получить доступ к извлечённому содержимому заметки:

*   Для заметок-<a class="reference-link" href="../Note%20Types/File.md">Файлов</a> откройте <a class="reference-link" href="../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20menu.md">Меню заметки</a> → _Дополнительно_ → _Просмотреть текст OCR_.
*   Для <a class="reference-link" href="../Basic%20Concepts%20and%20Features/Notes/Attachments.md">Вложений</a> (например, <a class="reference-link" href="../Note%20Types/Text/Images.md">Изображений</a> в заметках <a class="reference-link" href="../Note%20Types/Text.md">Текст</a>) дважды щёлкните вложение, чтобы просмотреть детали, нажмите кнопку \[…\] слева и выберите _Просмотреть извлечённый текст (OCR)_.

Этот раздел позволяет:

*   Просматривать извлечённый текст, который при необходимости можно скопировать в другое место или просто проверить качество извлечения.
*   Если заметка ещё не была извлечена, нажатие _Обработать OCR_ обработает её в фоне. Если уверенность извлечения ниже минимальной, будет показано уведомление.
*   Аналогично, если минимальная уверенность была изменена в настройках, можно снова нажать кнопку _Обработать OCR_, чтобы извлечь текст заново.
