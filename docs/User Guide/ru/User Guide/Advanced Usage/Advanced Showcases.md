# Продвинутые примеры
Trilium предлагает расширенные возможности через [Скрипты](../Scripting.md) и [Продвигаемые атрибуты](Attributes/Promoted%20Attributes.md). Чтобы продемонстрировать эти возможности, мы подготовили несколько примеров, доступных в [демонстрационных заметках](Database.md):

*   [Карта отношений](../Note%20Types/Relation%20Map.md)
*   [Заметки дня](Advanced%20Showcases/Day%20Notes.md)
*   [Трекер веса](Advanced%20Showcases/Weight%20Tracker.md)
*   [Менеджер задач](Advanced%20Showcases/Task%20Manager.md)

Важно отметить: эти примеры не поддерживаются в Trilium «из коробки»; вместо этого они демонстрируют, что можно построить внутри Trilium.
