# Экземпляр Trilium
Экземпляр Trilium представляет сервер. Если настроена <a class="reference-link" href="../../Installation%20%26%20Setup/Synchronization.md">Синхронизация</a>, задействовано несколько серверов (десктопного клиента и сервера синхронизации), и иногда бывает полезно различать, на каком экземпляре вы работаете.

## Задание имени экземпляра

Чтобы задать имя экземпляра, измените `config.ini`:

```
[General]
instanceName=Hello
```

## Различение экземпляра на сервере

Используйте `api.getInstanceName()`, чтобы получить имя экземпляра текущего сервера, заданное в файле конфигурации или переменных окружения.

## Ограничение запуска скриптов по экземплярам

Для скрипта, запускаемого периодически или по определённому событию, можно ограничить его запуск определёнными экземплярами без изменения кода. Просто добавьте `runOnInstance` и в качестве значения укажите имя экземпляра, на котором скрипт должен запускаться. Чтобы запускать на нескольких именованных экземплярах, просто добавьте метку несколько раз.
