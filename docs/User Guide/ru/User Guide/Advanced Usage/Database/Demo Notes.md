# Демонстрационные заметки
При первом запуске Trilium создаёт новую базу данных с демонстрационными заметками. Эти заметки демонстрируют его многочисленные возможности, такие как:

*   <a class="reference-link" href="../../Note%20Types/Relation%20Map.md">Карта отношений</a>
*   <a class="reference-link" href="../Advanced%20Showcases/Day%20Notes.md">Заметки дня</a>
*   <a class="reference-link" href="../Advanced%20Showcases/Weight%20Tracker.md">Трекер веса</a>
*   <a class="reference-link" href="../Advanced%20Showcases/Task%20Manager.md">Менеджер задач</a>
*   <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/Themes.md">Темы</a>

### Восстановление демонстрационных заметок

Есть случаи, когда может понадобиться восстановить исходные демонстрационные заметки. Например, если вы поэкспериментировали с некоторыми более продвинутыми возможностями и хотите увидеть исходный образец, или если вы просто хотите изучить последнюю версию демонстрационных заметок, которая может демонстрировать новые возможности.

Вы можете легко восстановить демонстрационные заметки с помощью встроенной функции импорта Trilium:

*   Скачайте [.zip-архив](https://github.com/TriliumNext/Trilium/raw/refs/heads/main/apps/server/src/assets/db/demo.zip) с последней версией демонстрационных заметок
*   Щёлкните правой кнопкой по любой заметке в дереве, под которой хотите импортировать демонстрационные заметки
*   Нажмите «Импортировать в заметку…»
*   Выберите .zip-архив для импорта
