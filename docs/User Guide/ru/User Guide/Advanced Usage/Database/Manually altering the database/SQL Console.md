# SQL-консоль
> [!IMPORTANT]
> Начиная с v0.104.0 серверные скрипты по умолчанию отключены для уменьшения поверхности атаки. Подробнее см. <a class="reference-link" href="../../../Scripting/Security.md">Безопасность</a>.

SQL-консоль — это встроенный редактор базы данных Trilium.

К ней можно получить доступ через <a class="reference-link" href="../../../Basic%20Concepts%20and%20Features/UI%20Elements/Global%20menu.md">Глобальное меню</a> → Дополнительно → SQL-консоль.

![](SQL%20Console_image.jpg)

### Взаимодействие

*   Наведение мыши на одну из таблиц, перечисленных вверху документа, покажет столбцы и их типы данных.
*   Одновременно можно выполнить только один SQL-запрос.
*   Чтобы выполнить запрос, нажмите значок _Выполнить_.
*   Для запросов, возвращающих результат, данные отображаются в таблице.
*   Для выражений (например, `INSERT`, `UPDATE`) отображается количество затронутых строк.

### Работа с таблицей

После выполнения запроса отображается таблица с результатами:

*   Щелчок по столбцу позволяет сортировать по возрастанию или убыванию. Столбец `#` нумерует строки и не сортируется.
*   Под каждым столбцом есть поле ввода, позволяющее фильтровать по тексту.
*   Нажмите <kbd>Ctrl</kbd>+<kbd>C</kbd>, чтобы скопировать текущую ячейку в буфер обмена.
*   Можно выделять несколько ячеек перетаскиванием или удерживая <kbd>Shift</kbd> + клавиши со стрелками.
*   Результаты разбиты на страницы для производительности. Элементы управления внизу таблицы позволяют переходить по страницам.

### Сохранённая SQL-консоль

SQL-запросы или команды можно сохранять в специальную заметку.

Для этого просто напишите запрос и нажмите кнопку <span class="tn-icon bx bx-save"></span>. После сохранения заметка появится в <a class="reference-link" href="../../Advanced%20Showcases/Day%20Notes.md">Заметках дня</a> по умолчанию. Изменить местоположение сохранённых запросов по умолчанию можно, присвоив [метку](../../Attributes/Labels.md) `#sqlConsoleHome`.

Заметку можно заблокировать для редактирования кнопкой _Заблокировать_ в разделе действий заметки рядом с заголовком. Когда редактирование заблокировано, SQL-выражение скрыто из вида.
