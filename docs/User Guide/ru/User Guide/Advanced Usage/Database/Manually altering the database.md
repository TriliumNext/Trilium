# Ручное изменение базы данных
Есть ситуации, когда изменение используемой Trilium базы данных SQLite желательно.

Если вы выполняете продвинутую разработку или отладку с ручным изменением базы данных, стоит рассмотреть создание резервных копий файла `document.db`.

## Внутреннее изменение через SQL-консоль

SQL-консоль — это встроенный редактор базы данных Trilium.

См. <a class="reference-link" href="Manually%20altering%20the%20database/SQL%20Console.md">SQL-консоль</a>.

## Внешнее изменение базы данных

Иногда SQL-консоль нельзя использовать (например, если приложение не запускается).

При внешних изменениях рассмотрите закрытие десктопного приложения. Если изменяется база данных сервера, остановите службу или Docker-контейнер.

### Использование DB Browser for SQLite

DB Browser for SQLite — кроссплатформенный редактор, который можно использовать для изменения базы данных через графический интерфейс.

Для этого:

1.  В главном меню выберите File → Open database… и перейдите к базе данных в [Каталоге данных](../../Installation%20%26%20Setup/Data%20directory.md).
2.  Выберите вкладку _Execute SQL_.
3.  Введите нужный SQL-запрос.
4.  Нажмите кнопку «Play» на панели инструментов под вкладкой «Execute SQL» (или клавишу F5).
5.  Нажмите «Write Changes» на главной панели инструментов.
6.  Закройте приложение или закройте базу данных.

![](Manually%20altering%20the%20database_image.jpg)

### Использование SQLite CLI

Сначала запустите SQLite 3 CLI, указав путь к базе данных:

```
sqlite3 ~/.local/share/trilium-data/document.db
```

*   В приглашении просто введите выражение и убедитесь, что оно заканчивается символом `;`.
*   Чтобы выйти, введите `.quit` и нажмите Enter.
