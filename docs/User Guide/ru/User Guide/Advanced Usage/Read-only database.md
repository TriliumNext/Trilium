# База данных только для чтения
> [!WARNING]
> Эта функциональность всё ещё в предпросмотре: возможны проблемы или даже полное исчезновение возможности.
> Не стесняйтесь [сообщать](../Troubleshooting/Reporting%20issues.md) о любых проблемах.

База данных только для чтения — альтернатива <a class="reference-link" href="Sharing.md">Публикации</a> заметок. Хотя возможность публикации неплохо работает для публикации страниц в интернете в формате вики/блога, она не предлагает полную функциональность Trilium (такую как продвинутый <a class="reference-link" href="../Basic%20Concepts%20and%20Features/Navigation/Search.md">Поиск</a>, интерактивность <a class="reference-link" href="../Collections.md">Коллекций</a> или различных <a class="reference-link" href="../Note%20Types.md">Типов заметок</a>).

Когда база данных в режиме только для чтения, приложение Trilium можно использовать как обычно, но редактирование отключено, а изменения выполняются только в памяти.

## Что она делает

*   Все заметки доступны только для чтения, без возможности их редактирования.
*   Возможности, которые обычно изменяют базу данных, такие как список недавних заметок, отключены.

## Ограничения

*   Некоторые возможности могут «проскользнуть» и всё же создать, например, заметку.
    *   Однако база данных по-прежнему только для чтения, поэтому все изменения будут сброшены при перезапуске сервера.
    *   При каждом таком случае в журналах будет показано `ERROR: read-only DB ignored`.

## Установка базы данных в режим только для чтения

Сначала убедитесь, что база данных инициализирована (например, первоначальная настройка завершена). Затем измените [config.ini](Configuration%20\(config.ini%20or%20environment%20variables\).md), найдя секцию `[General]` и добавив новое поле `readOnly`:

```
[General]
readOnly=true
```

Если ваш сервер уже запущен, перезапустите его, чтобы применить изменения.

Аналогично, чтобы отключить режим только для чтения, удалите строку или установите её в `false`.
