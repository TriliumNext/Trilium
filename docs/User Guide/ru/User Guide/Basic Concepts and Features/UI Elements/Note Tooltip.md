# Подсказка заметки
<figure class="image image-style-align-right"><img style="aspect-ratio:505/261;" src="Note Tooltip_image.png" width="505" height="261"></figure>

Подсказка заметки — удобная возможность, отображающая всплывающее окно при наведении на [внутреннюю ссылку](../../Note%20Types/Text/Links/Internal%20\(reference\)%20links.md) на другую заметку.

Отображается следующая информация:

*   Путь заметки вверху всплывающего окна.
*   Заголовок заметки.
    *   Щелчок по заголовку откроет заметку в текущей вкладке.
    *   Удержание <kbd>Ctrl</kbd> при щелчке по заголовку откроет её в новой вкладке вместо текущей.
*   Фрагмент содержимого также будет отображён.
*   Кнопка для [быстрого редактирования](../Navigation/Quick%20edit.md) заметки во всплывающем окне.
    *   Для ссылки на блоки заметки, в которой находится ссылка, её место занимает кнопка <span class="tn-icon bx bx-up-arrow"></span> _Перейти к блоку_ или _Перейти к заголовку_ для заголовка, и она прокручивает к ним, не покидая заметку.

Для ссылки на [вложение](../Notes/Attachments.md) подсказка вместо этого показывает вложение: его заголовок после пути заметки, которая им владеет, строку с его размером (например, _Вложение • 20.59 MiB_), предпросмотр его содержимого там, где он доступен, и кнопку быстрого редактирования, открывающую вложение.

Подсказку можно найти в нескольких местах, включая:

*   В заметках <a class="reference-link" href="../../Note%20Types/Text.md">Текст</a>, при наведении на <a class="reference-link" href="../../Note%20Types/Text/Links/Internal%20(reference)%20links.md">Внутренние (ссылочные) ссылки</a>.
*   <a class="reference-link" href="../../Collections.md">Коллекции</a>:
    *   <a class="reference-link" href="../../Collections/Geo%20Map.md">Вид геокарты</a>, при наведении на маркер.
    *   <a class="reference-link" href="../../Collections/Calendar.md">Вид календаря</a>, при наведении на событие.
    *   <a class="reference-link" href="../../Collections/Table.md">Вид таблицы</a>, при наведении на заголовок заметки или на [отношение](../../Advanced%20Usage/Attributes/Relations.md).
