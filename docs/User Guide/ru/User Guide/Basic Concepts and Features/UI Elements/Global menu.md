# Глобальное меню
Глобальное меню настраивает текущее окно (масштаб, поверх других окон), переключает тему и предлагает доступ к некоторым более продвинутым опциям.

![](Global%20menu_image.jpg)

## Доступ к глобальному меню

См. [Вертикальное и горизонтальное расположение](Vertical%20and%20horizontal%20layout.md), так как положение глобального меню меняется в зависимости от выбранного расположения.

## Переключение темы

Подменю _Тема_ меняет внешний вид приложения, не открывая <a class="reference-link" href="Options.md">Настройки</a>. Отметка в конце строки показывает активный выбор. Подменю не показывается на мобильных устройствах; меняйте тему там в <a class="reference-link" href="Options.md">Настройках</a> → _Внешний вид_.

*   Под _Цветовая схема_ выберите _Система_, чтобы следовать светлому или тёмному режиму операционной системы, или _Светлая_ либо _Тёмная_, чтобы использовать одну из них независимо.
*   Под _Тема_ выберите _Современная_ (тема по умолчанию) или одну из пользовательских тем, каждая показана со значком своей заметки. Переключение на _Современную_ сохраняет текущую цветовую схему.

Пользовательская тема приносит собственные цвета, поэтому цветовые схемы недоступны, пока она активна. Устаревшая тема не перечислена; выберите её в <a class="reference-link" href="Options.md">Настройках</a> → _Внешний вид_.

Подробнее о встроенных и пользовательских темах см. <a class="reference-link" href="../Themes.md">Темы</a>.
