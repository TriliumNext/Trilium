# Правая боковая панель
<figure class="image"><img style="aspect-ratio:1990/1168;" src="Right Sidebar_image.png" width="1990" height="1168"></figure>

Правая боковая панель отображает специфичное содержимое для текущей заметки. Панель сгруппирована в несколько вкладок:

*   <a class="reference-link" href="Right%20Sidebar/Outline%20tab.md">Вкладка «Структура»</a>, которая отображает оглавление, выделения и другие разделы, связанные с навигацией, в зависимости от типа заметки.
*   <a class="reference-link" href="Right%20Sidebar/Attributes%20tab.md">Вкладка «Атрибуты»</a>, предоставляющая визуальный редактор для <a class="reference-link" href="../../Advanced%20Usage/Attributes.md">Атрибутов</a> текущей заметки.
*   <a class="reference-link" href="Right%20Sidebar/AI%20chat%20tab.md">Вкладка «ИИ-чат»</a>, использующая интеграцию <a class="reference-link" href="../../AI.md">ИИ</a> для общения в чате с опциональным доступом к текущей заметке.
*   <a class="reference-link" href="Right%20Sidebar/Connections%20tab.md">Вкладка «Связи»</a>, группирующая вместе карту заметок, пути заметки, обратные ссылки и похожие заметки.

Каждое окно хранит свою выбранную вкладку, поэтому переключение вкладок в одном окне не влияет на остальные. Вновь открытое окно начинается с вкладки, выбранной последней.

## Переключение правой боковой панели

Есть два способа переключить правую боковую панель:

*   Через значок <span class="tn-icon bx bx-sidebar bx-flip-horizontal"></span> рядом со строкой заголовка, который переключает, закреплена ли панель.
*   Через [сочетание клавиш](../Keyboard%20Shortcuts.md) _Переключить правую панель_, не назначенное по умолчанию.

## Подглядывание панели

Рядом с правым краем приложения есть небольшая полоса со значком стрелки.

*   Когда панель скрыта, нажатие на край _подглянет_ панель.
    *   В этом режиме панель показывается временно поверх содержимого, не сдвигая содержимое ваших заметок.
    *   Щелчок вне панели в режиме подглядывания просто скроет панель. То же касается кнопки X и щелчка по правому краю.
    *   Нажатие значка булавки закрепит панель.
*   Когда панель закреплена, нажатие на край скроет панель (аналогично значку переключения вверху).

[Сочетание клавиш](../Keyboard%20Shortcuts.md) _Подглянуть правую панель_, <kbd>Alt</kbd>+<kbd>]</kbd> по умолчанию, делает то же самое, что и нажатие полосы.

## Поддержка мобильных устройств

На мобильных устройствах правая боковая панель заменена панелью заметки, которая открывается как шторка снизу экрана по кнопке <span class="tn-icon bx bx-dock-bottom"></span> рядом с <a class="reference-link" href="Note%20menu.md">Меню заметки</a>.

*   Вкладки переключаются с панели внизу шторки. Как и на десктопе, вкладка, которой нечего показать для текущей заметки, опускается, а вкладка _Виджеты_ перечисляет [виджеты правой панели](../../Scripting/Frontend%20Basics/Custom%20Widgets/Right%20pane%20widget.md) скриптов.
*   Разделы вкладки отображаются один за другим как карточки, каждая со своим именем над ней, вместо сворачиваемых разделов.
*   Заголовок шторки показывает имя вкладки, кроме вкладок _Атрибуты_ и _ИИ-чат_, где он содержит их кнопки (см. <a class="reference-link" href="Right%20Sidebar/Attributes%20tab.md">Вкладка «Атрибуты»</a> и <a class="reference-link" href="Right%20Sidebar/AI%20chat%20tab.md">Вкладка «ИИ-чат»</a>).
*   Нажатие на заголовок оглавления или на страницу либо аннотацию PDF закрывает панель и прокручивает заметку к нему.
