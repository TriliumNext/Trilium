# Типы заметок с разделённым видом
Разделённый вид — возможность заметок <a class="reference-link" href="../../Note%20Types/Mermaid%20Diagrams.md">Диаграммы Mermaid</a> и <a class="reference-link" href="../../Note%20Types/Markdown.md">Markdown</a>, которая отображает исходный код с одной стороны и предпросмотр содержимого с другой.

<a class="reference-link" href="../../Note%20Types/Mermaid%20Diagrams.md">Диаграммы Mermaid</a> также позволяют переключаться между горизонтальным и вертикальным разделением, чтобы подстроиться под различные размеры диаграмм.

## Режимы отображения и взаимодействие

Разделение имеет три разных режима отображения, которые можно переключать из области <a class="reference-link" href="Note%20buttons.md">Кнопок заметки</a>:

*   <span class="tn-icon bx bxs-dock-left"></span> _(Разделённый вид)_, в котором исходный код доступен с одной стороны и может редактироваться, а предпросмотр — с другой.
    *   В этом режиме размер панели исходника или панели предпросмотра можно настроить перетаскиванием маленькой границы между ними.
*   <span class="tn-icon bx bx-code"></span> _(Вид исходника)_, который показывает исходный код на весь экран для более сфокусированного редактирования.
*   <span class="tn-icon bx bx-show"></span> _(Предпросмотр)_, который отображает только рендеринг диаграммы или текста в полный экран, особенно полезен для заметок только для чтения.

Режим отображения хранится на уровне заметки.

Включённая в текстовую заметку Markdown-заметка или встроенный Markdown-файл имеют те же три режима отображения, переключаемые со строки заголовка и панели инструментов включения. См. _Включённый Markdown_ в <a class="reference-link" href="../../Note%20Types/Text/Include%20Note.md">Включении заметки</a>.

## Связь с заметками только для чтения

Если заметка помечена как [доступная только для чтения](../Notes/Read-Only%20Notes.md), вид исходника не будет редактируемым. В режиме предпросмотра пометка заметки как доступной только для чтения не имеет эффекта, так как сам предпросмотр не редактируется.
