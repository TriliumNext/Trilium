# Вертикальное и горизонтальное расположение
Trilium поддерживает два разных расположения, на основе ваших предпочтений.

### Вертикальное расположение

Вертикальное расположение — исходное расположение Trilium:

*   <a class="reference-link" href="Launch%20Bar.md">Панель запуска</a> расположена с левой стороны экрана, с кнопками, разложенными вертикально.
*   Панель вкладок находится вверху, но справа от <a class="reference-link" href="Note%20Tree.md">Дерева заметок</a>.
*   <a class="reference-link" href="../Navigation/Quick%20search.md">Быстрый поиск</a> находится вверху <a class="reference-link" href="Note%20Tree.md">Дерева заметок</a>.
*   <a class="reference-link" href="Note%20Tree.md">Дерево заметок</a> можно свернуть, нажав кнопку <span class="tn-icon bx bx-chevrons-left"></span> внизу <a class="reference-link" href="Launch%20Bar.md">Панели запуска</a>. В свёрнутом состоянии его можно временно подглядеть поверх содержимого, нажав полосу на правой стороне <a class="reference-link" href="Launch%20Bar.md">Панели запуска</a>.
*   К <a class="reference-link" href="Global%20menu.md">Глобальному меню</a> можно получить доступ через значок <span class="tn-icon cke cke-trilium"></span> вверху <a class="reference-link" href="Launch%20Bar.md">Панели запуска</a>.

### Горизонтальное расположение

Горизонтальное расположение — более традиционное расположение, так как оно похоже на другие приложения. В этом режиме:

*   <a class="reference-link" href="Launch%20Bar.md">Панель запуска</a> находится вверху экрана, с кнопками, разложенными горизонтально.
*   Панель вкладок находится вверху экрана, но теперь покрывает всю ширину, позволяя отображать больше вкладок одновременно.
*   <a class="reference-link" href="../Navigation/Quick%20search.md">Быстрый поиск</a> теперь является частью <a class="reference-link" href="Launch%20Bar.md">Панели запуска</a>. Его можно перемещать по предпочтению и даже удалить при необходимости.
*   <a class="reference-link" href="Note%20Tree.md">Дерево заметок</a> можно свернуть, нажав маленькую кнопку <span class="tn-icon bx bx-sidebar"></span> слева от первой вкладки. В свёрнутом состоянии его можно временно подглядеть поверх содержимого, нажав полосу на левом краю приложения.
*   К <a class="reference-link" href="Global%20menu.md">Глобальному меню</a> можно получить доступ через кнопку <span class="tn-icon bx bx-menu"></span> в конце <a class="reference-link" href="Launch%20Bar.md">Панели запуска</a>.

![](Vertical%20and%20horizontal%20layout_image.jpg)

## Изменение расположения

Перейдите в <a class="reference-link" href="Options.md">Настройки</a> и найдите опцию _Внешний вид_ слева. Затем найдите раздел _Расположение_, где есть возможность переключаться между двумя доступными расположениями.

Щелчок по опции немедленно применит выбранное расположение, перезагрузив окно.
