# Масштаб
Масштаб применяется ко всему интерфейсу, включая текст.

В десктопном приложении используйте <a class="reference-link" href="Global%20menu.md">Глобальное меню</a>, чтобы увеличить/уменьшить масштаб.

И в веб-браузере, и на десктопе можно использовать сочетания клавиш <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>+</kbd> и <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>-</kbd>.

## Настройка размера текста вместо масштаба

Как альтернативу масштабу, размер текста можно настроить индивидуально, перейдя в <a class="reference-link" href="Options.md">Настройки</a> → _Внешний вид_.
