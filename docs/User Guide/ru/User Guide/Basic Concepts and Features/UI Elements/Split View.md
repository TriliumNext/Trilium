# Разделённый вид
В Trilium возможно работать с двумя или более заметками бок о бок.

<figure class="image image-style-align-center"><img style="aspect-ratio:1398/1015;" src="Split View_2_Split View_image.png" width="1398" height="1015"></figure>

## Взаимодействие

*   Нажмите кнопку <span class="tn-icon bx bx-dock-right"></span> справа от заголовка заметки, чтобы открыть новое разделение справа от неё.
    *   Можно иметь столько разделений, сколько нужно; просто нажмите кнопку ещё раз.
    *   Возможны только горизонтальные разделения; вертикальные или перетаскивание не поддерживаются.
*   Когда открыто хотя бы одно разделение, нажмите кнопку <span class="tn-icon bx bx-x"></span> рядом с ним, чтобы закрыть его.
*   Используйте кнопку <span class="tn-icon bx bx-chevron-right"></span> или <span class="tn-icon bx bx-chevron-left"></span>, чтобы перемещаться между разделениями.
*   Создание, закрытие и перемещение разделения также можно вызвать [сочетанием клавиш](../Keyboard%20Shortcuts.md) (_Создать новое разделение_, _Закрыть активное разделение_, _Переместить разделение влево_ и _Переместить разделение вправо_, все не назначены по умолчанию) или через [палитру команд](../Navigation/Jump%20to%20%26%20command%20palette.md).
*   Фокус можно переместить с одного разделения на следующее действиями _Фокусировать разделение слева_ и _Фокусировать разделение справа_, которые останавливаются на любом конце вкладки вместо продолжения в следующую вкладку. Они также не назначены по умолчанию.
*   Каждая [вкладка](Tabs.md) имеет собственную конфигурацию разделённого вида (например, в одной вкладке может быть две заметки в разделённом виде, тогда как остальные — однозаметочный вид).
    *   Заголовок вкладки будет указывать все заголовки заметок в порядке разделений слева направо, разделённые символом-маркером.
    *   Значок вкладки будет указывать значок последнего активного разделения, которое будет автоматически сфокусировано при щелчке по вкладке.

## Разделения и дерево заметок и хостинг

Щелчок по содержимому разделения сфокусирует это разделение. В сфокусированном состоянии <a class="reference-link" href="Note%20Tree.md">Дерево заметок</a> также будет указывать редактируемую заметку.

Для каждого из разделений возможен собственный <a class="reference-link" href="../Navigation/Note%20Hoisting.md">хостинг заметок</a>.

При создании нового разделения оно будет разделять тот же хостинг заметок, что и предыдущее. Простое решение — просто поднять заметки после создания разделения.

Это обычно весьма полезно для реорганизации заметок из одного места в другое: подняв старое место в первом разделении и подняв новое место во втором. Это позволит легко вырезать и вставлять без прыгания дерева при переключении между заметками.

## Поддержка мобильных устройств

Начиная с v0.100.0, возможен разделённый вид и в мобильном интерфейсе, со следующими отличиями от десктопной версии разделения:

*   На смартфонах разделённые виды расположены вертикально (один сверху и один снизу) вместо горизонтально, как на десктопе.
*   Может быть открыто только одно разделение на вкладку.
*   Невозможно изменить размер двух разделённых панелей.
*   При открытии клавиатуры активная заметка будет «развёрнута», обеспечивая больше места даже при открытом разделении. При закрытии клавиатуры разделения снова становятся одинакового размера.

Взаимодействие:

*   Чтобы создать новое разделение, нажмите кнопку с тремя точками справа от заголовка заметки и нажмите <span class="tn-icon bx bx-dock-right"></span> _Новое разделение_ в строке значков вверху.
    *   Эта опция будет доступна, только если в текущей вкладке ещё нет разделения.
*   Чтобы закрыть разделение, нажмите кнопку с тремя точками справа от заголовка заметки и выберите _Закрыть эту панель_.
    *   Обратите внимание, что эта опция будет доступна только на второй заметке в разделении (на смартфонах — нижней, на планшетах — правой).
*   При длительном нажатии ссылки появится контекстное меню с опцией _Открыть заметку в новом разделении_.
    *   Если разделение уже есть, опция заменит существующее.
