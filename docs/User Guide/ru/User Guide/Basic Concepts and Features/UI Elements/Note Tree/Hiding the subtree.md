# Скрытие поддерева
<figure class="image image-style-align-right"><img style="aspect-ratio:328/45;" src="1_Hiding the subtree_image.png" width="328" height="45"><figcaption>Пример коллекции с относительно большим числом потомков, скрытых из дерева.</figcaption></figure>

Дерево хорошо работает, когда заметки структурированы в иерархию, так что число элементов остаётся небольшим. Когда у заметки большое число заметок (порядка тысяч или десятков тысяч), возникают две проблемы:

*   Навигация между заметками становится громоздкой, и само дерево захламляется большим количеством заметок.
*   Большое количество заметок может значительно замедлить приложение.

Начиная с v0.102.0, Trilium позволяет дереву скрывать дочерние заметки определённых заметок. Это работает как для <a class="reference-link" href="../../../Collections.md">Коллекций</a>, так и для обычных заметок.

## Взаимодействие

Когда поддерево заметки скрыто, есть несколько тонких изменений:

*   Чтобы указать, что поддерево скрыто, у заметки не будет кнопки разворачивания, и она будет показывать число дочерних заметок справа.
*   Нельзя добавить новую заметку напрямую из дерева.
    *   Для <a class="reference-link" href="../../../Collections.md">Коллекций</a> лучше всего использовать встроенный механизм создания заметок (например, создавая новую точку на геокарте или добавляя новую строку в таблице).
    *   Для обычных заметок всё ещё возможно создавать потомков другими способами, такими как использование системы <a class="reference-link" href="../../../Note%20Types/Text/Links/Internal%20(reference)%20links.md">Внутренних (ссылочных) ссылок</a>.
*   Заметки можно перетащить извне заметки, в этом случае они будут клонированы в неё.
    *   Вместо переключения на скопированные дочерние заметки подсвечивается родительская заметка.
    *   Уведомление укажет это поведение.
*   Аналогично, функции вроде вырезания/копирования с последующей вставкой в заметку тоже будут работать.

## Подсветка в центре внимания (Spotlighting)

<figure class="image image-style-align-right"><img style="aspect-ratio:322/83;" src="Hiding the subtree_image.png" width="322" height="83"></figure>

Даже если поддерево заметки скрыто, если дочерней заметке удаётся стать активной, она всё равно появится внутри дерева в специальном состоянии, называемом _подсвеченной в центре внимания_.

В этом состоянии заметка остаётся под своей обычной иерархией, так что легко определить её местоположение. Кроме того, это означает, что:

*   Позиция заметки чётко видна при использовании <a class="reference-link" href="../../Navigation/Search.md">Поиска</a>.
*   С заметкой по-прежнему можно работать из дерева, например добавлять <a class="reference-link" href="../../Notes/Cloning%20Notes/Branch%20prefix.md">Префикс ветви</a> или перемещать её за пределы коллекции.

Заметка появляется курсивом, чтобы указать её временное отображение. При переключении на другую заметку подсвеченная заметка исчезнет.

> [!NOTE]
> Одновременно может быть подсвечена только одна заметка. При работе с несколькими заметками, например перетаскивании их в коллекцию, ни одна заметка не будет подсвечена. Это намеренно, чтобы избежать отображения частичного состояния поддерева.

## Работа с коллекциями

Для больших коллекций может быть полезно скрыть их дочерние заметки для производительности или расчистки дерева.

Чтобы переключить это поведение:

*   Откройте коллекцию и в <a class="reference-link" href="../../../Collections/Collection%20Properties.md">Свойствах коллекции</a> найдите _Скрыть дочерние заметки в дереве_.
*   Щёлкните правой кнопкой по заметке коллекции в <a class="reference-link" href="../Note%20Tree.md">Дереве заметок</a> и выберите _Дополнительно_ → _Показать поддерево_.

## Работа с обычными заметками

Возможно скрыть поддерево и для обычных заметок, не только коллекций. Для этого щёлкните правой кнопкой по заметке в <a class="reference-link" href="../Note%20Tree.md">Дереве заметок</a> и выберите _Дополнительно_ → _Скрыть поддерево_.
