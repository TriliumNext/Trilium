# Множественный выбор
В <a class="reference-link" href="../Note%20Tree.md">Дереве заметок</a> можно выбрать несколько заметок одновременно. Это не затронет отображаемую в данный момент заметку, но позволит выполнять пакетные операции.

## Типы множественного выбора

### Выбор заметок по одной

Чтобы выбрать каждую заметку по отдельности, нажмите клавишу <kbd>Alt</kbd> и щёлкните по заметке, которую нужно выбрать.

Выбранные заметки будут обозначены другим цветом фона и значком.

### Выбор заметок последовательностью

<figure class="image image-style-align-right image_resized" style="width:29.24%;"><img style="aspect-ratio:233/205;" src="Multiple selection_image.jpg" width="233" height="205"></figure>

Когда заметки идут последовательно (например, одна под другой), весь выбор можно сделать, просто выбрав первый и последний элемент, вместо того чтобы щёлкать каждую заметку по отдельности.

Для этого сначала выберите заметку, с которой начать выбор. Затем удерживайте <kbd>Shift</kbd> и щёлкните по заметке, которой закончить выбор. Все заметки между начальной и конечной также будут выбраны.

## Выбранные заметки и активная заметка

Есть различие между _выбранными заметками_ и _активной заметкой_:

*   _Выбранные заметки_ — это просто заметки, которые были выбраны в процессе множественного выбора (т.е. через <kbd>Alt</kbd> или <kbd>Shift</kbd>).
*   _Активная заметка_ — это просто заметка, содержимое которой отображается справа от дерева.
    *   Визуально она опознаётся в дереве по другому цвету фона и тонкой тени.
    *   Активная заметка также может быть выбрана, в этом случае значок и фон тоже изменятся:
