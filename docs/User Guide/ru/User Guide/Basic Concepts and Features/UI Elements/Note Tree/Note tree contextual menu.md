# Контекстное меню дерева заметок
<figure class="image image-style-align-right"><img style="aspect-ratio:269/608;" src="1_Note tree contextual menu_image.png" width="269" height="608"></figure>

_Меню дерева заметок_ доступно правым щелчком в <a class="reference-link" href="../Note%20Tree.md">Дереве заметок</a>.

## Взаимодействие

Контекстное меню может работать:

*   С одной заметкой, щёлкнув по ней правой кнопкой в дереве заметок.
*   С несколькими заметками, сначала выбрав их. Как это сделать, см. <a class="reference-link" href="Multiple%20selection.md">Множественный выбор</a>.
    *   При правом щелчке учтите, что обычно заметка, по которой щёлкают правой кнопкой, также включается в затронутые заметки независимо от того, была ли она выбрана.

## Доступные опции

> [!NOTE]
> Когда выбрано несколько заметок, активен только подмножество заметок. Те, что поддерживают несколько заметок, упомянут это в списке ниже.

Самые частые действия расположены рядом вверху меню, каждый значок над своим именем. Используйте <kbd>←</kbd> и <kbd>→</kbd> или <kbd>↑</kbd> и <kbd>↓</kbd>, чтобы перемещаться между ними.

*   **Вырезать**
    *   Поместит данные заметки в буфер обмена.
    *   Используйте одну из двух функций вставки (или сочетания клавиш), чтобы переместить их в нужное место.
*   **Копировать**
    *   Поместит данные заметки в буфер обмена.
    *   Используйте одну из двух функций вставки (или сочетания клавиш), чтобы скопировать их в нужное место.
    *   Обратите внимание, что функция копирования здесь работает согласно функциональности <a class="reference-link" href="../../Notes/Cloning%20Notes.md">Клонирования заметок</a> (т.е. сама заметка будет присутствовать в двух местах одновременно, и её редактирование в одном месте отредактирует её везде).
    *   Чтобы просто создать дубликат заметки, который можно изменять независимо, ищите _Дублировать_.
*   **Вставить в**
    *   Вставляет заметки из буфера обмена как дочерние заметки той, по которой щёлкнули правой кнопкой.
    *   Показывается только после вырезания или копирования заметок.
*   **Вставить после**
    *   Вставляет заметки из буфера обмена под той, по которой щёлкнули правой кнопкой.
    *   Показывается только после вырезания или копирования заметок.
*   **Удалить**
    *   Удалит данные заметки, сначала запросив подтверждение.
    *   В диалоге можно настроить следующие опции:
        *   _Удалить также все клоны_, чтобы гарантировать, что заметка будет удалена везде, если она была размещена в нескольких местах (см. <a class="reference-link" href="../../Notes/Cloning%20Notes.md">Клонирование заметок</a>).
        *   _Стереть заметки навсегда_ гарантирует, что заметку нельзя будет восстановить из <a class="reference-link" href="../Recent%20Changes.md">Последних изменений</a>.

Остальная часть меню перечисляет свои опции по одной в строку:

*   **Открыть заметку**
    *   Щелчок открывает заметку в новой [вкладке](../Tabs.md).
    *   Наведение на неё или щелчок по её стрелке открывает подменю с местами, где можно открыть заметку: _Открыть в новой вкладке_, _Открыть в новом разделении_ (справа от заметки, внутри текущей вкладки) и _Открыть в новом окне_.
    *   На мобильном меню вместо _Открыть заметку_ напрямую перечисляет _Открыть_, _Открыть в новой вкладке_ и _Открыть в новом разделении_, и опускает _Открыть в новом окне_. _Открыть_ показывает заметку в текущей вкладке, что также открывает заметку с потомками, так как нажатие на одну перечисляет её потомков.
*   **Быстрое редактирование**
    *   Открывает заметку в <a class="reference-link" href="../../Navigation/Quick%20edit.md">Быстром редактировании</a> поверх текущей.
*   **Поднять заметку**
    *   Сфокусирует дерево заметок на этой заметке. Подробнее см. <a class="reference-link" href="../../Navigation/Note%20Hoisting.md">Поднятие заметки</a>.
*   **Вставить заметку после**
    *   Позволяет легко создать заметку с указанным [типом заметок](../../../Note%20Types.md).
    *   Подменю _Код_ начинается со скриптовых заметок, каждая — кодовая заметка, настроенная для своей роли: _Пользовательский CSS_ (с `#appCss`), _Виджет_ (с `#widget` и начальным скелетом) и _Серверный скрипт_. За ними следуют включённые языки кода.
    *   <a class="reference-link" href="../../../Collections.md">Коллекции</a> сгруппированы в подменю _Коллекция_. Типы заметок, создаваемые реже, <a class="reference-link" href="../../../Advanced%20Usage/Snippets.md">Фрагменты</a> и быстрое действие ИИ находятся в подменю _Ещё_.
    *   <a class="reference-link" href="../../../Advanced%20Usage/Templates.md">Шаблоны</a> также будут присутствовать (если есть) в конце списка под заголовком _Шаблоны_. Кнопка <span class="tn-icon bx bx-cog"></span> рядом с заголовком открывает _Управление содержимым_ в <a class="reference-link" href="../Options.md">Настройках</a>, где можно управлять шаблонами.
    *   Чтобы быстро найти запись, введите текст в поле поиска вверху подменю или просто начните печатать, пока подменю открыто. Подменю затем перечисляет каждую совпадающую запись, включая те, что внутри его собственных подменю (таких как язык кода или коллекция), каждую с подменю, из которого она взята. Используйте <kbd>↑</kbd> и <kbd>↓</kbd>, чтобы выбрать совпадение, <kbd>Enter</kbd>, чтобы создать его, и <kbd>Esc</kbd>, чтобы очистить поиск.
    *   Заметка будет добавлена на том же уровне иерархии, что и выбранная заметка.
*   **Вставить дочернюю заметку**
    *   То же, что _Вставить заметку после_, но заметка будет создана как дочерняя выбранной заметки.
*   **Переместить в…**
    *   Покажет модальный диалог для указания, куда переместить нужные заметки.
*   **Клонировать в…**
    *   Покажет модальный диалог для указания, куда [клонировать](../../Notes/Cloning%20Notes.md) нужные заметки.
*   **Дублировать**
    *   Создаёт копию заметки и её потомков, размещённую сразу после оригинала.
    *   Когда у заметки есть дочерние заметки, элемент также имеет стрелку, отделённую разделителем. Наведение на элемент или щелчок по стрелке открывает подменю:
        *   _Заметка и её потомки_ делает то же, что щелчок по _Дублировать_.
        *   _Только эта заметка_ копирует заметку с её содержимым и атрибутами, но без каких-либо её дочерних заметок. Ссылки и отношения на оригинальные потомки продолжают указывать на них.
    *   Этот процесс отличается от <a class="reference-link" href="../../Notes/Cloning%20Notes.md">Клонирования заметок</a>, так как продублированную заметку можно редактировать независимо от оригинала.
    *   Альтернатива этому, если делается регулярно, — <a class="reference-link" href="../../../Advanced%20Usage/Templates.md">Шаблоны</a>.
*   **Архивировать/Разархивировать**
    *   Помечает заметку как [архивную](../../Notes/Archived%20Notes.md).
    *   Если заметка уже архивная, она вместо этого будет разархивирована.
    *   Можно выбрать и несколько заметок. Однако все выбранные заметки должны быть в одном состоянии (архивные или нет), иначе опция будет отключена.
*   **Защитить поддерево/Снять защиту поддерева**
    *   На незащищённой заметке _Защитить поддерево_ помечает эту заметку и всех её потомков как защищённые. На защищённой заметке элемент читается _Снять защиту поддерева_ и вместо этого снимает с них защиту после запроса подтверждения. Любое действие запрашивает пароль, если защищённая сессия не запущена. Подробнее см. <a class="reference-link" href="../../Notes/Protected%20Notes.md">Защищённые заметки</a>.
    *   Наведение на элемент или щелчок по его стрелке открывает подменю с обоими действиями, например чтобы снять защиту с защищённых заметок ниже заметки, которая сама не защищена.
*   **Импортировать в заметку…**
    *   Открывает диалог [импорта](../../Import%20%26%20Export.md) и размещает импортированные заметки как дочерние заметки выбранной.
*   **Экспортировать…**
    *   Открывает диалог [экспорта](../../Import%20%26%20Export.md) для выбранных заметок.
*   **Искать в поддереве**
    *   Открывает полный <a class="reference-link" href="../../Navigation/Search.md">Поиск</a>, преднастроенный искать только в этой заметке и её потомках (поле _Предок_).

## Дополнительные опции

<figure class="image image-style-align-right"><img style="aspect-ratio:231/263;" src="Note tree contextual menu_image.png" width="231" height="263"></figure>

Меню дополнительных опций предлагает некоторые из менее часто используемых действий для заметок.

Чтобы получить доступ к этим опциям, сначала найдите опцию _Дополнительно_ внизу контекстного меню, чтобы раскрыть подменю с:

*   **Применить массовые действия…**
    *   Открывает диалог <a class="reference-link" href="../../../Advanced%20Usage/Bulk%20Actions.md">Массовых действий</a>, чтобы применить действия, такие как добавление меток или перемещение заметок, к нескольким заметкам сразу (см. <a class="reference-link" href="Multiple%20selection.md">Множественный выбор</a>).
*   **Редактировать префикс ветви…**
    *   Открывает диалог для присвоения имени, позволяющего различать [клоны](../../Notes/Cloning%20Notes.md); подробнее см. <a class="reference-link" href="../../Notes/Cloning%20Notes/Branch%20prefix.md">Префикс ветви</a>.
*   **Преобразовать во вложение…**
    *   Преобразует выбранные заметки во <a class="reference-link" href="../../Notes/Attachments.md">Вложения</a> их родительских заметок.
    *   Эта функция наиболее полезна при работе с заметками-<a class="reference-link" href="../../../Note%20Types/File.md">Файлами</a>-изображениями, импортированными из внешнего источника или более старой версии Trilium.
*   **Развернуть поддерево**
    *   Разворачивает все дочерние заметки в <a class="reference-link" href="../Note%20Tree.md">Дереве заметок</a>.
*   **Свернуть поддерево**
    *   Сворачивает все дочерние заметки в дереве заметок.
*   **Сортировать по…**
    *   Открывает диалог для сортировки всех дочерних заметок выбранной заметки.
    *   Сортировка выполняется только один раз; есть также механизм автоматической сортировки, который можно задать с помощью <a class="reference-link" href="../../../Advanced%20Usage/Attributes.md">Атрибутов</a>.
    *   Подробнее см. <a class="reference-link" href="../../Notes/Sorting%20Notes.md">Сортировка заметок</a>.
*   **Копировать путь заметки в буфер обмена**
    *   Копирует фрагмент URL, представляющий полный путь к этой ветви для заметки, например `#root/Hb2E70L7HPuf/4sRFgMZhYFts/2IVuShedRJ3U/LJVMvKXOFv7n`.
    *   URL для ручного создания <a class="reference-link" href="../../../Note%20Types/Text/Links.md">Ссылок</a> внутри заметок или для <a class="reference-link" href="../../Navigation">Навигации</a> по заметкам.
*   **Последние изменения в поддереве**
    *   Откроет <a class="reference-link" href="../Recent%20Changes.md">Последние изменения</a>, но отфильтрованные только по изменениям, относящимся к этой заметке или одному из её потомков.
