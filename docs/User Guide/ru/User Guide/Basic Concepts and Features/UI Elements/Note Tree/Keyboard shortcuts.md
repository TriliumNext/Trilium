# Сочетания клавиш
<a class="reference-link" href="../Note%20Tree.md">Дерево заметок</a> имеет несколько сочетаний клавиш для ускорения редактирования:

## Навигация по дереву

*   <kbd><span>↑</span></kbd> и <kbd><span>↓</span></kbd> для перемещения между заметками.
*   <kbd><span>←</span></kbd> чтобы свернуть заметку с потомками или <kbd><span>→</span></kbd>, чтобы развернуть её.
*   <kbd><span>←</span></kbd> на заметке без потомков для перехода к её родителю.

## Открытие заметок

*   <kbd>Щелчок</kbd>, чтобы открыть заметку в текущей вкладке.
*   <kbd>Ctrl</kbd>+<kbd>Щелчок</kbd> или <kbd>Средний щелчок</kbd>, чтобы открыть заметку в новой вкладке.
*   <kbd>Ctrl</kbd>+<kbd>Правый щелчок</kbd>, чтобы открыть заметку в <a class="reference-link" href="../../Navigation/Quick%20edit.md">Быстром редактировании</a>.

## Управление буфером обмена

*   <kbd>Ctrl</kbd>+<kbd>C</kbd>, чтобы скопировать одну или несколько заметок на основе выбора (см. <a class="reference-link" href="../../Notes/Cloning%20Notes.md">Клонирование заметок</a>).
*   <kbd>Ctrl</kbd>+<kbd>X</kbd>, чтобы вырезать одну или несколько заметок (для их перемещения).
*   <kbd>Ctrl</kbd>+<kbd>V</kbd>, чтобы вставить их куда-нибудь (что приводит к копированию или перемещению в зависимости от использованного сочетания).

## Перемещение заметок

*   <kbd>Ctrl</kbd> + <kbd><span>↑</span></kbd>, <kbd>Ctrl</kbd> + <kbd><span>↓</span></kbd> — переместить заметку вверх/вниз по списку заметок.
*   <kbd>Ctrl</kbd> + <kbd><span>←</span></kbd> — переместить заметку вверх по дереву заметок.
*   <kbd>Ctrl</kbd>+<kbd><span>→</span></kbd> — переместить заметку вниз по дереву заметок.
*   <kbd>Del</kbd> — удаляет заметку и опционально её поддерево (спрашивается в диалоге).
*   <kbd>Alt</kbd>+<kbd>S</kbd> — сортирует дочерние заметки заметки (см. <a class="reference-link" href="../../Notes/Sorting%20Notes.md">Сортировка заметок</a>).

## Множественный выбор

Подробнее о том, как работает выбор, см. <a class="reference-link" href="Multiple%20selection.md">Множественный выбор</a>.

*   <kbd>Alt</kbd>+<kbd>Щелчок</kbd> – добавить одну заметку к текущему выбору.
*   <kbd>Shift</kbd>+<kbd>Щелчок</kbd> – выбрать диапазон заметок, начиная с текущей заметки (подсвеченной) и до той, по которой выполняется щелчок.
*   <kbd>Shift</kbd>+<kbd><span>↑</span></kbd>, <kbd>Shift</kbd>+<kbd><span>↓</span></kbd> – мультивыбор выше/ниже.
*   <kbd>Ctrl</kbd>+<kbd>A</kbd> – выбрать все заметки на текущем уровне
