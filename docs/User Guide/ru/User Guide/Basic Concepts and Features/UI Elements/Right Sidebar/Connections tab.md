# Вкладка «Связи»
<figure class="image image-style-align-right image_resized" style="width:33.35%;"><img style="aspect-ratio:490/1801;" src="Connections tab_image.png" width="490" height="1801"></figure>

Вкладка связей группирует вместе всю информацию о текущей заметке и о том, как она относится к другим заметкам, в четырёх разных разделах.

> [!NOTE]
> Как правило, лучше держать развёрнутыми только нужные разделы, так как каждому из разделов нужно получать дополнительные данные, которые иначе могли бы не понадобиться. В свёрнутом состоянии разделы не получают никаких дополнительных данных.

## Карта заметок

Карта заметок отображает граф, показывающий отношения между текущей заметкой и другими заметками в иерархии. Есть два типа визуализаций, которые можно выбрать в правой верхней части раздела:

*   _Link map_ (<span class="tn-icon bx bx-network-chart"></span>), который отображает [отношения](../../../Advanced%20Usage/Attributes/Relations.md) между заметками.
*   _Карта дерева_ (<span class="tn-icon bx bx-sitemap"></span>), которая отображает иерархическую структуру.

Боковая панель запомнит, какая визуализация выбрана, как глобальную опцию. Обратите внимание, что карты заметок также имеют `#mapType`, описывающий, какую визуализацию использовать, но боковая панель намеренно игнорирует его, чтобы сохранять согласованность при переключении между заметками.

Карту также можно развернуть, нажав кнопку <span class="tn-icon bx bx-expand-alt"></span> в правом верхнем углу раздела. В развёрнутом виде карта отображается в отдельном диалоге. Альтернативно, можно свернуть все остальные разделы, что сделает карту заметок выше, а боковую панель можно перетащить, чтобы получить больше бокового пространства.

Вид карты заметок внутри боковой панели намеренно более компактен, чтобы вписаться в пространство: link map также показывал бы заметки, не имеющие ссылки на текущую заметку из иерархии (создавая облако точек), но это показывается только пока карта развёрнута. Аналогично, кнопки силы связи и настройки булавок здесь не отображаются.

См. также:

*   Тип заметок <a class="reference-link" href="../../../Note%20Types/Note%20Map.md">Карта заметок</a>
*   <a class="reference-link" href="../../../Advanced%20Usage/Note%20Map%20(Link%20map%2C%20Tree%20map).md">Карта заметок (Link map, Tree map)</a> для получения дополнительной информации о концепции в целом.

## Пути заметки

Раздел путей заметки отображает места, в которых текущая заметка [клонирована](../../Notes/Cloning%20Notes.md). Каждый сегмент пути заметки кликабелен, чтобы перейти к этой заметке или клону. Корневая заметка показана её значком, так же как в <a class="reference-link" href="../Breadcrumb.md">«Хлебных крошках»</a>; наведение на него показывает её заголовок.

Новый клон можно создать с кнопки <span class="tn-icon bx bx-duplicate"></span> в правом верхнем углу.

## Обратные ссылки

Обратные ссылки перечисляют заметки, которые ссылаются на текущую заметку, а также предпросмотр содержимого, где сделана ссылка на заметку.

Подробнее см. <a class="reference-link" href="../../../Note%20Types/Text/Links/Backlinks.md">Обратные ссылки</a>.

## Похожие заметки

Отображает список заметок, кажущихся похожими на основе содержимого заметок и их атрибутов. Подробнее см. <a class="reference-link" href="../../Navigation/Similar%20Notes.md">Похожие заметки</a>.
