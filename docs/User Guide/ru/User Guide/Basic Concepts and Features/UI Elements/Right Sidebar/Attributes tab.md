# Вкладка «Атрибуты»
<figure class="image image-style-align-right image_resized" style="width:34.71%;"><img style="aspect-ratio:596/1688;" src="Attributes tab_image.png" width="596" height="1688"></figure>

Вкладка атрибутов предоставляет более графический способ просматривать и редактировать [атрибуты](../../../Advanced%20Usage/Attributes.md).

## Разделы

Атрибуты сгруппированы в сворачиваемые разделы, каждый показывает число содержащихся в нём атрибутов рядом со своим именем:

*   _Собственные_ содержит список атрибутов, принадлежащих этой заметке.
*   _Наследуемые_ содержат атрибуты, применяемые к текущей заметке, но приходящие через <a class="reference-link" href="../../../Advanced%20Usage/Attributes/Attribute%20Inheritance.md">Наследование атрибутов</a>. Этот раздел отображается только если заметка наследует атрибуты.
*   _Определения_ описывают тип атрибутов и используются в <a class="reference-link" href="../../../Advanced%20Usage/Attributes/Promoted%20Attributes.md">Продвигаемых атрибутах</a> и коллекциях <a class="reference-link" href="../../../Collections/Table.md">Таблица</a>. Этот раздел отображается только если у заметки есть или наследуются определения.

Щелчок по имени раздела сворачивает или разворачивает его, и свёрнутое состояние запоминается.

## Панель инструментов

Над разделами есть панель инструментов с:

*   Флажком _Выбрать все_, который выбирает каждый атрибут (см. [Выбор атрибутов](#выбор-атрибутов)).
*   Кнопкой <span class="tn-icon bx bx-paste"></span>, которая появляется только после копирования атрибутов. Она перечисляет скопированные атрибуты и предлагает вставить их в текущую заметку или очистить их.
*   Кнопкой <span class="tn-icon bx bx-plus"></span> _Добавить новый атрибут_, которая предлагает добавить метку, отношение, определение метки или определение отношения. Это показывает полное всплывающее окно деталей.

На заметке, которую нельзя редактировать (например, страница встроенной справки), кнопки вставки и добавления заменены индикатором <span class="tn-icon bx bx-lock-alt"></span> _Только для чтения_. Атрибуты с такой заметки всё равно можно выбирать и копировать.

## Собственные атрибуты

Каждый элемент структурирован так:

*   Значок каждого элемента указывает, является ли он [меткой](../../../Advanced%20Usage/Attributes/Labels.md) (<span class="tn-icon bx bx-hash"></span>) или [отношением](../../../Advanced%20Usage/Attributes/Relations.md) (<span class="tn-icon bx bx-transfer"></span>, ссылка на другую заметку).
*   Первый текст — имя метки.
*   Значение атрибута отображается после имени, если присутствует.
    *   Значение показано графически: значение отношения — кликабельная ссылка на заметку; метка цвета показывает образец цвета.

Системные атрибуты (имеющие особое значение в Trilium) показывают маленькую шестерёнку <span class="tn-icon bx bx-cog"></span> рядом со значком и сгруппированы отдельно от пользовательских.

Взаимодействие:

*   Щелчок по элементу (кроме значения и ссылок) раскрывает выделенное всплывающее окно, где можно определить имя, значение и <a class="reference-link" href="../../../Advanced%20Usage/Attributes/Attribute%20Inheritance.md">Наследование атрибутов</a>.
*   Значение атрибутов можно редактировать на месте:
    *   Поле ввода следует типу, определённому в соответствующем определении метки (дата, цвет, выпадающий список, числа), а также для системных атрибутов, имеющих конкретный тип (например, `color`).
    *   Для меток щелчок по значению редактирует его на месте.
        *   Нажмите <kbd>Enter</kbd> для подтверждения или щёлкните вне поля ввода, или <kbd>Esc</kbd> для отмены.
        *   Для многострочного текста <kbd>Ctrl</kbd>+<kbd>Enter</kbd> подтверждает, тогда как <kbd>Enter</kbd> создаёт новую строку.
    *   Для атрибутов-флажков щелчок по флажку переключит его состояние.
    *   Для меток без значения значение можно добавить, щёлкнув по тексту _Нет значения_, который появляется при наведении курсора на элемент.
    *   Для отношений вместо этого есть выделенная кнопка <span class="tn-icon bx bx-pencil"></span>.
*   Атрибут можно удалить, нажав кнопку <span class="tn-icon bx bx-trash"></span> справа от него, которая появляется только при наведении. Сначала отображается экран подтверждения, чтобы убедиться, что атрибут не удалён случайно.

Атрибуты можно добавить двумя способами:

*   Новая метка, отношение или определение атрибута может быть добавлены с кнопки <span class="tn-icon bx bx-plus"></span> на [панели инструментов](#панель-инструментов). Это показывает полное всплывающее окно деталей.
*   Чтобы быстро добавить метку или отношение прямо из боковой панели, нажмите элемент _Добавить атрибут_ (<span class="tn-icon bx bx-plus"></span>) в конце списка.
    *   Сначала будет сфокусировано поле имени. По умолчанию будет создана метка, но её можно переключить на отношение, введя <kbd>~</kbd> или нажав значок <span class="tn-icon bx bx-hash"></span> (аналогично, ввод `#` переключит обратно на метку вместо отношения).
    *   Как только имя заполнено, нажмите <kbd>Enter</kbd>, чтобы перейти к значению. Введите значение, если нужно, затем снова нажмите <kbd>Enter</kbd>, чтобы создать атрибут.
    *   Щелчок вне редактора также создаст атрибут, но только если указано имя.

## Наследуемые атрибуты

Наследуемые метки или отношения показаны тем же образом, что и собственные.

Единственные различия:

*   Справа от наследуемого атрибута есть ссылка на заметку, откуда атрибут пришёл, а также значок <span class="tn-icon bx bx-sitemap"></span>, указывающий, что он наследуемый.
*   Щелчок по наследуемому атрибуту раскроет то же всплывающее окно, что и для собственных атрибутов, но оно не редактируемо. Чтобы отредактировать его, сначала перейдите к заметке, где атрибут определён.

## Определения

Для определения атрибута (см. <a class="reference-link" href="../../../Advanced%20Usage/Attributes/Promoted%20Attributes.md">Продвигаемые атрибуты</a>):

*   Значок указывает тип атрибута (текст, число).
    *   Если атрибут продвигаемый, он имеет маленькую наложенную иконку шеврона <span class="tn-icon bx bx-chevron-up"></span>.
*   Имя указывает имя определяемого атрибута (без префикса `label:` или `relation:`).
*   Справа от имени отображается краткая сводка, указывающая отображаемое имя (псевдоним), имеет ли он несколько значений или обратное отношение.
*   Щелчок по определению раскрывает всплывающее окно, где можно настроить имя, тип, отображаемое имя и другие аспекты.
*   Чтобы добавить определение метки, нажмите элемент _Добавить определение_ (<span class="tn-icon bx bx-plus"></span>) в конце списка; его тип можно сменить на отношение из всплывающего окна. Оба вида определений также можно добавить с кнопки <span class="tn-icon bx bx-plus"></span> на [панели инструментов](#панель-инструментов).
*   Для наследуемого определения есть ссылка на заметку, откуда определение пришло, а также значок <span class="tn-icon bx bx-sitemap"></span>, указывающий, что оно наследуемое.

## Выбор атрибутов

Можно выбрать несколько атрибутов, чтобы скопировать или удалить их вместе:

*   Наведение на атрибут показывает флажок вместо его значка. Нажмите его, чтобы выбрать атрибут.
*   Альтернативно, удерживайте <kbd>Ctrl</kbd> (<kbd>Cmd</kbd> на macOS), щёлкая по атрибуту, чтобы выбрать его, или <kbd>Shift</kbd>, чтобы выбрать диапазон атрибутов. Диапазон может охватывать несколько разделов.
*   Как только выбран хотя бы один атрибут, каждый атрибут показывает свой флажок, и щелчок где угодно по атрибуту выбирает или снимает выбор вместо открытия всплывающего окна деталей.
*   Флажок _Выбрать все_ на панели инструментов выбирает каждый атрибут; пока атрибуты выбраны, он показывает, сколько. Повторный щелчок по нему снимает выбор, как и нажатие <kbd>Esc</kbd>.

Пока атрибуты выбраны, панель инструментов показывает:

*   Кнопку <span class="tn-icon bx bx-copy"></span>, которая копирует выбранные атрибуты.
*   Кнопку <span class="tn-icon bx bx-trash"></span>, которая удаляет выбранные атрибуты после подтверждения. Она появляется, только если все выбранные атрибуты принадлежат текущей заметке, так как наследуемые атрибуты можно удалить только из заметки, откуда они пришли.

Правый щелчок по атрибуту показывает меню с теми же действиями, а также вставкой. Если атрибут не является частью выбора, меню применяется только к этому атрибуту.

## Копирование и вставка атрибутов

Атрибуты можно копировать из одной заметки и вставлять в другую:

*   Чтобы скопировать, выберите атрибуты и нажмите <kbd>Ctrl</kbd>+<kbd>C</kbd> или используйте кнопку <span class="tn-icon bx bx-copy"></span> на панели инструментов или в контекстном меню.
*   Чтобы вставить, перейдите к заметке назначения и нажмите <kbd>Ctrl</kbd>+<kbd>V</kbd> после щелчка где угодно на вкладке атрибутов или используйте кнопку <span class="tn-icon bx bx-paste"></span> на панели инструментов. Правый щелчок по атрибуту или пустой области раздела также предлагает вставку.

Атрибуты копируются как текст в том же формате, что и редактор атрибутов (например, `#author=John ~template=#root/abc123 #tag(inheritable)`). В результате:

*   Скопированные атрибуты можно вставить в редактор атрибутов или в заметку, а текст редактора атрибутов можно вставить на вкладку атрибутов.
*   Атрибуты можно написать вручную в любом другом приложении, а затем вставить в Trilium.

При вставке атрибуты становятся собственными атрибутами текущей заметки, даже если они были наследуемыми в исходной заметке:

*   Если у заметки уже есть атрибут с тем же именем, его значение заменяется вставленным.
*   Если определение помечает атрибут как имеющий несколько значений (см. <a class="reference-link" href="../../../Advanced%20Usage/Attributes/Promoted%20Attributes.md">Продвигаемые атрибуты</a>), вставленное значение вместо этого добавляется рядом с существующими, если только такое же значение уже не присутствует.

> [!NOTE]
> <kbd>Ctrl</kbd>+<kbd>V</kbd> вставляет то, что держит буфер обмена системы, тогда как кнопка <span class="tn-icon bx bx-paste"></span> и контекстное меню вставляют атрибуты, скопированные последними в Trilium. Они различаются, если с тех пор было скопировано что-то ещё.

## Мобильные устройства

На мобильном атрибуты — это вкладка _Атрибуты_ панели заметки (см. <a class="reference-link" href="../Right%20Sidebar.md">Правая боковая панель</a>), которая открывается как шторка снизу экрана по кнопке <span class="tn-icon bx bx-dock-bottom"></span> рядом с <a class="reference-link" href="../Note%20menu.md">Меню заметки</a>. Выбор _Атрибуты_ в меню заметки, под _Обратные ссылки_ и _Пути заметки_, открывает панель на этой вкладке. Нажатие на атрибут открывает его на отдельной странице с кнопкой <span class="tn-icon bx bx-chevron-left"></span> для возврата к списку.

На мобильном [панель инструментов](#панель-инструментов) занимает место имени вкладки в заголовке шторки, и каждый раздел отображается как отдельная карточка:

*   Атрибуты добавляются с кнопки <span class="tn-icon bx bx-plus"></span> в заголовке или с кнопки <span class="tn-icon bx bx-plus"></span> над карточкой _Определения_.
*   Чтобы выбрать атрибут, нажмите и удерживайте его. Как только атрибут выбран, нажатие на другие атрибуты тоже выбирает их.
*   Копирование, вставка и удаление работают так же, как на десктопе, из заголовка.
