# Вкладка «Структура»
Вкладка «Структура» появляется в <a class="reference-link" href="../Right%20Sidebar.md">Правой боковой панели</a> и отображает заголовки и выделения для текущей заметки.

## Оглавление

Оглавление отображает заголовки текущей заметки и позволяет легко перемещаться по ним.

Поддерживаются следующие типы заметок:

*   <a class="reference-link" href="../../../Note%20Types/Text.md">Текст</a>
*   <a class="reference-link" href="../../../Note%20Types/Markdown.md">Markdown</a>
*   <a class="reference-link" href="../../../Note%20Types/File/PDFs.md">PDF</a>
*   Заметки-чаты <a class="reference-link" href="../../../AI.md">ИИ</a>
*   Страницы встроенной документации

<figure class="image image-style-align-right image_resized" style="width:47%;"><img style="aspect-ratio:556/205;" src="1_Outline tab_image.png" width="556" height="205"></figure>

### Взаимодействие

*   Щелчок по заголовку прокручивает документ к позиции заголовка.
*   По мере прокрутки документа заголовок, который читается, подсвечивается, а список прокручивается, чтобы держать его в виду. Если этот заголовок скрыт внутри свёрнутого раздела, вместо него подсвечивается свёрнутый заголовок.
*   Вложенные элементы можно свернуть, нажав соответствующую кнопку <span class="tn-icon bx bx-chevron-down"></span>.

## Выделения

<figure class="image image-style-align-right image_resized" style="width:46.04%;"><img style="aspect-ratio:489/240;" src="Outline tab_image.png" width="489" height="240"></figure>

Похоже на оглавление, но вместо заголовков эта возможность будет перечислять выделенный текст из текстовой заметки и позволять легко перемещаться к ним.

В отличие от оглавления, которое поддерживает несколько типов заметок, выделения специфичны для заметок <a class="reference-link" href="../../../Note%20Types/Text.md">Текст</a>.

Выделенным текстом считается:

*   Полужирный текст.
*   Курсивный текст.
*   Подчёркнутый текст.
*   Текст с заданным цветом переднего плана.
*   Текст с заданным цветом фона/выделением.

### Взаимодействие

*   Щелчок по выделенному тексту прокручивает документ к его позиции.

### Конфигурация

*   Глобально можно переключать отображение каждой категории выделенного текста (как определено выше)
    *   Нажатие кнопки с шестерёнкой в правой верхней части раздела раскроет меню для переключения между категориями выделения.
    *   Альтернативно, их можно изменить, перейдя в настройки <a class="reference-link" href="#root/_hidden/_options/_optionsTextNotes">Текстовых заметок</a> и найдя раздел _Список выделений_.

## Структура, специфичная для PDF

Когда <a class="reference-link" href="../../../Note%20Types/File/PDFs.md">PDF</a> открыты в Trilium, <a class="reference-link" href="../Right%20Sidebar.md">Правая боковая панель</a> дополняется навигацией, специфичной для PDF, со следующими возможностями:

*   Оглавление/структура
    *   Все заголовки и «закладки» будут отображены иерархически.
    *   Заголовок на текущей странице также подсвечивается (обратите внимание, что он может быть слегка смещён в зависимости от того, сколько заголовков на той же странице).
    *   Щелчок по заголовку перейдёт к соответствующей позиции в PDF.
*   Страницы
    *   Предпросмотр всех страниц с маленькой миниатюрой.
    *   Щелчок по странице автоматически перейдёт к этой странице.
    *   Правый щелчок по странице и выбор _Копировать ссылку_ копирует ссылку, открывающую PDF на этой странице.
*   Аннотации
    *   Аннотации выделения и комментария перечислены здесь.
    *   Правый щелчок по аннотации и выбор _Копировать ссылку_ копирует ссылку, открывающую PDF на этой аннотации.
*   Вложения
    *   Если у PDF есть собственные вложения (не путать с <a class="reference-link" href="../../Notes/Attachments.md">Вложениями</a> Trilium), они будут отображены списком.
    *   Отображается некоторая информация, такая как имя и размер вложения.
    *   Вложение можно скачать, нажав кнопку скачивания.
*   Слои
    *   Менее распространённая возможность: если у PDF есть переключаемые слои, эти слои будут отображены здесь списком.
    *   Можно переключать видимость каждого отдельного слоя.
