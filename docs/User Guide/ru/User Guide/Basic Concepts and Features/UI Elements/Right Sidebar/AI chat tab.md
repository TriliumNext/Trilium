# Вкладка «ИИ-чат»
После активации интеграции <a class="reference-link" href="../../../AI.md">ИИ</a> в <a class="reference-link" href="../Right%20Sidebar.md">Правой боковой панели</a> появится запись _Чат_.

*   В отличие от выделенного типа заметки, боковая панель имеет опциональный доступ к текущей заметке, что облегчает запрос информации или изменений заметки без необходимости сначала искать заметку.
    *   Чтобы переключить, видна ли текущая заметка ИИ, просто нажмите на значок файла внизу интерфейса чата.
*   В правом верхнем углу панели есть три кнопки:
    *   <span class="tn-icon bx bx-plus"></span> создаёт новый диалог.
    *   <span class="tn-icon bx bx-history"></span> переходит к предыдущему диалогу.
    *   <span class="tn-icon bx bx-dots-vertical-rounded"></span> открывает меню для переименования или удаления текущего диалога либо сохранения его как выделенной заметки в <a class="reference-link" href="../../../Advanced%20Usage/Advanced%20Showcases/Day%20Notes.md">Заметках дня</a>, что превращает его в выделенную заметку-чат.

> [!NOTE]
> Диалоги боковой панели хранятся в <a class="reference-link" href="../../../Advanced%20Usage/Hidden%20Notes.md">Скрытых заметках</a> и видны в разделе _История ИИ-чата_.

## Мобильные устройства

На мобильном чат — это вкладка _ИИ-чат_ панели заметки (см. <a class="reference-link" href="../Right%20Sidebar.md">Правая боковая панель</a>). Её кнопки находятся в заголовке шторки:

*   <span class="tn-icon bx bx-plus"></span> слева создаёт новый диалог.
*   Заголовок текущего диалога в центре перечисляет предыдущие диалоги при нажатии.
*   <span class="tn-icon bx bx-dots-vertical-rounded"></span> рядом с кнопкой закрытия открывает то же меню, что и на десктопе.
