# Панель запуска
## Положение панели запуска

На десктопе, в зависимости от выбранного расположения, панель запуска будет либо с левой стороны экрана с кнопками, отображёнными вертикально, либо вверху экрана. Подробнее см. <a class="reference-link" href="Vertical%20and%20horizontal%20layout.md">Вертикальное и горизонтальное расположение</a>.

На мобильных устройствах панель запуска всегда находится внизу.

Если элементов на панели запуска слишком много для экрана, она станет прокручиваемой.

## Терминология

*   **Элемент запуска**: кнопка, которая может быть (или есть) отображена на панели запуска.
*   **Доступный элемент запуска**: элемент запуска, не отображённый на панели запуска, но который можно добавить.
*   **Видимый элемент запуска**: элемент запуска, в данный момент отображённый на панели запуска.

## Настройка десктопной панели запуска

Есть два способа настроить панель запуска:

*   Щёлкните правой кнопкой по пустому месту между элементами запуска на панели запуска и выберите _Настроить панель запуска…_
*   Нажмите на <a class="reference-link" href="Global%20menu.md">Глобальное меню</a> и выберите _Настроить панель запуска_.

Это откроет новую вкладку с <a class="reference-link" href="Note%20Tree.md">Деревом заметок</a>, перечисляющим элементы запуска.

![](Launch%20Bar_image.jpg)

Разворачивание раздела _Доступные элементы запуска_ покажет список элементов запуска, не отображённых на панели запуска. _Видимые элементы запуска_ покажут те, что в данный момент отображены.

## Настройка мобильной панели запуска

Панель запуска на мобильных устройствах использует другую конфигурацию, чем десктопная. Причина в том, что не все десктопные значки доступны на мобильных, и меньше значков помещается на экран мобильного устройства.

Чтобы настроить панель запуска на мобильном, откройте <a class="reference-link" href="Global%20menu.md">Глобальное меню</a> и выберите _Настроить панель запуска_.

Чтобы настроить мобильную панель запуска, находясь на десктопе (особенно полезно для настройки более сложных элементов запуска, таких как скрипты или пользовательские виджеты), перейдите в <a class="reference-link" href="Global%20menu.md">Глобальное меню</a> → Дополнительно → Скрытые заметки и найдите раздел _Мобильная панель запуска_. Находясь в скрытом поддереве, также можно перетаскивать элементы запуска между разделами _Мобильная панель запуска_ и (Десктопная) _Панель запуска_.

### Добавление/удаление и изменение порядка элементов запуска

Чтобы отобразить новый элемент запуска на панели запуска, сначала найдите его в разделе _Доступные элементы запуска_. Затем щёлкните по нему правой кнопкой и выберите _Переместить в видимые элементы_. Также можно перетащить элемент вручную.

Аналогично, чтобы удалить его с панели запуска, просто найдите его в _Видимых элементах запуска_, затем щёлкните правой кнопкой и выберите _Переместить в доступные элементы_ или используйте перетаскивание.

Перетаскивайте элементы в дереве, чтобы изменить их порядок. Подробнее о вариантах взаимодействия, включая использование сочетаний клавиш, см. <a class="reference-link" href="Note%20Tree.md">Дерево заметок</a>.

### Добавление заметки перетаскиванием

Чтобы добавить заметку на панель запуска, перетащите её из <a class="reference-link" href="Note%20Tree.md">Дерева заметок</a> на панель запуска. Линия между элементами запуска показывает, где будет размещена заметка. Если панель запуска прокручиваема, удерживайте заметку возле любого конца, чтобы прокрутить её. Сброс заметки добавляет кнопку с заголовком и значком заметки, которая открывает заметку при щелчке.

*   Несколько заметок, выбранных в дереве, можно сбросить одновременно; они сохраняют свой порядок.
*   Заметка, которая уже на панели запуска, или элемент запуска, перетащенный из раздела _Доступные элементы запуска_, перемещается на новое место вместо добавления повторно.

Кнопка — клон заметки в разделе _Видимые элементы запуска_ (см. <a class="reference-link" href="../Notes/Cloning%20Notes.md">Клонирование заметок</a>), поэтому она всегда показывает текущий заголовок и значок заметки. Щёлкните по ней правой кнопкой и выберите _Убрать с панели запуска_, чтобы убрать клон; сама заметка остаётся на своём месте в дереве. Если панель запуска — единственное место, где находится заметка, она перемещается в _Доступные элементы запуска_, чтобы заметка не была удалена.

Чтобы перечислить потомков заметки вместо её открытия, щёлкните правой кнопкой по кнопке и отметьте _Показывать как папку_, так же как для [папки закладок](../Navigation/Bookmarks.md). Чтобы открыть заметку в новой вкладке, разделении, новом окне или во всплывающем окне быстрого редактирования вместо текущей вкладки, щёлкните правой кнопкой по кнопке и выберите место в пункте _Режим открытия_, как описано в [Закладках](../Navigation/Bookmarks.md).

## Настройка элемента запуска

*   Значок элемента запуска можно изменить так же, как обычную заметку. Подробнее см. [Значки заметок](../Notes/Note%20Icons%20%26%20Colors.md).
*   Заголовок элемента запуска также можно изменить.

### Сброс

Сброс позволяет восстановить исходную конфигурацию Trilium для панели запуска или её части. Просто щёлкните правой кнопкой по элементу запуска (или даже по целому разделу _Панель запуска_) и выберите _Сбросить_, чтобы вернуть его в исходное состояние.

### Создание новых элементов запуска / типы элементов запуска

Щёлкните правой кнопкой по разделу _Доступные элементы запуска_ или _Видимые элементы запуска_ и выберите одну из опций:

1.  **Элемент запуска заметки**
    Элемент запуска заметки просто переходит к указанной заметке.

    1.  Установите продвигаемый атрибут `target` на заметку, к которой нужно перейти.
    2.  Опционально задайте `hoistedNote`, чтобы поднять определённую заметку. Подробнее см. <a class="reference-link" href="../Navigation/Note%20Hoisting.md">Поднятие заметки</a>.
    3.  Опционально задайте `keyboardShortcut`, чтобы вызывать элемент запуска.
2.  **Элемент запуска скрипта**
    Продвинутый элемент запуска, который запускает скрипт при нажатии. Подробнее см. <a class="reference-link" href="../../Scripting.md">Скриптинг</a>.

    1.  Установите `script`, указывающий на нужный скрипт для запуска.
    2.  Опционально задайте `keyboardShortcut`, чтобы вызывать элемент запуска.
3.  **Пользовательский виджет**

    Позволяет определить пользовательский виджет для отображения внутри элемента запуска. Подробнее см. <a class="reference-link" href="../../Scripting/Frontend%20Basics/Custom%20Widgets/Widget%20Basics.md">Основы виджетов</a>.
4.  **Разделители**
    Элементы запуска, создающие некоторое расстояние между другими элементами запуска для лучшего визуального различения.

Элементы запуска настраиваются через предопределённые <a class="reference-link" href="../../Advanced%20Usage/Attributes/Promoted%20Attributes.md">Продвигаемые атрибуты</a>.
