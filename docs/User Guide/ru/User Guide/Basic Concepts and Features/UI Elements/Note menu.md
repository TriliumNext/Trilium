# Меню заметки
<figure class="image image-style-align-right image_resized" style="width:25.95%;"><img style="aspect-ratio:402/988;" src="Note menu_image.png" width="402" height="988"></figure>

Меню заметки содержит различные действия и настройки для текущей заметки. Его можно найти в области <a class="reference-link" href="Note%20buttons.md">Кнопок заметки</a> (справа от <a class="reference-link" href="../Notes/Title.md">Заголовка</a>).

Каждое разделение имеет собственное меню заметки, которое действует на заметку, отображённую в этом разделении. Записи, неприменимые к текущей заметке, всё равно перечислены, но серые, а записи, существующие только для некоторых заметок (описаны в _Специфичные записи заметки_), появляются только на этих заметках.

## Навигация по заметке

Эти записи — строка значков вверху меню, каждый с коротким заголовком. Наведение показывает его полное имя и его сочетание клавиш. В Быстром редактировании на телефоне, где осталась только функция _Найти_, она перечислена как обычная запись.

*   <span class="tn-icon bx bx-file-find"></span> _Найти_ открывает панель <a class="reference-link" href="../Navigation/Search%20in%20note.md">Поиск в заметке</a>, чтобы находить и заменять текст внутри текущей заметки. В десктопном приложении та же панель открывается с помощью <kbd>Ctrl</kbd>+<kbd>F</kbd>.
    *   Доступна на заметках <a class="reference-link" href="../../Note%20Types/Text.md">Текст</a>, <a class="reference-link" href="../../Note%20Types/Code.md">Код</a>, <a class="reference-link" href="../../Note%20Types/Mind%20Map.md">Mind Map</a> и <a class="reference-link" href="../../Note%20Types/Spreadsheets.md">Таблицы</a>, <a class="reference-link" href="../../Collections.md">Коллекциях</a>, PDF-файлах и любой заметке, отображённой как <a class="reference-link" href="../../Advanced%20Usage/Note%20source.md">Исходный код заметки</a>.
*   <span class="tn-icon bx bx-paperclip"></span> _Вложения_ переключает заметку на список её <a class="reference-link" href="../Notes/Attachments.md">Вложений</a>, где их можно загружать, открывать, скачивать, переименовывать или удалять.
*   <span class="tn-icon bx bxs-network-chart"></span> _Карта заметок_ открывает <a class="reference-link" href="Right%20Sidebar/Connections%20tab.md">Вкладку связей</a> <a class="reference-link" href="Right%20Sidebar.md">Правой боковой панели</a>, которая показывает <a class="reference-link" href="../../Advanced%20Usage/Note%20Map%20(Link%20map%2C%20Tree%20map).md">Карту заметок (Link map, Tree map)</a>, центрированную на текущей заметке.

## Свойства заметки

Переключатели в этом разделе вступают в силу немедленно:

*   <span class="tn-icon bx bx-share-alt"></span> _Опубликована_ публикует заметку через <a class="reference-link" href="../../Advanced%20Usage/Sharing.md">Публикацию</a>, клонируя её в дерево _Опубликованные заметки_.
    *   Выключение убирает клон из этого дерева. Если заметка существует только как опубликованная, Trilium запрашивает подтверждение, так как снятие публикации удаляет её.
    *   Переключатель недоступен на корневой заметке, на самой заметке _Опубликованные заметки_ и на системных заметках.
*   <span class="tn-icon bx bx-lock-alt"></span> _Защитить заметку_ шифрует заметку, превращая её в одну из <a class="reference-link" href="../Notes/Protected%20Notes.md">Защищённых заметок</a>. Если защищённая сессия не активна, Trilium сначала запрашивает пароль. Затрагивается только текущая заметка, а не её потомки.
*   <span class="tn-icon bx bx-bookmark"></span> _Закладка_ добавляет заметку в <a class="reference-link" href="../Navigation/Bookmarks.md">Закладки</a>, отображаемые в <a class="reference-link" href="Launch%20Bar.md">Панели запуска</a>, или удаляет её из них.
*   <span class="tn-icon bx bx-copy-alt"></span> _Шаблон_ помечает заметку как один из <a class="reference-link" href="../../Advanced%20Usage/Templates.md">Шаблонов</a> (добавляя метку `#template`), что делает её доступной при создании новой заметки.
*   <span class="tn-icon bx bx-expand-horizontal"></span> _Полная ширина_ позволяет заметке использовать всю ширину окна вместо предела, заданного в <a class="reference-link" href="Content%20width.md">Ширине содержимого</a>, добавляя метку `#fullContentWidth`. Не перечисляется для типов заметок, которые всегда отображаются в полную ширину.

Два подменю в этом разделе:

*   <span class="tn-icon bx bx-file"></span> _Тип заметки_ меняет тип заметки на любой из <a class="reference-link" href="../../Note%20Types.md">Типов заметок</a>; текущий отмечен. Если у заметки уже есть содержимое, Trilium сначала запрашивает подтверждение, так как содержимое обычно не переносится. <a class="reference-link" href="../../Note%20Types/Converting%20between%20note%20types.md">Преобразование между типами заметок</a>.
    *   Для заметки <a class="reference-link" href="../../Note%20Types/Code.md">Код</a> язык выбирается в <a class="reference-link" href="Status%20bar.md">Строке состояния</a>.
*   <span class="tn-icon bx bx-edit-alt"></span> _Редактируемость_ управляет тем, когда заметка открывается как доступная только для чтения (см. <a class="reference-link" href="../Notes/Read-Only%20Notes.md">Заметки только для чтения</a>):
    *   _Авто_ (по умолчанию): заметка редактируема, если она недостаточно длинна, чтобы открываться автоматически только для чтения.
    *   _Только для чтения_: заметка всегда открывается только для чтения, но её всё равно можно отредактировать после нажатия _Редактировать заметку_.
    *   _Всегда редактируема_: заметка всегда редактируема независимо от её длины.

## Импорт, экспорт и печать

*   <span class="tn-icon bx bx-import"></span> _Импортировать файлы_ открывает диалог импорта, который импортирует файлы как потомков текущей заметки. См. <a class="reference-link" href="../Import%20%26%20Export.md">Импорт и экспорт</a>. Недоступно на заметках <a class="reference-link" href="../../Note%20Types/Saved%20Search.md">Сохранённый поиск</a>.
*   <span class="tn-icon bx bx-export"></span> _Экспортировать заметку_ открывает диалог экспорта с выбранным _Только эта заметка_; выберите там _Эта заметка и все потомки_, чтобы экспортировать всё поддерево.
*   <span class="tn-icon bx bx-printer"></span>_Печать/экспорт в PDF…_ печатает заметку или сохраняет её как PDF-файл. См. <a class="reference-link" href="../Notes/Printing%20%26%20Exporting%20as%20PDF.md">Печать и экспорт в PDF</a>, включая то, какие типы заметок и коллекции можно печатать.

Некоторые типы заметок добавляют собственные форматы экспорта прямо под _Экспортировать заметку_:

*   <span class="tn-icon bx bxs-file-image"></span>_Экспортировать как изображение_ на заметках <a class="reference-link" href="../../Note%20Types/Mermaid%20Diagrams.md">Диаграммы Mermaid</a> и <a class="reference-link" href="../../Note%20Types/Mind%20Map.md">Mind Map</a> скачивает диаграмму как _PNG (растр)_ или _SVG (вектор)_.
*   <span class="tn-icon bx bxs-spreadsheet"></span>_Экспорт в Excel (.xlsx)_ и _Экспорт в CSV (.csv)_ на <a class="reference-link" href="../../Note%20Types/Spreadsheets.md">Таблицах</a> скачивают таблицу в этих форматах.

## Ревизии

Эти записи управляют <a class="reference-link" href="../Notes/Note%20Revisions.md">Ревизиями заметки</a>:

*   <span class="tn-icon bx bx-history"></span>_Ревизии заметки…_ открывает диалог ревизий, где предыдущие версии можно предпросматривать, сравнивать с текущей, скачивать или восстанавливать. Стрелка рядом с ним открывает записи, сохраняющие ревизию сразу. На мобильном нажатие на него открывает эти записи, с _Ревизии заметки…_ первой.
    *   <span class="tn-icon bx bx-save"></span>_Сохранить ревизию_ сохраняет ревизию заметки сразу, вместо ожидания следующего автоматического снимка.
    *   <span class="tn-icon bx bx-purchase-tag"></span>_Сохранить именованную ревизию…_ также сохраняет ревизию сразу, но сначала запрашивает короткое описание изменений, которое показывается в диалоге ревизий.

## Специфичные записи заметки

Следующие записи появляются только на некоторых заметках:

*   <span class="tn-icon bx bx-pencil"></span>_Редактировать заметку_ появляется вверху меню, когда заметка в данный момент доступна только для чтения. Включает редактирование до закрытия заметки.
*   <span class="tn-icon bx bx-align-justify"></span>_Перенос строк_ появляется вверху меню на заметках <a class="reference-link" href="../../Note%20Types/Code.md">Код</a> и задаёт, переносятся ли длинные строки в этой заметке:
    *   _Авто_ (по умолчанию) следует <a class="reference-link" href="Options.md">Настройкам</a> → _Заметки с кодом_ → _Переносить строки в заметках с кодом_.
    *   _Вкл_ и _Выкл_ переопределяют это только для этой заметки, задавая метку `#wrapLines`.
*   <span class="tn-icon bx bx-paperclip"></span>_Преобразовать во вложение_ появляется на заметке-изображении, у которой нет потомков и один родитель — заметка <a class="reference-link" href="../../Note%20Types/Text.md">Текст</a>. После подтверждения превращает изображение во вложение её родительской заметки и открывает его там. См. <a class="reference-link" href="../Notes/Attachments.md">Вложения</a>.
*   <span class="tn-icon bx bx-extension"></span>_Перендерить заметку_ появляется на <a class="reference-link" href="../../Note%20Types/Render%20Note.md">Render Note</a> и снова запускает её скрипт, чтобы обновить вывод.
*   <span class="tn-icon bx bx-cog"></span>_Свойства доски_ появляется на <a class="reference-link" href="../../Collections/Kanban%20Board.md">Kanban-доске</a> и настраивает её колонки, атрибуты карточек и шаблоны карточек.
*   <span class="tn-icon bx bx-cog"></span>_Свойства календаря_ появляется на <a class="reference-link" href="../../Collections/Calendar.md">Календаре</a>, создающем события, и настраивает его шаблоны событий.
*   <span class="tn-icon bx bx-cog"></span>_Свойства геокарты_ появляется на <a class="reference-link" href="../../Collections/Geo%20Map.md">Геокарте</a> и настраивает её параметры карты и изображение [карты-изображения](../../Collections/Geo%20Map/Image%20maps.md).
*   <span class="tn-icon bx bx-cog"></span>_Свойства таблицы_ появляется на <a class="reference-link" href="../../Collections/Table.md">Таблице</a> и настраивает, какие заметки она показывает.

## Дополнительно

Подменю <span class="tn-icon bx bx-wrench"></span>_Дополнительно_ группирует действия, которые нужны реже:

*   <span class="tn-icon bx bx-file-find"></span>_Открыть внешне_ (только десктопное приложение) сохраняет заметку во временный файл и открывает её в приложении, которое операционная система ассоциирует с ним. Trilium следит за файлом: каждый раз, когда он сохраняется, уведомление в окне, из которого он был открыт, предлагает загрузить изменённую версию обратно в заметку, сохраняя текущее содержимое как ревизию. Файл, который операционная система запустила бы как программу, такой как `.exe`, `.bat`, `.ps1` или `.lnk`, не открывается; _Открыть с помощью..._ всё равно может открыть его в выбранном вами приложении. Недоступно на <a class="reference-link" href="../../Collections.md">Коллекциях</a> и заметках <a class="reference-link" href="../../Note%20Types/Saved%20Search.md">Сохранённый поиск</a>.
*   <span class="tn-icon bx bx-customize"></span>_Открыть с помощью..._ (только десктопное приложение) работает как _Открыть внешне_, но позволяет выбрать приложение для открытия файла. См. [Открыть с помощью](#открыть-с-помощью) ниже.
*   <span class="tn-icon bx bx-code"></span>_Исходный код заметки_ показывает <a class="reference-link" href="../../Advanced%20Usage/Note%20source.md">Исходный код заметки</a> — содержимое заметки в точности как оно хранится.
*   <span class="tn-icon bx bxl-markdown"></span>_Преобразовать в Markdown-заметку_ (на текстовых заметках) и _Преобразовать в текстовую заметку_ (на Markdown-заметках) переключают заметку между форматированным текстом и Markdown. После подтверждения Trilium сохраняет ревизию и конвертирует содержимое; ревизия позволяет вернуться, если какое-то форматирование было потеряно. См. <a class="reference-link" href="../../Note%20Types/Converting%20between%20note%20types.md">Преобразование между типами заметок</a>.
*   <span class="tn-icon bx bx-collapse-alt"></span>_Сжать изображения_ открывает диалог, уменьшающий размер изображений в заметке. Он перечисляет найденные изображения и сколько места они занимают, и предлагает:
    *   Изменить размер изображений больше выбранного размера.
    *   Сохранить или сжать JPEG-изображения.
    *   Сохранить, оптимизировать или конвертировать в JPEG PNG-изображения.
    *   _Обработать также дочерние заметки_, чтобы включить изображения заметок под этой.

    Сжатие нельзя отменить. Изображения также можно сжимать автоматически при загрузке, см. <a class="reference-link" href="../../Note%20Types/Text/Images.md">Изображения</a>.
*   <span class="tn-icon bx bx-text"></span>_Просмотреть текст OCR_ (на заметках-изображениях и файлах) показывает текст, извлечённый из заметки через <a class="reference-link" href="../../Advanced%20Usage/Text%20Extraction%20(OCR).md">Извлечение текста (OCR)</a>. Если заметка ещё не была обработана, диалог предлагает _Обработать OCR_.
*   <span class="tn-icon bx bx-world"></span>_Открыть заметку на сервере_ (только десктопное приложение, перечислено когда настроена <a class="reference-link" href="../../Installation%20%26%20Setup/Synchronization.md">Синхронизация</a>) открывает ту же заметку на сервере синхронизации в веб-браузере.

## Открыть с помощью

<span class="tn-icon bx bx-customize"></span>_Открыть с помощью..._ в подменю _Дополнительно_ открывает заметку в выбранном вами приложении вместо того, которое операционная система ассоциирует с её типом. Как и с _Открыть внешне_, Trilium сохраняет заметку во временный файл, следит за ним и предлагает загрузить изменённую версию обратно в заметку. Запись доступна только в десктопном приложении; вложения предлагают то же действие.

*   В Windows системный диалог _Открыть с помощью_ перечисляет установленные приложения.
*   В Linux выбор приложения идёт через desktop portal (`xdg-desktop-portal`), поэтому работает и в Flatpak.
*   В версии из Flathub _Открыть внешне_ тоже идёт через desktop portal, который может показывать выбор приложения первые несколько раз, когда тип файла открывается, как решает политика системы; _Открыть с помощью..._ показывает его всегда.
*   В macOS открывается файловый выбор в папке _Applications_; заметка открывается в выбранном там приложении, как с _Открыть с помощью_ → _Другое…_ в Finder.

Если выбор приложения не может быть показан (например, когда ни один desktop portal не запущен в Linux), Trilium сообщает об ошибке вместо открытия файла. _Открыть внешне_ всё равно открывает его в приложении по умолчанию.

### Добавление приложения в выбор в Linux

Портал перечисляет только приложения, зарегистрированные для типа файла. Текстовые редакторы обычно регистрируются для простого текста, но не для HTML, поэтому их нет при открытии текстовой заметки, которая сохраняется как HTML-файл.

Чтобы редактор появился без смены приложения по умолчанию, добавьте его под `[Added Associations]` в `~/.config/mimeapps.list`, используя имя `.desktop`-файла редактора:

```toml
[Added Associations]
text/html=org.gnome.TextEditor.desktop;
```

Запись _Открыть с помощью другого приложения_ большинства файловых менеджеров добавляет ту же строку.

## Удаление заметки

<span class="tn-icon bx bx-trash"></span>_Удалить заметку_ открывает диалог удаления для текущей заметки и её поддерева. Диалог перечисляет заметки, которые будут удалены, и отношения, которые будут разорваны, и предлагает:

*   Также удалить другие клоны заметки, если она клонирована в другом месте. Иначе удаляется только текущее размещение, и заметка остаётся в других местах. См. <a class="reference-link" href="../Notes/Cloning%20Notes.md">Клонирование заметок</a>.
*   _Стереть навсегда_ вместо обычного мягкого удаления. Это нельзя отменить.

Заметки, удалённые без стирания, можно вернуть, см. <a class="reference-link" href="../Notes/Restoring%20Deleted%20Notes.md">Восстановление удалённых заметок</a>.

## Ограничения

*   Меню заметки недоступно на элементах запуска.
*   На заметках <a class="reference-link" href="Options.md">Настроек</a> и встроенной справки большинство записей серые, так как эти заметки нельзя импортировать, удалять или иметь ревизии. Из двух экспортировать можно только встроенную справку, см. <a class="reference-link" href="../Import%20%26%20Export.md">Импорт и экспорт</a>.
*   Раздел [Свойства заметки](#свойства-заметки) перечислен только когда отображается сама заметка, а не её <a class="reference-link" href="../Notes/Attachments.md">Вложения</a> или её <a class="reference-link" href="../../Advanced%20Usage/Note%20source.md">Исходный код заметки</a>.
*   В <a class="reference-link" href="../Navigation/Quick%20edit.md">Быстром редактировании</a> _Карта заметок_, _Полная ширина_ и _Преобразовать во вложение_ не перечислены.

## Поддержка мобильных устройств

В <a class="reference-link" href="../../Installation%20%26%20Setup/Mobile%20Frontend.md">мобильном интерфейсе</a> меню заметки открывается как шторка снизу экрана. Помимо записей выше, оно содержит элементы, которые десктопный макет размещает в других местах:

*   Два дополнительных значка в строке значков в самом верху шторки, которая читается слева направо как <span class="tn-icon bx bx-dock-right"></span> _Новое разделение_, _Карта заметок_, _Найти_ и <span class="tn-icon bx bx-plus"></span> _Дочерняя заметка_: _Новое разделение_ открывает <a class="reference-link" href="Split%20View.md">Разделённый вид</a>, пока его нет во вкладке, а _Дочерняя заметка_ создаёт заметку под текущей.
*   _Обратные ссылки_ и _Пути заметки_ под строкой значков, которые открывают <a class="reference-link" href="../../Note%20Types/Text/Links/Backlinks.md">Обратные ссылки</a> и другие местоположения заметки.
*   <span class="tn-icon bx bx-paperclip"></span> _Вложения_ и <span class="tn-icon bx bx-list-check"></span> _Атрибуты_ под ними, которые открывают вложения и атрибуты заметки, каждый с числом заметки. Ссылки, созданные содержимым заметки, не считаются атрибутами. _Атрибуты_ недоступны там, где заметку нельзя редактировать. На мобильном _Вложения_ перечислены здесь вместо строки значков.
*   Пользовательские кнопки типа заметки (такие как <span class="tn-icon bx bx-download"></span>_Скачать_ на заметке-<a class="reference-link" href="../../Note%20Types/File.md">Файле</a>).
*   _Закрыть эту панель_ на второй заметке <a class="reference-link" href="Split%20View.md">Разделённого вида</a>.
*   <span class="tn-icon bx bx-slider-alt"></span> _Настройки заметки_ под _Защитить заметку_, которая открывает _Опубликована_ и _Закладка_, затем _Тип заметки_, _Шаблон_ и _Полная ширина_ на отдельной странице, вместе с языком заметки: языком содержимого на заметках <a class="reference-link" href="../../Note%20Types/Text.md">Текст</a> (см. <a class="reference-link" href="../../Note%20Types/Text/Content%20language%20%26%20Right-to-left%20support.md">Язык содержимого и поддержка справа налево</a>) и языком кода на заметках <a class="reference-link" href="../../Note%20Types/Code.md">Код</a>. Варианты _Редактируемости_ перечислены в конце этой страницы под собственным заголовком вместо дальнейшего подменю.
*   <span class="tn-icon bx bx-info-circle"></span> _Сведения о заметке_ под _Настройки заметки_, которая открывает даты, тип, ID и размер заметки на отдельной странице, заканчивающейся _Показать похожие заметки_ (см. <a class="reference-link" href="../Navigation/Similar%20Notes.md">Похожие заметки</a>).
*   _Карта заметок_ открывает карту во всплывающем окне вместо правой боковой панели.
