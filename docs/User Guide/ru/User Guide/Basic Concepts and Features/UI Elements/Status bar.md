# Строка состояния
Строка состояния отображает информацию о текущей заметке и позволяет менять связанные с ней настройки, такие как настройка языка или атрибутов.

## Макет и взаимодействие

С левой стороны отображаются <a class="reference-link" href="Breadcrumb.md">«Хлебные крошки»</a>, указывающие текущую заметку, а также её родительские заметки, и позволяющие быстро перемещаться по иерархии.

С правой стороны отображаются специфичные разделы в зависимости от типа текущей заметки.

1.  Для заметок <a class="reference-link" href="../../Note%20Types/Code.md">Код</a> указывается языковой режим заметки (например, JavaScript, простой текст), а также позволяет легко переключиться на другой режим.
    1.  Перед ним показывается позиция курсора как строка и столбец, например _Ln: 12 Col: 32_. Она обновляется по мере перемещения курсора. Пока выделен текст, следует число выделенных символов, например _Выделено: 120_.
2.  Для заметок <a class="reference-link" href="../../Note%20Types/Text.md">Текст</a> отображается язык содержимого и может быть изменён, настраивая проверку орфографии и поддержку письма справа налево.
    1.  Обратите внимание, что это применяется ко всей заметке, а не к выделению, в отличие от некоторых текстовых редакторов.
    2.  Пока в настройках включён <a class="reference-link" href="../../Note%20Types/Text/Vim%20mode.md">Режим Vim</a>, значок _Vim_ включает или выключает его для заметки, за которым следует текущий режим Vim.
3.  Если заметка размещена в нескольких местах дерева (клонирована), отображается число путей заметки.
    1.  Щелчок по нему открывает всплывающее окно с полным списком путей заметки, откуда заметку также можно клонировать в новое место. Тот же список доступен на <a class="reference-link" href="Right%20Sidebar/Connections%20tab.md">Вкладке связей</a> боковой панели.
4.  Если у заметки есть вложения, отображается их число.
    1.  Щелчок по нему раскроет список вложений в новой вкладке.
5.  Если на заметку ссылаются из других текстовых заметок (обратные ссылки), отображается число обратных ссылок.
    1.  Щелчок по нему открывает всплывающее окно со списком заметок, ссылающихся на эту заметку, а также выдержкой из места, где на заметку ссылаются. Тот же список доступен на <a class="reference-link" href="Right%20Sidebar/Connections%20tab.md">Вкладке связей</a> боковой панели.

Независимо от типа заметки, следующие элементы всегда отображаются, если есть заметка:

1.  Сведения о заметке, отображающие:
    1.  Дату создания/изменения заметки.
    2.  Тип и MIME заметки.
    3.  ID заметки.
    4.  Оценку размера заметки и её потомков.
    5.  Кнопку, раскрывающую Похожие заметки на <a class="reference-link" href="Right%20Sidebar/Connections%20tab.md">Вкладке связей</a> боковой панели.

> [!NOTE]
> При нажатии кнопки, которая раскрывает <a class="reference-link" href="Right%20Sidebar.md">Правую боковую панель</a>, у неё особое поведение, если панель скрыта: панель будет подглянута вместо закрепления. В любом случае панель будет переключена на соответствующую вкладку, и соответствующий раздел будет подсвечен.
