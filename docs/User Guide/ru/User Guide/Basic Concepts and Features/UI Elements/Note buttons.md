# Кнопки заметки
Кнопки заметки — область в правом верхнем углу заметки с несколькими кнопками:

*   <a class="reference-link" href="Note%20menu.md">Меню заметки</a>, предлагающее команды для заметки или её поддерева, такие как импорт, экспорт, просмотр [Исходного кода заметки](../../Advanced%20Usage/Note%20source.md) или [Вложений](../Notes/Attachments.md).
*   Элементы управления <a class="reference-link" href="Split%20View.md">Разделённым видом</a>
    *   <span class="tn-icon bx bx-dock-right"></span>, чтобы открыть новое разделение
    *   <span class="tn-icon bx bx-chevron-right"></span>/<span class="tn-icon bx bx-chevron-left"></span>, чтобы переместить панель
    *   <span class="tn-icon bx bx-x"></span>, чтобы закрыть панель.
*   На некоторых типах заметок, таких как <a class="reference-link" href="../../Note%20Types/File.md">Файл</a> и изображения, есть выделенные кнопки (например, <span class="tn-icon bx bx-download"></span>, чтобы скачать файл локально).
