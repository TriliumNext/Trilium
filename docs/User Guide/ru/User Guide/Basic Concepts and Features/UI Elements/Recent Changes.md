## Доступ к последним изменениям

*   Для обзора изменений по всем документам нажмите кнопку <span class="tn-icon bx bx-history"></span> в <a class="reference-link" href="Launch%20Bar.md">Панели запуска</a>.
    *   Если есть [поднятая заметка](../Navigation/Note%20Hoisting.md) или [рабочая область](../Navigation/Workspaces.md), список последних изменений будет ограничен потомками поднятой заметки или рабочей области.
    *   Правый щелчок или нажатие и удерживание кнопки перечисляет до 15 недавно изменённых заметок, не открытых во вкладке. Выбор заметки открывает её в новой вкладке.
*   Чтобы ограничить список последних изменений заметкой и её потомками, найдите соответствующую опцию в <a class="reference-link" href="Note%20Tree/Note%20tree%20contextual%20menu.md">Контекстном меню дерева заметок</a> → Дополнительно.
*   Правый щелчок или нажатие и удерживание кнопки <span class="tn-icon bx bx-plus"></span> панели <a class="reference-link" href="Tabs.md">Вкладок</a> перечисляет недавно изменённые заметки, не открытые во вкладке. _Все последние изменения_ внизу этого меню открывают этот диалог.

## Взаимодействие

*   Изменённые заметки появляются в обратном хронологическом порядке (последнее обновление первым).
*   Отображается заголовок заметки, а также путь заметки. Щелчок по заголовку заметки закроет диалог и перейдёт к этой конкретной заметке.
*   Удалённые заметки также будут перечислены здесь по времени их удаления. Нажмите ссылку _Восстановить_ рядом с ними, чтобы вернуть их.
