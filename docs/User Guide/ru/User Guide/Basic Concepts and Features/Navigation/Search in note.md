# Поиск в заметке
<figure class="image image_resized" style="width:100%;"><img style="aspect-ratio:898/93;" src="Search in note_image.png" width="898" height="93"></figure>

Локальный поиск позволяет искать внутри отображаемой в данный момент заметки.

## Альтернативы

*   Нажатие <kbd>Ctrl</kbd>+<kbd>F</kbd> в браузере, когда фокус не находится в заметке <a class="reference-link" href="../../Note%20Types/Text.md">Текст</a> или <a class="reference-link" href="../../Note%20Types/Code.md">Код</a>, вызовет нативный поиск браузера. Он также найдёт текст, являющийся частью интерфейса Trilium.
*   Нажатие <kbd>Ctrl</kbd>+<kbd>F</kbd> в заметке <a class="reference-link" href="../../Note%20Types/Text.md">Текст</a> раскроет функциональность поиска <a class="reference-link" href="../../Advanced%20Usage/Technologies%20used/CKEditor.md">CKEditor</a>.

## Доступ к поиску

*   На десктопе нажмите <kbd>Ctrl</kbd> + <kbd>F</kbd>.
*   Из <a class="reference-link" href="../UI%20Elements/Note%20menu.md">Меню заметки</a> выберите _Найти_ в строке значков вверху.
*   В <a class="reference-link" href="Quick%20edit.md">Быстром редактировании</a> оба варианта открывают панель поиска внизу всплывающего окна для заметки во всплывающем окне.

## Взаимодействие

*   Поиск:
    *   Заполните поле _Найти в тексте…_ текстом для поиска.
    *   Поиск будет выполнен автоматически в фоне.
    *   Используйте стрелки вверх и вниз текстового поля для перемещения между результатами.
*   Замена:
    *   Заполните поле _Найти в тексте…_ текстом для замены.
    *   Заполните поле _Заменить на…_ текстом, на который нужно заменить.
    *   Нажмите _Заменить_, чтобы заменить только текущий результат.
    *   Нажмите _Заменить все_, чтобы заменить их все сразу.
*   Опции:
    *   _Учитывать регистр_ – поиск будет различать прописные и строчные символы (например, поиск «Hello» не совпадёт с `hello`).
    *   _Слова целиком_ - поиск будет находить только точные совпадения слов (например, поиск `Java` не совпадёт с `JavaScript`).

## Включённые заметки

В заметке <a class="reference-link" href="../../Note%20Types/Text.md">Текст</a> поиск также находит текст заметок, включённых через <a class="reference-link" href="../../Note%20Types/Text/Include%20Note.md">Включение заметки</a>, в порядке их появления в заметке.

*   Ищется текст включённых текстовых и кодовых заметок, встроенных файлов с кодом, таких как вложение `.js` или `.txt`, и холстов для рисования. Заголовок включения и содержимое других заметок, таких как коллекция или включённая заметка <a class="reference-link" href="../../Note%20Types/Canvas.md">Холст</a>, не ищутся.
*   Результат в холсте для рисования подсвечивается на рисунке. Холст перемещается только чтобы показать результат вне его вида, и возвращается обратно, как только поиск идёт дальше, если его не переместили за это время. В редактируемой заметке закрытие поиска на таком результате оставляет холст там и, пока холст редактируем, выделяет текст результата.
*   Стрелки вверх и вниз перемещаются по результатам включения как по остальной части заметки.
*   Результат в свёрнутом _Разворачиваемом_ включении разворачивает включение, пока этот результат текущий, и снова сворачивает его, как только поиск идёт дальше.
*   _Заменить_ и _Заменить все_ изменяют включённую заметку только пока её кнопка _Редактируемо_ включена. Пока текущий результат находится во включении, которое нельзя редактировать, _Заменить_ отключена, а _Заменить все_ оставляет такие результаты без изменений. Текст холста для рисования никогда не заменяется.
