# Концепции дерева
Эта страница объясняет основные концепции, связанные со структурой дерева заметок в TriliumNext.

## Заметка

Заметка — центральная сущность в TriliumNext. Подробнее см. <a class="reference-link" href="../Notes.md">Заметки</a>.

## Ветвь

Ветвь описывает размещение заметки в дереве заметок. По сути, это кортеж из `parentNoteId` и `noteId`, указывающий, что данная заметка размещена как дочерняя под указанной родительской заметкой.

Каждая заметка может иметь несколько ветвей, то есть любая заметка может быть размещена в нескольких местах дерева. Эта концепция называется <a class="reference-link" href="../Notes/Cloning%20Notes.md">Клонированием заметок</a>.

## Префикс

Префикс — специфичный для ветви модификатор заголовка заметки. Если вы размещаете свою заметку в двух разных местах дерева и хотите немного изменить заголовок в одном из этих размещений, вы можете использовать префикс.

Чтобы отредактировать префикс, щёлкните правой кнопкой по заметке в панели дерева и выберите _Редактировать префикс ветви_.

Префикс не является частью самой заметки и не шифруется, когда заметка защищена. Это может быть полезно, если вы хотите, чтобы часть заголовка оставалась видимой в дереве для облегчения навигации, даже когда заметка защищена.

## Поддерево

Поддерево состоит из конкретной заметки (корня поддерева) и всех её дочерних заметок и потомков. Некоторые операции, такие как экспорт, работают со всеми поддеревьями.
