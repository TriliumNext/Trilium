# Быстрый поиск
<figure class="image image-style-align-center"><img style="aspect-ratio:659/256;" src="Quick search_image.png" width="659" height="256"></figure>

Функция _Быстрый поиск_ выполняет полнотекстовый поиск (то есть ищет по содержимому заметок, а не только по заголовку заметки) и отображает результат в удобной форме.

Альтернативой быстрому поиску является функция <a class="reference-link" href="Search.md">Поиск</a>, которая открывается в специальной вкладке и поддерживает расширенные запросы.

Для ещё более быстрой навигации можно использовать <a class="reference-link" href="Jump%20to%20%26%20command%20palette.md">«Переход к» и палитру команд</a>, которые ищут только по заголовкам заметок, а не по содержимому.

## Расположение

В зависимости от <a class="reference-link" href="../UI%20Elements/Vertical%20and%20horizontal%20layout.md">Вертикального и горизонтального расположения</a> быстрый поиск размещён:

*   При вертикальном расположении он отображается прямо над <a class="reference-link" href="../UI%20Elements/Note%20Tree.md">Деревом заметок</a>.
*   При горизонтальном расположении он отображается в <a class="reference-link" href="../UI%20Elements/Launch%20Bar.md">Панели запуска</a>, где его можно расположить как любой другой значок.

## Возможности поиска

Быстрый поиск включает следующие возможности:

### Предпросмотры содержимого

Результаты поиска теперь показывают предпросмотр содержимого заметки из 200 символов под заголовком заметки. Этот предпросмотр показывает контекст, в котором встречаются ваши поисковые термины, облегчая опознание нужной заметки без её открытия.

### Все результаты в одном списке

Быстрый поиск перечисляет до 200 совпадающих заметок в одном прокручиваемом списке, так что полоса прокрутки показывает, сколько результатов и как далеко по ним вы прошли.

### Продолжение в полном поиске

Чтобы уточнить запрос опциями полного <a class="reference-link" href="Search.md">Поиска</a>, нажмите _Показать в полном поиске_ под результатами или нажмите <kbd>Ctrl</kbd>+<kbd>Enter</kbd> в поле поиска. Полный поиск открывается в новой вкладке с тем же запросом. Кнопка остаётся под списком, как бы далеко ни были прокручены результаты.

### Визуальные возможности

*   **Подсветка**: Поисковые термины показаны полужирным с акцентными цветами
*   **Разделение**: Результаты разделены разделителями
*   **Поддержка тем**: Цвета подсветки адаптируются к светлым/тёмным темам

### Поведение поиска

Быстрый поиск использует прогрессивный поиск:

1.  Показывает точные совпадения первыми
2.  Включает нечёткие совпадения, когда точных результатов меньше 5
3.  Точные совпадения показываются перед нечёткими

### Область поиска

Быстрый поиск покрывает только поддерево, в котором вы сейчас работаете:

*   Без хостинга он покрывает всё дерево заметок.
*   Под [поднятой заметкой](Note%20Hoisting.md) или внутри [рабочей области](Workspaces.md) он покрывает только это поддерево.
*   Заметки, существующие только в скрытом дереве, такие как встроенные страницы справки и настройка панели запуска, не возвращаются. Поднимитесь в справку, чтобы искать по ней, или используйте [«Переход к…»](Jump%20to%20%26%20command%20palette.md), который ищет по заголовкам во всём скрытом дереве.

Чтобы искать по всей базе данных под хостингом, используйте полный <a class="reference-link" href="Search.md">Поиск</a> и оставьте поле _Предок_ пустым.

### Навигация с клавиатуры

*   Нажмите <kbd>Enter</kbd> в поле поиска, чтобы искать или обновить уже показанные результаты.
*   Нажмите <kbd>↓</kbd> в поле поиска, чтобы перейти к первому результату, затем <kbd>↑</kbd> и <kbd>↓</kbd> для перемещения между результатами. <kbd>↑</kbd> на первом результате возвращает в поле поиска.
*   Нажмите <kbd>Page Down</kbd> и <kbd>Page Up</kbd>, чтобы перемещаться по результатам по странице за раз.
*   Нажмите <kbd>Enter</kbd> на результате, чтобы открыть его.
*   Нажмите <kbd>Ctrl</kbd>+<kbd>Enter</kbd>, чтобы открыть запрос в полном поиске.
*   Нажмите <kbd>Escape</kbd>, чтобы закрыть результаты.

Чтобы увидеть эти сочетания на экране, нажмите кнопку <kbd>?</kbd> под результатами или нажмите <kbd>Alt</kbd>+<kbd>F1</kbd>, пока поле поиска в фокусе.

## Использование быстрого поиска

1.  **Толерантность к опечаткам**: Поиск находит результаты несмотря на мелкие опечатки
2.  **Предпросмотры содержимого**: Фрагменты по 200 символов показывают контекст совпадения
3.  **Конкретные термины**: Конкретные поисковые термины возвращают более сфокусированные результаты
4.  **Места совпадений**: Полужирный текст показывает, где происходят совпадения

## Быстрый поиск — оператор точного совпадения

Быстрый поиск разделяет тот же поисковый движок, что и полный <a class="reference-link" href="Search.md">Поиск</a>, поэтому оператор точного совпадения (`=`) ведёт себя одинаково в обоих. Начните запрос с `=` (без пробела после него), чтобы переключиться с поведения «содержит» по умолчанию на точное совпадение целого слова или фразы.

**Что на самом деле делает `=`:** он находит заметки, где заголовок или содержимое содержат ваш термин как **целое слово или фразу**, игнорируя окружающую пунктуацию. Он **не** требует, чтобы вся заметка была равна вашему термину, и он **не** выполняет поиск подстроки или нечёткое совпадение.

| Запрос | Пример содержимого заметки | Совпадает? | Почему |
| --- | --- | --- | --- |
| `sync` | `synchronize the database now` | Да | поиск по умолчанию совпадает с подстрокой |
| `=sync` | `see (sync) mode` | Да | `=` совпадает с целым словом `sync`, пунктуация игнорируется |
| `=sync` | `synchronize the database now` | Нет | `=` никогда не совпадает с подстроками |
| `="project plan"` | `the (project plan) is ready to share` | Да | заключите многословную фразу в кавычки, чтобы совпасть с ней точно |

Поиск нечувствителен к регистру и диакритике. Полное объяснение трёх режимов сопоставления, нечётких операторов и ранжирования по релевантности см. в [Как поиск сопоставляет ваш текст](Search.md) в документации полного поиска.

### Ограничения

*   Оператор `=` должен находиться в самом начале поискового запроса.
*   Пробел сразу после `=` трактуется как обычный поиск.
*   Несколько операторов `=` (например, `==example`) трактуются как обычный текстовый поиск.

### Связанные возможности

*   Для запросов по атрибутам, свойствам, булевым значениям и порядку используйте полную функциональность [Поиска](Search.md).
*   Для нечёткого сопоставления (поиска результатов несмотря на опечатки) используйте операторы `~=` или `~*` в полном поиске.
*   Для частичных совпадений с подстановочными знаками используйте в полном поиске операторы вроде `*=*`, `=*` или `*=`.
