## Переход к заметке

Функция _Переход к заметке_ позволяет легко перемещаться между заметками, ища их по заголовку. Кроме того, она может запускать полный поиск или создавать заметки.

Чтобы открыть диалог «Переход к»:

*   На <a class="reference-link" href="../UI%20Elements/Launch%20Bar.md">Панели запуска</a> нажмите кнопку <span class="tn-icon bx bx-send"></span>.
*   С клавиатуры нажмите <kbd>Ctrl</kbd> + <kbd>J</kbd>.

Помимо поиска заметок, также можно искать команды. Подробнее см. выделенный раздел ниже.

### Взаимодействие

*   По умолчанию, когда текст не введён, отображаются последние заметки.
*   С клавиатуры используйте стрелки вверх или вниз для перемещения между элементами. Нажмите <kbd>Enter</kbd>, чтобы открыть нужную заметку.
*   Если заметки не существует, её можно создать, введя нужный заголовок заметки и выбрав один из двух вариантов:
    *   _Создать заметку_ помещает её во <a class="reference-link" href="../Notes/Note%20Inbox.md">Входящие заметки</a>: заметку с меткой `#inbox`, сегодняшнюю <a class="reference-link" href="../../Advanced%20Usage/Advanced%20Showcases/Day%20Notes.md">Заметку дня</a>, если входящих нет, или верхний уровень, если нет и журнала. При поднятии в <a class="reference-link" href="Workspaces.md">Рабочую область</a> используются собственные входящие рабочей области, затем сегодняшняя заметка дня, если у рабочей области есть `#workspaceCalendarRoot`, иначе корень рабочей области. Опция называет место назначения, поэтому оно всегда видно перед созданием заметки.
    *   _Создать дочернюю заметку_ помещает её под открытую в данный момент заметку.
*   Когда поиск по заголовку не находит заметку, строка под результатами предлагает два способа поиска дальше. Она остаётся под списком, как бы далеко ни были прокручены результаты. Обе скрыты, пока поле пусто или перечисляет команды.
    *   Переключатель _Включить содержимое заметок_ ищет содержимое заметок наряду с их заголовками и перечисляет находки вместо текущих результатов, не покидая диалог. Он остаётся включённым при изменении запроса, пока не будет выключен. Нажмите <kbd>Shift</kbd>+<kbd>Enter</kbd>, чтобы переключить его с клавиатуры.
    *   _Показать в полном поиске_ открывает запрос в полном <a class="reference-link" href="Search.md">Поиске</a> в новой вкладке, где его опции могут уточнить его. Нажмите <kbd>Ctrl</kbd>+<kbd>Enter</kbd>, чтобы выполнить его с клавиатуры.
*   Чтобы увидеть клавиши, на которые отвечают результаты, нажмите кнопку <kbd>?</kbd> под результатами или нажмите <kbd>Alt</kbd>+<kbd>F1</kbd>, пока поле поиска в фокусе.
*   При достаточно широком десктопном окне заметка, подсвеченная в результатах, предпросматривается справа от них: её путь, заголовок, атрибуты и начало содержимого. Предпросмотр следует за подсветкой при перемещении по результатам и опускается для палитры команд.
*   Опции создания заметки перечислены после заметок. Когда ни одна заметка не совпадает, список сообщает об этом над ними. <kbd>Enter</kbd> открывает наилучшую совпавшую заметку или создаёт заметку, когда ни одна не совпадает. Иначе нажмите <kbd>↑</kbd> от первой заметки, чтобы добраться до опций создания заметки.

## Недавние заметки

«Переход к заметке» также умеет показывать список недавно просмотренных / отредактированных заметок и быстро переходить к ним.

Чтобы получить доступ к этой функциональности, нажмите кнопку «Переход к» вверху. По умолчанию (когда в автодополнение ничего не введено) этот диалог покажет список недавних заметок.

Недавние заметки сгруппированы по времени последнего посещения: _Сегодня_, _Вчера_, _Последние 7 дней_, _Последние 30 дней_ и _Старше_. Другие поля заметок, такие как в диалоге _Переместить в_, показывают тот же список, когда пусты: нажмите кнопку <span class="tn-icon bx bx-chevron-down"></span> в конце поля или <kbd>↓</kbd>. Ввод как минимум двух символов вместо этого перечисляет совпадающие заметки.

## Палитра команд

<figure class="image image-style-align-center"><img style="aspect-ratio:982/524;" src="Jump to &amp; command palette_image.png" width="982" height="524"></figure>

Палитра команд — это возможность, позволяющая легко выполнять различные команды, которые можно найти по всему приложению, например в меню или сочетаниях клавиш. Эта возможность напрямую интегрирована в диалог «Переход к».

### Взаимодействие

Чтобы вызвать палитру команд:

*   Нажмите <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>J</kbd>, чтобы показать палитру команд напрямую.
*   Если вы в диалоге «Переход к», введите `>` в поиске, чтобы переключиться на палитру команд.

Взаимодействие:

*   Введите несколько слов, чтобы отфильтровать команды.
*   Используйте стрелки вверх и вниз на клавиатуре или мышь, чтобы выбрать команду.
*   Нажмите <kbd>Enter</kbd>, чтобы выполнить команду.

Чтобы выйти из палитры команд:

*   Удалите `>` в поиске, чтобы вернуться к поиску заметок.
*   Нажмите <kbd>Esc</kbd>, чтобы закрыть диалог целиком.

### Доступные опции

В настоящее время отображаются следующие опции:

*   Большинство <a class="reference-link" href="../Keyboard%20Shortcuts.md">Сочетаний клавиш</a> имеют запись, за исключением тех, что слишком специфичны для запуска из диалога.
*   Некоторые дополнительные опции, которые пока недоступны как сочетания клавиш, но доступны из различных меню, такие как: экспорт заметки, показ вложений, поиск заметок или настройка <a class="reference-link" href="../UI%20Elements/Launch%20Bar.md">Панели запуска</a>.

### Ограничения

В настоящее время невозможно определять пользовательские действия, отображаемые в палитре команд. В будущем это может измениться за счёт интеграции опций в панель запуска, которую можно настроить при необходимости.
