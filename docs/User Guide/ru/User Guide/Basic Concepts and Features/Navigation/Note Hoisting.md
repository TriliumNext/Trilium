# Поднятие заметки (Note Hoisting)
Хостинг (поднятие) — стандартная возможность аутлайнеров, позволяющая сфокусироваться (или «приблизиться») к конкретной заметке и её поддереву, скрыв все родительские и соседние заметки. Демонстрация:

![](Note%20Hoisting_note-hoisting.gif)

Помимо показа только этого поддерева, это также сужает и полнотекстовый поиск, и [«переход к заметке»](Note%20Navigation.md) до заметок, присутствующих в поднятом поддереве.

## Показ всех заметок снова

Пока заметка поднята, десктопный интерфейс показывает кнопку _Показать все заметки_ со значком <span class="tn-icon bx bx-arrow-back"></span> над <a class="reference-link" href="../UI%20Elements/Note%20Tree.md">Деревом заметок</a>. Нажмите её, чтобы снять хостинг и снова увидеть всё дерево.

На телефоне кнопка «назад» на верхнем уровне поднятого дерева превращается в кнопку <span class="tn-icon bx bx-exit"></span>, за которой следует заголовок поднятой заметки. Нажмите её, чтобы снять хостинг заметки; дерево затем показывает уровень, содержащий поднятую заметку, как ещё один шаг вверх.

См. также [Рабочую область](Workspaces.md), которая расширяет эту возможность.
