# Навигация по заметкам
Одна из целей Trilium — обеспечить быструю и удобную навигацию между заметками.

## Назад и вперёд

Чтобы перемещаться назад и вперёд по истории просмотренных заметок, нажимайте <kbd>Alt</kbd>+<kbd>←</kbd> и <kbd>Alt</kbd>+<kbd>→</kbd> или используйте кнопки <span class="tn-icon bx bx-left-arrow-alt"></span> и <span class="tn-icon bx bx-right-arrow-alt"></span> слева от <a class="reference-link" href="../UI%20Elements/Tabs.md">Вкладок</a>.

Это работает так же, как «назад / вперёд» в браузере — на самом деле используется встроенная поддержка браузера для этого.

Чтобы перейти сразу на несколько заметок назад или вперёд, щёлкните правой кнопкой по одной из кнопок или нажмите и удерживайте её. Кнопка «назад» перечисляет заметки перед текущей, а кнопка «вперёд» — заметки после неё, ближайшие первыми. Каждая запись показывает заголовок заметки с путём её родительских заметок в конце строки. Выбор заметки переходит сразу к ней.

Элементы запуска _Перейти к предыдущей заметке_ и _Перейти к следующей заметке_ на <a class="reference-link" href="../UI%20Elements/Launch%20Bar.md">Панели запуска</a> перечисляют те же заметки под собственными элементами панели запуска.

## Переход к заметке

Это полезно для быстрого поиска и просмотра произвольных заметок — нажмите кнопку «Переход к» вверху или нажмите <kbd>Ctrl</kbd> + <kbd>J</kbd>. Затем введите часть названия заметки, и автодополнение поможет выбрать нужную заметку.

Подробнее см. <a class="reference-link" href="Jump%20to%20%26%20command%20palette.md">Переход к заметке</a>.
