# Быстрое редактирование
<figure class="image image-style-align-right image_resized" style="width:53.13%;"><img style="aspect-ratio:895/694;" src="Quick edit_image.png" width="895" height="694"></figure>

_Быстрое редактирование_ предоставляет альтернативу стандартной навигации и редактированию на основе вкладок.

Вместо щелчка по заметке, который переключает <a class="reference-link" href="../UI%20Elements/Note%20Tree.md">Дерево заметок</a> на вновь выбранную заметку, или навигации между двумя разными <a class="reference-link" href="../UI%20Elements/Tabs.md">Вкладками</a>, возможность _Быстрое редактирование_ открывается как всплывающее окно, которое легко закрыть.

Эта возможность также хорошо интегрирована с <a class="reference-link" href="../../Collections.md">Коллекциями</a>, такими как вид календаря, что облегчает редактирование записей без необходимости ходить туда-сюда между дочерней заметкой и календарём.

## Основные возможности

*   Поддерживаются все типы заметок, включая <a class="reference-link" href="../../Collections.md">Коллекции</a>.
*   Обратите внимание, что <a class="reference-link" href="../Notes/Note%20List.md">Список заметок</a> не будет отображаться, кроме заметок типа <a class="reference-link" href="../../Collections.md">Коллекции</a>.
*   Для заметок <a class="reference-link" href="../../Note%20Types/Text.md">Текст</a>, в зависимости от предпочтений пользователя, поддерживаются как плавающий, так и классический редакторы. См. <a class="reference-link" href="../../Note%20Types/Text/Formatting%20toolbar.md">Панель форматирования</a>.
*   Заголовок, заметка и значок редактируемы, как в обычной вкладке.
*   Действия заметки и её меню показаны в заголовке всплывающего окна, как в строке заголовка вкладки.
    *   Когда другие заметки ссылаются на заметку, кнопка со значком ссылки перечисляет <a class="reference-link" href="../../Note%20Types/Text/Links/Backlinks.md">Обратные ссылки</a>. Нажатие на одну открывает эту заметку во всплывающем окне.
    *   Пункты меню, которые работают только во вкладке, не показываются: _Карта заметок_, _Полная ширина_ и _Преобразовать во вложение_.
    *   _Найти_ в меню или <kbd>Ctrl</kbd>+<kbd>F</kbd> в десктопном приложении открывает панель <a class="reference-link" href="Search%20in%20note.md">Поиск в заметке</a> внизу всплывающего окна. Она ищет заметку во всплывающем окне, а не заметку во вкладке позади него.
    *   Страница справки, открытая из всплывающего окна, например через кнопку справки типа заметки, открывается во втором всплывающем окне поверх него. Закрытие этого всплывающего окна возвращает к редактируемой заметке.
*   <a class="reference-link" href="../../Advanced%20Usage/Attributes/Promoted%20Attributes.md">Продвигаемые атрибуты</a> также отображаются.
    *   Это хорошо сочетается с <a class="reference-link" href="../../Collections.md">Коллекциями</a>, где есть предопределённые атрибуты, такие как _Дата начала_ и _Дата окончания_, позволяющие легко редактировать их.

## Доступ к быстрому редактированию

*   Из <a class="reference-link" href="../UI%20Elements/Note%20Tree.md">Дерева заметок</a>:
    *   Щёлкните правой кнопкой по заметке и выберите _Быстрое редактирование_.
    *   или нажмите <kbd>Ctrl</kbd>+<kbd>Правый щелчок</kbd> по заметке.
*   По <a class="reference-link" href="../../Note%20Types/Text/Links/Internal%20(reference)%20links.md">внутренним (ссылочным) ссылкам</a>:
    *   Щёлкните правой кнопкой и выберите _Быстрое редактирование_.
    *   или нажмите <kbd>Ctrl</kbd>+<kbd>Правый щелчок</kbd> по ссылке.
*   На <a class="reference-link" href="../UI%20Elements/Note%20Tooltip.md">Подсказке заметки</a> нажмите значок быстрого редактирования.
*   В <a class="reference-link" href="../../Collections.md">Коллекциях</a>:
    *   Для <a class="reference-link" href="../../Collections/Calendar.md">Календаря</a>:
        *   Щелчок по событию откроет это событие для быстрого редактирования.
        *   Если календарь относится к корню <a class="reference-link" href="../../Advanced%20Usage/Advanced%20Showcases/Day%20Notes.md">Заметок дня</a>, щелчок по номеру дня откроет всплывающее окно для заметки этого дня.
    *   Для <a class="reference-link" href="../../Collections/Geo%20Map.md">Геокарты</a>:
        *   Щелчок по маркеру откроет этот маркер, но только если карта в режиме только для чтения.

## Обработка заметок только для чтения

Возможность «Быстрое редактирование» имеет особое поведение для <a class="reference-link" href="../Notes/Read-Only%20Notes.md">заметок только для чтения</a>:

*   Если заметка доступна только для чтения по причинам производительности (автоматический режим только для чтения), то заметка делается редактируемой для быстрого редактирования.
*   Если заметка вручную установлена в режим только для чтения, то заметка остаётся только для чтения, чтобы предотвратить случайное изменение.
    *   В этом случае заметку всё равно можно отредактировать по инструкциям на экране.

## Поддержка мобильных устройств

На телефоне всплывающее окно использует всю ширину экрана, а содержимое заметки сохраняет те же боковые поля, что и заметка <a class="reference-link" href="../../Note%20Types/Text.md">Текст</a>. <a class="reference-link" href="../../Note%20Types/Text/Formatting%20toolbar.md">Панель форматирования</a> текстовой заметки находится внизу диалога, под заметкой; её выпадающие списки открываются вверх, чтобы клавиатура их не закрывала.
