# Закладки
Часто используемые заметки можно добавить в закладки, что сделает их видимыми в <a class="reference-link" href="../UI%20Elements/Launch%20Bar.md">Панели запуска</a> для лёгкого доступа.

## Настройка панели запуска

Если закладки не появляются на панели запуска, то, скорее всего, раздел закладок был скрыт. Перейдите к настройке <a class="reference-link" href="../UI%20Elements/Launch%20Bar.md">Панели запуска</a> из <a class="reference-link" href="../UI%20Elements/Global%20menu.md">Глобального меню</a> и убедитесь, что _Закладки_ находятся в разделе _Видимые элементы запуска_.

## Папка закладок

Место на левой панели ограничено, а в закладки можно добавить много элементов. Одно из возможных решений — добавить в закладки папку, чтобы она показывала своих потомков:

Для этого добавьте в закладки папку, затем щёлкните правой кнопкой по её кнопке на <a class="reference-link" href="../UI%20Elements/Launch%20Bar.md">Панели запуска</a> и отметьте _Показывать как папку_. Кнопка затем открывает меню вместо самой заметки: заметка находится вверху, за ней следуют её потомки. Снимите отметку _Показывать как папку_, чтобы вернуть её к обычной закладке.

Потомок, у которого есть собственные потомки, показывает стрелку в конце своей строки. Нажмите стрелку, чтобы перечислить его потомков в подменю, или нажмите остальную часть строки, чтобы открыть заметку. Подменю вкладываются до четырёх уровней глубины. Меню, перечисляющее более 15 потомков, показывает над ними поле фильтра: введите часть заголовка, чтобы перечислить только совпадающие заметки. Заметка, чьё поддерево скрыто (см. <a class="reference-link" href="../UI%20Elements/Note%20Tree/Hiding%20the%20subtree.md">Скрытие поддерева</a>), не перечисляет своих потомков и здесь.

Заметки в меню открываются так же, как ссылки: средний щелчок или <kbd>Ctrl</kbd>+щелчок открывает заметку в новой вкладке, <kbd>Shift</kbd>+щелчок открывает её в новом окне, а правый щелчок перечисляет другие места, где её можно открыть.

_Показывать как папку_ присваивает заметке метку `#bookmarkFolder`, поэтому добавление метки вручную тоже работает. Поскольку метка принадлежит заметке, заметка, которая одновременно добавлена в закладки и перетащена на панель запуска, показывает своих потомков в обоих местах.

## Выбор места открытия закладки

Закладка открывает свою заметку в текущей вкладке. Чтобы открыть её в другом месте, щёлкните правой кнопкой по её кнопке на <a class="reference-link" href="../UI%20Elements/Launch%20Bar.md">Панели запуска</a> и выберите место в пункте _Режим открытия_. Действующее место отмечено.

| _Режим открытия_ | Значение метки | Где открывается заметка |
| --- | --- | --- |
| _Текущая вкладка_ | `currentTab` | В текущей вкладке. Это значение по умолчанию. |
| _Новая вкладка_ | `newTab` | В новой вкладке после текущей (см. <a class="reference-link" href="../UI%20Elements/Tabs.md">Вкладки</a>). |
| _Новое разделение_ | `newSplit` | В новом разделении рядом с текущей заметкой (см. <a class="reference-link" href="../UI%20Elements/Split%20View.md">Разделённый вид</a>). |
| _Новое окно_ | `newWindow` | В новом окне. |
| _Быстрое редактирование_ | `quickEdit` | Во всплывающем окне над текущей заметкой (см. <a class="reference-link" href="Quick%20edit.md">Быстрое редактирование</a>). |

_Режим открытия_ задаёт на заметке метку `#bookmarkOpenMode`, поэтому добавление метки вручную тоже работает. Метка работает так же для заметки, перетащенной на панель запуска, и для заметок в меню папки закладок. На папке _Режим открытия_ делает метку наследуемой, поэтому каждая заметка в меню папки и её подменю ему следует, включая собственную заметку папки (см. <a class="reference-link" href="../../Advanced%20Usage/Attributes/Attribute%20Inheritance.md">Наследование атрибутов</a>). Заметка в папке всё равно может иметь собственное значение, например `currentTab`, добавленное вручную.

Режим открытия применяется только к обычному щелчку. Средний щелчок или <kbd>Ctrl</kbd>+щелчок по-прежнему открывает заметку в новой вкладке, а <kbd>Shift</kbd>+щелчок по заметке в меню папки по-прежнему открывает её в новом окне.

## Мобильные устройства

На мобильных устройствах закладки отображаются только начиная с v0.102.0. Из-за более ограниченного размера экрана закладки сгруппированы под одним значком вместо отображения их отдельными значками.

При нажатии появится меню со списком всех закладок. Папки закладок также поддерживаются и будут отображаться как подменю. Каждое подменю начинается с собственной заметки, поэтому заметку с потомками можно и открыть, и просмотреть.

На телефоне закладки также перечислены вверху <a class="reference-link" href="../UI%20Elements/Note%20Tree.md">Дерева заметок</a>, пока оно показывает корень вкладки, которая не поднята, ниже <a class="reference-link" href="Workspaces.md">Рабочих областей</a>. Нажмите закладку, чтобы открыть её, или, для закладки с потомками, чтобы перечислить их, как и для других заметок дерева.
