# Похожие заметки
<figure class="image image-style-align-right image_resized" style="width:50.46%;"><img style="aspect-ratio:538/290;" src="Similar Notes_image.png" width="538" height="290"></figure>

Возможность «Похожие заметки» пытается опознать заметки, относящиеся к текущей заметке, глядя на содержимое заметок, их отношения, а также дату их создания.

Чтобы получить доступ к списку похожих заметок:

*   Откройте <a class="reference-link" href="../UI%20Elements/Right%20Sidebar/Connections%20tab.md">Вкладку связей</a> в <a class="reference-link" href="../UI%20Elements/Right%20Sidebar.md">Правой боковой панели</a> и найдите соответствующий раздел.
*   Альтернативно, нажмите <span class="tn-icon bx bx-info-circle"></span> в <a class="reference-link" href="../UI%20Elements/Status%20bar.md">Строке состояния</a> и выберите _Показать похожие заметки_, что откроет панель внизу.
*   В <a class="reference-link" href="../../Installation%20%26%20Setup/Mobile%20Frontend.md">мобильном интерфейсе</a> откройте <a class="reference-link" href="../UI%20Elements/Note%20menu.md">Меню заметки</a> → _Сведения о заметке_ и выберите _Показать похожие заметки_.

## Взаимодействие

*   Наведите курсор на заметку, чтобы увидеть короткий предпросмотр заметки.
*   Щёлкните по заметке, чтобы открыть её в текущем виде.
*   <kbd>Ctrl</kbd> + щелчок по заметке, чтобы открыть её в отдельной вкладке.
