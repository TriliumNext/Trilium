# Архивные заметки
Архивные заметки — это заметки, имеющие [атрибут](../../Advanced%20Usage/Attributes.md) `archived` — либо напрямую, либо [унаследованный](../../Advanced%20Usage/Attributes/Attribute%20Inheritance.md).

Такие заметки затем по умолчанию не показываются в автодополнении и в полнотекстовом [поиске](../Navigation/Search.md).

Это может быть полезно для заметок, которые больше не очень нужны, но всё ещё достаточно ценны, чтобы сохранить их, не мешая слишком сильно.
