# Входящие заметки
Входящие — место назначения по умолчанию для быстро захваченных заметок. Когда заметка создаётся без предварительного выбора местоположения, она попадает во входящие. Это облегчает быстрый захват заметок и их рассортировку позже.

## Где используются входящие

*   Кнопка _Новая заметка_ в <a class="reference-link" href="../UI%20Elements/Launch%20Bar.md">Панели запуска</a>.
*   Глобальное сочетание клавиш _Создать заметку во входящих_ (по умолчанию <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>P</kbd>).
*   Действие _Новая заметка_ в [меню значка в трее](../../Installation%20%26%20Setup/Desktop%20Installation/Tray%20icon%20%26%20automatic%20startup.md).
*   Расширение <a class="reference-link" href="../../Installation%20%26%20Setup/Web%20Clipper.md">Web Clipper</a>.
*   Опция _Создать заметку_, предлагаемая, когда поиск не находит совпадений, в <a class="reference-link" href="../Navigation/Jump%20to%20%26%20command%20palette.md">«Переход к» и палитре команд</a>, в пустой вкладке и в дополнении `@` текстовой заметки.

## Настройка входящих заметок

Чтобы создать входящие заметки, примените к ним [метку](../../Advanced%20Usage/Attributes/Labels.md) `#inbox`.

Только одна заметка должна нести эту метку. Если таких заметок несколько, приложение будет использовать только одну.

> [!NOTE]
> Если заметки входящих нет, Trilium откатится к сегодняшней [заметке дня](../../Advanced%20Usage/Advanced%20Showcases/Day%20Notes.md), создавая её и её календарных предков по мере необходимости. Если журнал был полностью удалён, заметка создаётся на верхнем уровне вместо построения для неё нового журнала.

## Входящие рабочих областей

Каждая [рабочая область](../Navigation/Workspaces.md) может иметь собственные входящие, заданные через метку `#workspaceInbox`.

Когда новая заметка создаётся под хостингом в рабочей области, местоположение определяется в следующем порядке:

*   Заметка с меткой `#workspaceInbox` в этой рабочей области.
*   Заметка с меткой `#inbox` внутри этой рабочей области.
*   Сегодняшняя [заметка дня](../../Advanced%20Usage/Advanced%20Showcases/Day%20Notes.md), если у рабочей области есть `#workspaceCalendarRoot`.
*   Сама корневая заметка рабочей области.
