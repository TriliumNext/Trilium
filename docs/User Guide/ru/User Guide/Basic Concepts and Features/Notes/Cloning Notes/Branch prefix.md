# Префикс ветви
Поскольку одна заметка может появляться в нескольких местах <a class="reference-link" href="../../UI%20Elements/Note%20Tree.md">Дерева заметок</a> через процесс, называемый <a class="reference-link" href="../Cloning%20Notes.md">Клонированием заметок</a>, рекомендуется выбирать обобщённое имя, подходящее ко всем местам, вместо чего-то более специфичного, чтобы избежать путаницы.

В некоторых случаях это невозможно, поэтому Trilium предоставляет «префиксы ветвей», которые показываются перед именем заметки в дереве и таким образом дают определённый вид контекста.

Префикс специфичен для местоположения, поэтому отображается только в дереве заметок.
