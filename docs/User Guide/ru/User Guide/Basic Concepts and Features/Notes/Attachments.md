# Вложения
[Заметка](../Notes.md) в Trilium может _владеть_ одним или несколькими вложениями, которые могут быть как изображениями, так и файлами. Эти вложения могут отображаться или связываться ссылками внутри заметки, которая ими владеет.

Это может быть особенно полезно для включения зависимостей ваших [скриптов](../../Scripting.md). <a class="reference-link" href="../../Advanced%20Usage/Advanced%20Showcases/Weight%20Tracker.md">Трекер веса</a> показывает, как использовать [chartjs](https://chartjs.org/), который прикреплён к скриптовой заметке.

Каждая заметка исключительно владеет своими вложениями, то есть вложения не могут разделяться или связываться ссылками из одной заметки в другую. Если ссылка на вложение скопирована в другую заметку, само вложение дублируется, и копии управляются независимо впоследствии.

Вложения, особенно файлы изображений, — рекомендуемый способ встраивания визуала в заметки. Важно связывать вложения изображений внутри текста владеющей заметки; иначе они будут автоматически удалены по истечении настраиваемого таймаута, если на них нет ссылок.

## Типы вложений

Есть два разных типа вложений:

*   _Пользовательское содержимое_, представляющее файлы или изображения, которые загружены и являются частью содержимого заметки.
*   _Системные вложения_, используемые внутренне Trilium и могущие быть множественных типов, включая:
    *   <a class="reference-link" href="../../Collections.md">Коллекции</a> для хранения информации о видах, такой как информация о колонках для <a class="reference-link" href="../../Collections/Kanban%20Board.md">Kanban-доски</a>.
    *   Значки и обложки для <a class="reference-link" href="../../Note%20Types/Text/Link%20Previews.md">Превью ссылок</a>.
    *   Отладочная информация для некоторых импортёров, таких как <a class="reference-link" href="../Import%20%26%20Export/Importing%20data%20from%20other%20applications/Microsoft%20OneNote.md">Microsoft OneNote</a> (только если флаг отладки был включён во время импорта).
    *   Транскрипт <a class="reference-link" href="../../Meeting%20transcription.md">Транскрипции встречи</a>, который также показывается над содержимым заметки.
    *   SVG-картинка заметки <a class="reference-link" href="../../Note%20Types/Canvas.md">Холст</a> (`canvas-export.svg`) и каждого холста для рисования в текстовой заметке (см. _Холсты для рисования_ в <a class="reference-link" href="../../Note%20Types/Text/Include%20Note.md">Включении заметки</a>), используемая для превью и опубликованных страниц.

Системные вложения отображаются в конце списка вложений, в выделенном разделе (_Сгенерировано Trilium_).

## Загрузка вложений

Пункт <span class="tn-icon bx bx-paperclip"></span>_Вложения_ <a class="reference-link" href="../UI%20Elements/Note%20menu.md">Меню заметки</a> открывает список вложений заметки.

*   Чтобы загрузить файлы как вложения, нажмите _Загрузить вложения_ вверху списка и выберите один или несколько файлов.
*   Альтернативно, перетащите один или несколько файлов из проводника и уроните их куда угодно на список. Картинки сжимаются, если _Автоматическое сжатие изображений_ включено в <a class="reference-link" href="../UI%20Elements/Options.md">Настройках</a> → _Медиа_.

## Прикрепление файлов из текстовой заметки

Чтобы прикрепить файлы к заметке <a class="reference-link" href="../../Note%20Types/Text.md">Текст</a> и встроить их в её содержимое, нажмите кнопку <span class="tn-icon cke cke-paper-clip"></span>_Прикрепить файл_ в <a class="reference-link" href="../../Note%20Types/Text/Formatting%20toolbar.md">Панели форматирования</a>, выберите _Прикрепить и встроить файл_ и выберите один или несколько файлов (см. _Встраивание вложения_ ниже). То же меню предлагает _Изображение_, которое вставляет картинки (см. <a class="reference-link" href="../../Note%20Types/Text/Images.md">Изображения</a>), и _Прикрепить файл как ссылку_, которое связывает файлы вместо этого. Оба файловых действия также доступны как _Прикрепить файл как ссылку_ и _Прикрепить и встроить файл_ в <a class="reference-link" href="../../Note%20Types/Text/Slash%20Commands.md">Слэш-командах</a>. На телефоне меню также предлагает _Камеру_ (см. <a class="reference-link" href="../../Installation%20%26%20Setup/Mobile%20Frontend.md">Мобильный интерфейс</a>).

Когда файлы прикреплены как ссылки:

*   Каждый файл становится вложением заметки, и ссылка на него вставляется в позицию курсора. Несколько файлов дают несколько ссылок, разделённых пробелом.
*   Пока файл загружается, его ссылка показывает имя файла, а всплывающее уведомление показывает прогресс.
*   Картинки появляются как ссылки, а не изображения, и прикрепляются именно как есть, без сжатия. Чтобы отобразить картинку в тексте, используйте вместо этого _Изображение_ в том же меню (см. <a class="reference-link" href="../../Note%20Types/Text/Images.md">Изображения</a>).

Перетаскивание файла, не являющегося картинкой, из проводника на текст также прикрепляет его и вставляет ссылку на него.

## Действия над ссылкой на вложение

Правый щелчок по ссылке на вложение показывает способы открыть её, а затем действия над вложением: открытие его внешне, скачивание, загрузка новой ревизии, переименование или удаление и преобразование в заметку. В редактируемой текстовой заметке те же записи находятся в меню <span class="tn-icon cke cke-three-vertical-dots"></span> _Дополнительные действия_ всплывающего окна ссылки, которое открывает правый щелчок по ссылке. Во всплывающем окне также есть кнопка <span class="tn-icon cke cke-trilium-download"></span> _Скачать_.

Ссылки следуют за изменениями их вложения: его переименование обновляет показываемый ими заголовок, а его удаление убирает их из открытых для редактирования текстовых заметок в тот момент. Преобразование его в заметку превращает его ссылки в ссылки на новую заметку.

## Встраивание вложения

Вложение может отображаться в тексте вместо того, чтобы связываться ссылкой, так же, как <a class="reference-link" href="../../Note%20Types/Text/Include%20Note.md">Включение заметки</a> показывает заметку: картинка отображается, PDF, видео или документ предпросматриваются, кодовый или текстовый файл показывается с подсветкой синтаксиса, а Markdown-файл, такой как `.md`, показывается отрендеренным. Встроенный кодовый файл также можно редактировать на месте (см. _Редактирование включения на месте_ в <a class="reference-link" href="../../Note%20Types/Text/Include%20Note.md">Включении заметки</a>), а встроенный Markdown-файл показывает его исходник, его рендеринг или оба, как это делает включённая Markdown-заметка (см. _Включённый Markdown_ там).

*   Чтобы прикрепить файлы и сразу встроить их, нажмите кнопку <span class="tn-icon cke cke-paper-clip"></span>_Прикрепить файл_ и выберите _Прикрепить и встроить файл_. Каждый файл получает своё встраивание, которое показывает имя файла, пока файл загружается.
*   Чтобы встроить уже связанное вложение, щёлкните правой кнопкой по ссылке на него в редактируемой текстовой заметке и выберите _Преобразовать ссылку во встраивание_ ближе к концу меню.
*   Холст для рисования, вставленный через <span class="tn-icon bx bx-pen"></span>_Холст для рисования_ в меню <span class="tn-icon cke cke-plus"></span>_Вставка_, — это встраивание вложения `Canvas.excalidraw`, на котором можно рисовать на месте. Прикреплённый Excalidraw-файл (`.excalidraw`) также встраивается как холст для рисования (см. _Холсты для рисования_ в <a class="reference-link" href="../../Note%20Types/Text/Include%20Note.md">Включении заметки</a>).
*   Встраивание получает размер блока, подходящий вложению, как новая включённая заметка (см. _Размеры блоков_ там). Чтобы изменить его размер, выберите встраивание и используйте меню размера блока на его панели инструментов или подменю _Размер_ его меню <span class="tn-icon bx bx-dots-vertical-rounded"></span>_Дополнительные действия_. _Изменяемое_ встраивание также можно изменять перетаскиванием его ручек, а _Разворачиваемое_ — по высоте (см. _Изменение размера_ там). _Изменяемое_ встраивание можно разместить слева или справа от заметки, с текстом рядом или без, из подменю _Положение_ его меню (см. _Позиционирование_ там).
*   Встраивание может иметь подпись, как может включённая заметка (см. _Подпись_ там).
*   Чтобы показать только вложение, выключите _Показывать заголовок_ в меню <span class="tn-icon bx bx-dots-vertical-rounded"></span>_Дополнительные действия_ встраивания, как для включённой заметки (см. _Заголовок_ там).
*   Чтобы открыть вложение в новой вкладке, нажмите кнопку <span class="tn-icon bx bx-link-external"></span> (_Открыть в новой вкладке_) в конце заголовка встраивания.
*   Встраивание размера _Компактный_ показывает только заголовок вложения и его размер в одной строке, что бы ни было вложение: холст для рисования или видео не показывают там ничего из своего содержимого. Его кнопки — <span class="tn-icon bx bx-file-find"></span>_Открыть внешне_ и <span class="tn-icon bx bx-download"></span>_Скачать_. Аудиофайл в _Компактном_ размере — это строка элементов управления плеером, без заголовка, пока _Показывать заголовок_ не включён.
*   Чтобы показать встраивание размера _Изменяемый_ или _Полный_ на весь экран, нажмите кнопку <span class="tn-icon bx bx-fullscreen"></span> (_Во весь экран_) в конце его заголовка. Чтобы вернуться, нажмите <span class="tn-icon bx bx-exit"></span> (_Выйти из полноэкранного режима_) в правом верхнем углу или <kbd>Esc</kbd>.
*   Чтобы превратить встраивание обратно в ссылку, выберите _Преобразовать в ссылку_ в меню, которое открывает правый щелчок по строке заголовка встраивания или нажатие его кнопки <span class="tn-icon bx bx-dots-vertical-rounded"></span>_Дополнительные действия_. Оно находится в последней группе, после <span class="tn-icon bx bx-trash"></span>_Удалить блок_, который убирает встраивание из заметки, и <span class="tn-icon bx bx-trash"></span>_Удалить вложение…_, который удаляет само вложение. За ним следует <span class="tn-icon bx bx-note"></span>_Преобразовать вложение в заметку…_.

Встраивание следует за своим вложением, как ссылка. Преобразование вложения в заметку превращает встраивание во включённую заметку. В [опубликованной заметке](../../Advanced%20Usage/Sharing.md) встроенная картинка отображается со своей подписью, холст для рисования — как картинка рисунка, видео- или аудиофайл — в плеере браузера, а любое другое вложение или картинка во встраивании _Компактный_ появляется как ссылка для скачивания.

## Преобразование заметок во вложения

Заметки-<a class="reference-link" href="../../Note%20Types/File.md">Файлы</a> можно легко преобразовать во вложения родительской заметки.

Для этого:

*   Для одной заметки нажмите контекстное меню из <a class="reference-link" href="../UI%20Elements/Note%20menu.md">Меню заметки</a> и выберите _Преобразовать во вложение_.
*   Для нескольких заметок выберите данные заметки в <a class="reference-link" href="../UI%20Elements/Note%20Tree.md">Дереве заметок</a>, правый щелчок → Дополнительно → _Преобразовать во вложение…_.

## Предпросмотры вложений

Вложения разделяют тот же предпросмотр содержимого для изображений, видео, PDF и т.д., что и тип заметок <a class="reference-link" href="../../Note%20Types/File.md">Файл</a>. Markdown-вложение предпросматривается отрендеренным, как заметка <a class="reference-link" href="../../Note%20Types/Markdown.md">Markdown</a>.
