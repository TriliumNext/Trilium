# Значки заметки
Значки заметки появляются рядом с фиксированным заголовком заметки и указывают важную информацию о заметке, такую как доступна ли она только для чтения. Некоторые значки также интерактивны.

<figure class="image"><img style="aspect-ratio:910/49;" src="Note badges_image.png" width="910" height="49"></figure>

Доступны следующие значки:

*   <span class="tn-icon bx bx-lock-alt"></span> **Значок «только для чтения»**, который показывается, если заметка не редактируема из-за автоматического режима только для чтения или ручного режима только для чтения. Щелчок по значку временно отредактирует заметку. На страницах встроенного руководства пользователя, которые нельзя редактировать, значок ничего не делает при щелчке.
*   <span class="tn-icon bx bx-share-alt"></span> **Значок публикации**, который указывает, что текущая заметка опубликована. Значок также указывает, является ли публикация в локальной сети (для десктопного приложения без настроенной <a class="reference-link" href="../../Installation%20%26%20Setup/Synchronization.md">Синхронизации</a>) или публично доступной (для сервера).
*   <span class="tn-icon bx bx-globe"></span> **Значок веб-клипа**, который указывает, была ли заметка вырезана с помощью <a class="reference-link" href="../../Installation%20%26%20Setup/Web%20Clipper.md">Web Clipper</a>. Значок действует как ссылка, поэтому по нему можно щёлкнуть, чтобы перейти на страницу, или щёлкнуть правой кнопкой для дополнительных опций. Когда клипер также сохранил описание страницы, её автора или даты публикации и последнего обновления, щелчок по значку показывает эти детали, со ссылкой на страницу вверху.
*   <span class="tn-icon bx bx-play"></span> **Значок выполнения**, для [скриптов](../../Scripting.md) или [сохранённых SQL-запросов](../../Advanced%20Usage/Database/Manually%20altering%20the%20database/SQL%20Console.md), имеющих кнопку выполнения или описание.
*   <span class="tn-icon bx bx-copy-alt"></span> **Значок шаблона**, для <a class="reference-link" href="../../Advanced%20Usage/Templates.md">Шаблонов</a> (включая шаблоны рабочих областей, для которых значок читает _Шаблон рабочей области_). Заметки, созданные из шаблона, наследуют его атрибуты, поэтому значок напоминает, что их изменение влияет на каждую такую заметку. Щелчок по значку переключает шаблон между предложением везде и только при хостинге в его рабочую область, последнее — только для шаблона внутри рабочей области (см. <a class="reference-link" href="../Navigation/Workspaces.md">Рабочие области</a>). Он также открывает _Свойства шаблона…_, где задаются заголовок и местоположение новых заметок по умолчанию.
*   Для <a class="reference-link" href="../Active%20content.md">Активного содержимого</a> (например, скриптов, стилей) показывается выделенный значок, указывающий тип заметки и с опцией легко включать или отключать её.
