# Переключатель типа новой заметки
Когда создаётся пустая заметка <a class="reference-link" href="../../Note%20Types/Text.md">Текст</a>, под <a class="reference-link" href="Title.md">Заголовком</a>, вверху содержимого появляется переключатель типа заметки. С компактным заголовком заметки (см. <a class="reference-link" href="Title.md">Заголовок</a>) он появляется внизу заметки. Помимо изменения типа заметки, также можно применить [шаблон](../../Advanced%20Usage/Templates.md):

*   <span class="tn-icon bx bxl-markdown"></span> _Markdown_ и <span class="tn-icon bx bx-pen"></span> _Холст_ переключают заметку на этот тип одним щелчком.
*   <span class="tn-icon bx bx-code"></span> _Код_ перечисляет скриптовые заметки (_Пользовательский CSS_, _Виджет_ и _Серверный скрипт_), затем включённые языки кода.
*   <span class="tn-icon bx bx-book"></span> _Коллекция_ и <span class="tn-icon bx bx-copy-alt"></span>_Шаблон_ перечисляют коллекции и шаблоны.
*   <span class="tn-icon bx bx-dots-vertical-rounded"></span> _Все типы_ отображает то же меню, что _Вставить заметку после_ в <a class="reference-link" href="../UI%20Elements/Note%20Tree/Note%20tree%20contextual%20menu.md">Контекстном меню дерева заметок</a>, со всеми типами заметок и шаблонами.

Ввод текста, пока открыто меню <span class="tn-icon bx bx-code"></span> _Код_, <span class="tn-icon bx bx-copy-alt"></span> _Шаблон_ или <span class="tn-icon bx bx-dots-vertical-rounded"></span> _Все типы_, сужает его до совпадающих записей.

Переключатель исчезает, как только введён текст.
