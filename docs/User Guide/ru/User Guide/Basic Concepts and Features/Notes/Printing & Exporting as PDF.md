# Печать и экспорт в PDF
<figure class="image"><img style="aspect-ratio:2023/1488;" src="Printing &amp; Exporting as PDF_image.png" width="2023" height="1488"><figcaption>Снимок экрана функциональности предпросмотра печати, представленной в v0.103.0.</figcaption></figure>

Trilium позволяет печатать заметки на настоящий принтер или генерировать структурированный PDF для одной заметки или для нескольких заметок через <a class="reference-link" href="../../Collections.md">Коллекции</a>.

Обратите внимание, что не все типы заметок в настоящее время можно распечатать. Мы планируем расширить покрытие поддерживаемых типов заметок в будущем.

Печать и экспорт в PDF не идеальны. Из-за технических ограничений, а иногда даже глюков браузера или Electron текст может в некоторых случаях отображаться обрезанным.

## Печать заметки или экспорт в PDF на десктопе

> [!NOTE]
> Версии до v0.103.0 имели два разных варианта: один для печати и другой для экспорта в PDF. С появлением предпросмотра печати эти функции были объединены.

В десктопном приложении Trilium возможно экспортировать заметку в PDF. Чтобы распечатать заметку:

*   Нажмите кнопку меню в <a class="reference-link" href="../UI%20Elements/Note%20menu.md">Меню заметки</a> и выберите _Печать/экспорт в PDF…_.
*   Альтернативно, печать можно вызвать через [сочетание клавиш](../Keyboard%20Shortcuts.md) (не назначено по умолчанию) или через [палитру команд](../Navigation/Jump%20to%20%26%20command%20palette.md).

Затем откроется экран предпросмотра печати.

### Предпросмотр печати и опции печати

Диалог предпросмотра печати позволяет настроить следующие опции печати:

*   Используемый принтер
    *   _Сохранить как PDF_ генерирует структурированный PDF (сохраняет оглавление, текст остаётся выделяемым). Предпочитайте его другим виртуальным PDF-принтерам, поставляемым с операционной системой.
*   Ориентация страницы: _Портретная_ (по умолчанию) или _Альбомная_.
*   Размер страницы
*   Масштабирование всего содержимого от 10% до 200% для улучшения вписывания в страницу.
*   Поля, которые можно полностью убрать или настроить по отдельности для всех четырёх краёв.
*   Печать только подмножества страниц. Отдельные номера страниц разделяются двоеточиями, поддерживаются диапазоны через дефис (например, 3-5 для страниц с 3 по 5).

Дополнительное взаимодействие:

*   _Печать через системный диалог_ позволяет задать больше опций, которые иначе недоступны в Trilium.

Если заметку нельзя отрендерить с текущими опциями или она перестаёт продвигаться в течение 30 секунд, предпросмотр заменяется сообщением об ошибке. Настройте опции, чтобы попробовать снова.

> [!NOTE]
> Большинство опций здесь (кроме принтера и того, какие страницы печатать) управляются на уровне заметки через <a class="reference-link" href="../../Advanced%20Usage/Attributes.md">Атрибуты</a> (такие как `#printLandscape`, `#printPageSize`, `#printScale`, `#printMargins`).
>
> Это означает, что настройки печати будут восстановлены при печати той же заметки. Нет настроек по умолчанию, которые можно было бы настроить для всех заметок, но это можно достичь через [наследуемые атрибуты](../../Advanced%20Usage/Attributes/Attribute%20Inheritance.md).

## Печать в браузере

Эта возможность позволяет печатать заметки. Она работает как в десктопном клиенте, так и в веб-версии.

Чтобы распечатать заметку, нажмите <a class="reference-link" href="../UI%20Elements/Note%20menu.md">Меню заметки</a> и выберите _Печать/экспорт в PDF…_. В зависимости от размера и типа заметки это может занять до нескольких секунд. После этого вы будете перенаправлены в системный/браузерный диалог печати.

На сервере или PWA (мобильном) опция недоступна из-за технических ограничений и будет скрыта.

## Сообщение о проблемах с рендерингом

Если вы столкнётесь с любыми визуальными проблемами в итоговом PDF-файле (например, таблица некорректно вписывается, текст обрезан и т.д.), не стесняйтесь [сообщить о проблеме](../../Troubleshooting/Reporting%20issues.md). В этом случае лучше предложить образец заметки (нажмите кнопку <span class="tn-icon cke cke-three-vertical-dots"></span>, выберите _Экспортировать заметку_ → _Эта заметка и все её потомки_ → _HTML в ZIP-архиве_). Следите, чтобы случайно не раскрыть личную информацию.

Рассмотрите настройку размеров шрифтов и использование [разрывов страниц](../../Note%20Types/Text/Insert%20buttons.md) для обхода проблемы с макетом.

> [!TIP]
> Хотя прямой экспорт в PDF недоступен в браузерной версии приложения, всё же можно сгенерировать PDF, выбрав вместо этого опцию _Печать_ и выбрав «Сохранить в PDF» в качестве принтера (в зависимости от браузера). Как правило, у Mozilla Firefox лучше возможности печати.

### Автоматическое открытие файла

Когда PDF экспортирован, он автоматически открывается в приложении по умолчанию системы для лёгкого предпросмотра.

Обратите внимание, что если вы используете Linux с окружением рабочего стола GNOME, иногда приложение по умолчанию может показаться некорректным (например, открытие в GIMP). Это связано с тем, что оно использует список «Рекомендуемых приложений» Gnome.

Чтобы решить это, вы можете сменить рекомендуемое приложение для PDF через командную строку. Сначала перечислите доступные приложения через `gio mime application/pdf`, а затем установите нужное. Например, чтобы использовать Evince от GNOME:

```
gio mime application/pdf
```

## Печать нескольких заметок

Начиная с v0.100.0, возможно печатать более одной заметки за раз с помощью <a class="reference-link" href="../../Collections.md">Коллекций</a>:

1.  Сначала создайте коллекцию.
2.  Настройте её на использование <a class="reference-link" href="../../Collections/List%20View.md">Списка</a>.
3.  Распечатайте заметку коллекции обычным способом.

Результирующая коллекция будет содержать всех потомков коллекции, сохраняя иерархию.

> [!NOTE]
> Не все типы заметок поддерживаются при печати или экспорте в PDF. При встрече неподдерживаемой заметки она пропускается. В конце, если какие-то из заметок были пропущены, будет показано сообщение с возможностью просмотра полного списка пропущенных заметок. Применяются те же ограничения, что описаны в разделе _Ограничения и пределы_.

## Сочетание клавиш

Возможно вызывать и печать, и экспорт в PDF с клавиатуры, перейдя в _Сочетания клавиш_ в <a class="reference-link" href="../UI%20Elements/Options.md">Настройках</a> и назначив комбинацию клавиш для:

*   _Распечатать активную заметку_
*   _Экспортировать активную заметку как PDF_

## Ограничения и пределы

Не все <a class="reference-link" href="../../Note%20Types.md">Типы заметок</a> поддерживаются при печати, в этом случае опции _Печать_ и _Экспорт в PDF_ будут отключены.

*   Для заметок <a class="reference-link" href="../../Note%20Types/Text.md">Текст</a> шрифт, фон и цвета таблиц печатаются в оттенках светлых тем, независимо от текущей темы (см. <a class="reference-link" href="../../Note%20Types/Text/General%20formatting.md">Общее форматирование</a>).
*   Заметки <a class="reference-link" href="../../Note%20Types/Code.md">Код</a> печатаются с подсветкой синтаксиса в _Светлой теме_ <a class="reference-link" href="../UI%20Elements/Options.md">Настроек</a> → _Заметки с кодом_ → _Внешний вид_, независимо от текущей темы. Строки нумеруются, если _Заметки с кодом_ → _Редактор_ → _Номера строк_ не отключены.
*   <a class="reference-link" href="../../Note%20Types/Render%20Note.md">Render Note</a> печатается так, как отображается, без повторного запуска её скрипта после установки её отношения `~renderNote`.
*   Для <a class="reference-link" href="../../Collections.md">Коллекций</a> поддерживаются следующие:
    *   <a class="reference-link" href="../../Collections/List%20View.md">Список</a>, позволяющий печатать несколько заметок за раз с сохранением иерархии (похоже на книгу).
    *   <a class="reference-link" href="../../Collections/Presentation.md">Презентация</a>, где отображается каждый слайд/подзаметка.
        *   Большинство типов заметок поддерживаются, особенно те, что имеют графическое представление, такие как <a class="reference-link" href="../../Note%20Types/Canvas.md">Холст</a> и <a class="reference-link" href="../../Note%20Types/Mind%20Map.md">Mind Map</a>.
    *   <a class="reference-link" href="../../Collections/Table.md">Таблица</a>, где таблица отображается в печатно-дружественном виде.
        *   Слишком сложные таблицы (особенно если у них несколько колонок) могут некорректно вписываться, однако таблицы с большим числом строк поддерживаются благодаря разбиению на страницы.
        *   Рассмотрите печать в альбомном режиме или используйте `#printLandscape` при экспорте в PDF.
    *   Остальные коллекции не поддерживаются, но мы планируем когда-нибудь добавить поддержку всех типов коллекций.
*   <a class="reference-link" href="../Navigation/Search.md">Сохранённый поиск</a> печатает свои результаты списком в виде _Предпросмотр поиска_ или _Список_.
*   Использование <a class="reference-link" href="../../Theme%20development/Custom%20app-wide%20CSS.md">Пользовательского CSS для всего приложения</a> для печати больше не поддерживается; вместо этого нужно использовать пользовательское отношение `printCss` (см. ниже).

## Настройка CSS печати

Как продвинутый сценарий, можно настроить CSS, используемый для печати, например настроив шрифты, размеры или поля. Обратите внимание, что <a class="reference-link" href="../../Theme%20development/Custom%20app-wide%20CSS.md">Пользовательский CSS для всего приложения</a> не будет работать для печати.

Для этого:

*   Создайте CSS [кодовую заметку](../../Note%20Types/Code.md).
*   На печатаемой заметке примените отношение `~printCss`, указывающее на вновь созданную CSS-кодовую заметку.
*   Чтобы применить CSS к нескольким заметкам, рассмотрите использование [наследуемых атрибутов](../../Advanced%20Usage/Attributes/Attribute%20Inheritance.md) или <a class="reference-link" href="../../Advanced%20Usage/Templates.md">Шаблонов</a>.

Например, чтобы сменить шрифт документа с заданного темой или пользователем на засечки:

```
body {
	--print-font-family: serif;
    --print-font-size: 11pt;
}
```

> [!IMPORTANT]
> При изменении `--print-font-family` убедитесь, что изменение сделано на уровне `body`, а не `:root`, так как иначе оно не будет учтено из-за правил специфичности.

Отметим:

*   Можно добавить несколько CSS-заметок, используя несколько отношений `~printCss`.
*   Если заметка, указывающая на `printCss`, имеет неправильный тип заметки или MIME-тип, она будет игнорироваться.
*   При миграции с предыдущей версии, где использовался <a class="reference-link" href="../../Theme%20development/Custom%20app-wide%20CSS.md">Пользовательский CSS для всего приложения</a>, не нужен `@media print {`, так как таблица стилей используется только для печати.

## Внутреннее устройство

И печать, и экспорт в PDF используют один и тот же механизм: заметка рендерится по отдельности на отдельной веб-странице, которая затем отправляется в браузер или приложение Electron либо для печати, либо для экспорта в PDF.

Веб-страница, рендерящая одну заметку, на самом деле доступна в веб-браузере. Например, `http://localhost:8080/#root/WWRGzqHUfRln/RRZsE9Al8AIZ?ntxId=0o4fzk` превращается в `http://localhost:8080/?print#root/WWRGzqHUfRln/RRZsE9Al8AIZ`.

Доступ к печатной заметке в веб-браузере позволяет легко отлаживать, чтобы понять, почему конкретная заметка плохо рендерится. Механизм рендеринга похож на используемый в <a class="reference-link" href="Note%20List.md">Списке заметок</a>.
