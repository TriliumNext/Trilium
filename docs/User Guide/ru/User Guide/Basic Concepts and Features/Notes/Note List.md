# Список заметок
<figure class="image"><img style="aspect-ratio:990/590;" src="Note List_image.png" width="990" height="590"></figure>

Когда у заметки есть одна или несколько дочерних заметок, они перечисляются в конце заметки для удобной навигации.

## Конфигурация

*   Чтобы скрыть список заметок для конкретной заметки, просто примените [метку](../../Advanced%20Usage/Attributes.md) `hideChildrenOverview`.
*   Для некоторых видов, таких как Сетка, только подмножество заметок будет отображаться, и для навигации по всем ним может использоваться разбиение на страницы из соображений производительности. Чтобы настроить количество заметок на страницу, задайте `pageSize` на нужное число.

## Типы видов

Типы видов определяют, как представлены дочерние заметки. По умолчанию заметки отображаются в сетке, однако доступны и другие типы видов.

Как правило, тип вида можно изменить только из <a class="reference-link" href="../../Collections/Collection%20Properties.md">Свойств коллекции</a>, но его также можно изменить вручную на любом типе заметки с помощью [метки](../../Advanced%20Usage/Attributes/Labels.md) `#viewType`.

Сохранённые поиски используют _Предпросмотр поиска_ по умолчанию: он рисует каждый результат как карточку-фрагмент с текстом и атрибутами, которые совпали. Он ограничен заметками поиска и описан в <a class="reference-link" href="../Navigation/Search.md">Поиске</a>.
