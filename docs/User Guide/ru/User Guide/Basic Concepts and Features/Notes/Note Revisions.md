# Ревизии заметки
<figure class="image"><img style="aspect-ratio:2089/1515;" src="Note Revisions_image.png" width="2089" height="1515"></figure>

Trilium поддерживает бесшовное версионирование заметок, сохраняя снимки («ревизии») заметок через регулярные интервалы.

Чтобы отобразить ревизии, нажмите <a class="reference-link" href="../UI%20Elements/Note%20menu.md">Меню заметки</a> и выберите _Ревизии заметки…_ (<span class="tn-icon bx bx-history"></span>).

## Взаимодействие

> [!NOTE]
> Эта документация соответствует редизайну диалога ревизий заметки в v0.103.0; в более старых версиях есть похожий диалог, но с некоторыми отличиями.

*   Полный список ревизий отображается слева в обратном хронологическом порядке.
    *   Ревизии сгруппированы по дате создания ревизии.
    *   Этот список не содержит _текущего состояния_ заметки, поэтому возможны заметки без сохранённых ревизий/снимков.
*   Значок ревизии указывает _источник_ этой ревизии (например, значок <span class="tn-icon bx bx-save"></span> для вручную сохранённой ревизии).
*   Нажатие кнопки <span class="tn-icon bx bx-dots-horizontal-rounded"></span> в правом верхнем углу диалога отображает несколько опций, включая:
    *   <span class="tn-icon bx bx-save"></span> Сохранение новой ревизии сейчас.
    *   Проверку интервала и лимита для этой заметки (см. ниже).
    *   <span class="tn-icon bx bx-trash"></span> Удаление всех ревизий этой заметки.
*   Для поддерживаемых заметок (текст, код) изменения подсвечиваются. Это поведение можно переключать через _Подсвечивать изменения_ вверху диалога.
    *   Подсвеченные изменения даются относительно **текущего состояния заметки**, а не относительно предыдущей ревизии.
*   Для любой заданной ревизии кнопки в правом верхнем углу позволяют работать с ней:
    *   <span class="tn-icon bx bx-trash"></span> Удаление ревизии.
    *   <span class="tn-icon bx bx-download"></span> Скачивание ревизии локально.
    *   <span class="tn-icon bx bx-history"></span> Восстановление ревизии, которое заменяет текущее содержимое заметки содержимым из ревизии. Сохраняется ещё одна ревизия, содержащая текущее содержимое заметки.

## Именованные ревизии

Именованные ревизии — новая возможность Trilium v0.103.0, позволяющая добавлять короткое описание того, что содержат изменения в снимке.

В списке ревизий заметки:

*   Имя ревизии отображается под временем ревизии в боковой панели, а также вверху диалога, где оно показано полностью.
*   Щелчок по кнопке редактирования <span class="tn-icon bx bx-edit-alt"></span> рядом с именем ревизии позволяет его изменить.

Чтобы создать именованную ревизию:

*   Откройте <a class="reference-link" href="../UI%20Elements/Note%20menu.md">Меню заметки</a>, выберите _Ревизии заметки…_ → _Сохранить именованную ревизию…_ (<span class="tn-icon bx bx-purchase-tag"></span>), введите имя ревизии и подтвердите.
*   Используйте соответствующее [сочетание клавиш](../Keyboard%20Shortcuts.md) или команду <a class="reference-link" href="../Navigation/Jump%20to%20%26%20command%20palette.md">«Переход к» и палитры команд</a> с тем же именем.
*   Сохраните ревизию обычным способом и скорректируйте имя затем из списка ревизий заметки.

## Когда сохраняются ревизии

Ревизии сохраняются:

*   Автоматически через фиксированный интервал. Это поведение можно настроить (см. ниже).
*   Вручную, путём:
    *   Перехода в <a class="reference-link" href="../UI%20Elements/Note%20menu.md">Меню заметки</a> и выбора _Ревизии заметки…_ → _Сохранить ревизию_ (<span class="tn-icon bx bx-save"></span>).
    *   Использования [сочетания клавиш](../Keyboard%20Shortcuts.md) _Принудительно сохранить ревизию_.
    *   В диалоге _Ревизии заметки_ нажатия кнопки <span class="tn-icon bx bx-dots-horizontal-rounded"></span> в правом верхнем углу и выбора _Сохранить ревизию сейчас_.

Кроме того, ревизии могут приходить откуда-то ещё, и это указывается значком ревизии:

*   <span class="tn-icon bx bx-code-alt"></span> Сгенерированы извне, через <a class="reference-link" href="../../Advanced%20Usage/ETAPI%20(REST%20API).md">ETAPI (REST API)</a>.
*   <span class="tn-icon bx bx-bot"></span> Изменение, созданное <a class="reference-link" href="../../AI.md">ИИ</a>.
*   <span class="tn-icon bx bx-history"></span> Ревизия восстановлена, в результате чего существующее содержимое заметки сохраняется как ревизия для предотвращения возможной потери данных.

#### Интервал снимков

Временной интервал создания снимков заметки настраивается в диалоге Настройки → Прочее. Это даёт компромисс между большим числом ревизий и большим объёмом хранимых данных.

Чтобы отключить версионирование заметки для конкретной заметки (или поддерева), добавьте заметке [метку](../../Advanced%20Usage/Attributes.md) `disableVersioning`.

#### Максимум ревизий

Лимит на количество снимков заметки можно настроить в диалоге Настройки → Прочее. Лимит числа снимков ревизий заметки относится к максимальному количеству ревизий, которое может быть сохранено для каждой заметки. Где -1 означает без лимита, 0 — удалить все ревизии. Максимальное число ревизий для одной заметки можно задать через метку `versioningLimit=X`.

Лимит заметки не вступит в силу немедленно; он будет применяться только при изменении заметки.

Можно нажать кнопку _Стереть сейчас_ под _Стереть избыточные снимки ревизий_, чтобы применить изменения немедленно.
