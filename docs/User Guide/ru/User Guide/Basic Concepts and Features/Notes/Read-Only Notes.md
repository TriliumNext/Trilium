# Заметки только для чтения
Некоторые типы заметок, такие как <a class="reference-link" href="../../Note%20Types/Text.md">Текст</a>, <a class="reference-link" href="../../Note%20Types/Code.md">Код</a> и даже некоторые <a class="reference-link" href="../../Collections.md">Коллекции</a>, можно установить в режим только для чтения. Когда заметка в режиме только для чтения, она представляется пользователю в нередактируемом виде, с возможностью переключиться в режим редактирования при необходимости.

## Автоматический режим только для чтения

В целях оптимизации Trilium автоматически устанавливает очень большие заметки в режим только для чтения. Отображение таких длинных заметок в режиме редактирования может замедлять производительность, особенно когда редактирование не нужно.

Это поведение можно отключить для каждой заметки отдельно, следуя инструкциям следующего раздела.

Кроме того, возможно изменить число символов, при котором срабатывает автоматический режим только для чтения, в <a class="reference-link" href="../UI%20Elements/Options.md">Настройках</a>, перейдя в настройки <a class="reference-link" href="#root/_hidden/_options/_optionsTextNotes">Текстовых заметок</a> и <a class="reference-link" href="#root/_hidden/_options/_optionsCodeNotes">Заметок с кодом</a>.

## Изменение поведения «только для чтения» заметки

Поведение «только для чтения» заметки можно изменить через <a class="reference-link" href="../UI%20Elements/Note%20menu.md">Меню заметки</a> → _Редактируемость_. Возможны следующие опции:

*   **Авто**
    Это поведение по умолчанию, при котором заметка будет редактируема по умолчанию, если не станет достаточно большой для включения режима только для чтения.
*   **Только для чтения**
    Заметка всегда будет помечена как доступная только для чтения, независимо от её размера. Тем не менее, при необходимости всё ещё возможно временно отредактировать заметку. Это обычно полезно для заметок, которые не склонны меняться.
*   **Всегда редактируема**
    Эта опция обходит автоматическое включение режима только для чтения для этой конкретной заметки. Полезно для больших заметок, которые часто редактируются.

Если раздел _Редактируемость_ отсутствует в <a class="reference-link" href="../UI%20Elements/Note%20menu.md">Меню заметки</a>, значит, этот тип заметок не поддерживает режим только для чтения.

### Ручная установка опций

Помимо использования <a class="reference-link" href="../UI%20Elements/Note%20menu.md">Меню заметки</a>, как упоминалось выше, также возможно использовать [метки](../../Advanced%20Usage/Attributes.md) для изменения поведения:

*   Чтобы установить режим только для чтения, примените заметке метку `readOnly`.
*   Чтобы отключить автоматический режим только для чтения (всегда редактируема), примените метку `autoReadOnlyDisabled`.

## Временное редактирование заметки только для чтения

При обращении к заметке только для чтения её можно временно отредактировать, нажав значок _Только для чтения_.

При нажатии заметка станет редактируемой, но снова станет доступной только для чтения после перехода к другой заметке.

Страницы встроенного руководства пользователя — исключение: они являются частью самого Trilium и не могут быть отредактированы, даже временно. Их значок _Только для чтения_ нельзя нажать, меню заметки не предлагает их редактировать, а их атрибуты показаны в правой боковой панели без возможности их изменения.
