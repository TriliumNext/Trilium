# Заметки
Заметка — центральная сущность в Trilium. Основные атрибуты заметки — [заголовок](Notes/Title.md) и содержимое.

### Типы заметок

Основной тип заметок — тип форматированного текста <a class="reference-link" href="../Note%20Types/Text.md">Текст</a>. Для диаграмм и рисования есть <a class="reference-link" href="../Note%20Types/Canvas.md">Холст</a> и <a class="reference-link" href="../Note%20Types/Mermaid%20Diagrams.md">Диаграммы Mermaid</a>.

Также есть более сложные типы заметок, такие как <a class="reference-link" href="../Note%20Types/Saved%20Search.md">Сохранённый поиск</a> и <a class="reference-link" href="../Note%20Types/Render%20Note.md">Render Note</a>, которые обычно идут рука об руку со <a class="reference-link" href="../Scripting.md">Скриптингом</a>.

В Trilium нет специального типа заметок «папка». Любая заметка может иметь потомков и таким образом быть папкой. Чтобы сделать заметку, которая показывает только своих потомков, как папка в других приложениях, используйте коллекцию <a class="reference-link" href="../Collections/Grid%20View.md">Сетка</a> или <a class="reference-link" href="../Collections/List%20View.md">Список</a>. См. также <a class="reference-link" href="../FAQ.md">Частые вопросы</a>.

### Корневая заметка

Есть одна специальная заметка, называемая «корневая заметка», которая является корнем дерева заметок. Все остальные заметки размещены ниже неё в структуре.

### Древовидная структура

Важно, что сама заметка не несёт информации о своём размещении в дереве заметок. Подробнее см. <a class="reference-link" href="Notes/Cloning%20Notes.md">Клонирование заметок</a>.

Древовидная структура заметок может напоминать файловую систему — но по сравнению с ней заметки в Trilium могут выступать и файлом, и каталогом — то есть заметка может иметь собственное содержимое и иметь потомков. «Конечная заметка» — это заметка, у которой нет потомков.

### Удаление / восстановление заметок

Когда вы удаляете заметку в Trilium, она на самом деле только помечается на удаление (мягкое удаление) — фактические содержимое, заголовок, атрибуты и т.д. не удаляются, а только скрываются.

В течение (по умолчанию) 7 дней возможно восстановить эти мягко удалённые заметки — откройте диалог <a class="reference-link" href="UI%20Elements/Recent%20Changes.md">Последние изменения</a>, и вы увидите список всех изменённых заметок, включая удалённые. Заметки, доступные для восстановления, имеют ссылку для этого. Это своего рода функциональность «корзины», известная, например, из Windows.

Щелчок по «восстановить» вернёт заметку, её содержимое и атрибуты — заметка будет в том же состоянии, что и перед удалением. Это действие также восстановит потомков заметки, которые были удалены в том же действии.

Чтобы иметь возможность восстановить заметку, необходимо, чтобы родитель удалённой заметки был восстановлен (иначе нет места, куда мы можем её восстановить). Это может стать проблемой, когда вы удаляете несколько заметок подряд — решение тогда восстанавливать в обратном порядке удаления.

После 7 дней (настраивается) заметки будут «стёрты» — их заголовок, содержимое, ревизии и атрибуты будут стёрты, и будет больше невозможно их восстановить (если вы не восстановите <a class="reference-link" href="../Installation%20%26%20Setup/Backup.md">Резервную копию</a>).
