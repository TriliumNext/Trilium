# Импорт и экспорт
Чтобы импортировать заметку:

*   Самый простой способ импорта — просто перетащить файл или архив в <a class="reference-link" href="UI%20Elements/Note%20Tree.md">Дерево заметок</a>.
    *   Это автоматически распознаёт некоторые форматы, такие как <a class="reference-link" href="Import%20%26%20Export/Importing%20data%20from%20other%20applications/Obsidian.md">Obsidian</a>.
    *   _Безопасный импорт_ автоматически включён, чтобы предотвратить случайный запуск посторонних скриптов.
*   Для настройки импорта существует специальный диалог, доступный через <a class="reference-link" href="UI%20Elements/Note%20Tree.md">Дерево заметок</a> → _Импортировать в заметку_ или <a class="reference-link" href="UI%20Elements/Note%20menu.md">Меню заметки</a> → _Импортировать в заметку_.
    *   Эта возможность позволяет использовать специальные импортёры для других приложений, таких как <a class="reference-link" href="Import%20%26%20Export/Importing%20data%20from%20other%20applications/Obsidian.md">Obsidian</a> или <a class="reference-link" href="Import%20%26%20Export/Importing%20data%20from%20other%20applications/Microsoft%20OneNote.md">Microsoft OneNote</a>.
    *   _Безопасный импорт_, а также другие опции можно настроить в свёрнутом разделе _Опции_ внизу.

Чтобы экспортировать заметку, щёлкните правой кнопкой по заметке в <a class="reference-link" href="UI%20Elements/Note%20Tree.md">Дереве заметок</a> и выберите _Экспортировать_. Аналогично, в <a class="reference-link" href="UI%20Elements/Note%20menu.md">Меню заметки</a> есть опция _Экспортировать заметку_.

## Поддерживаемые форматы

Trilium нативно поддерживает следующие форматы как для импорта, так и для экспорта.

*   HTML:
    *   Это основной формат, используемый Trilium, где стандартные теги используются для представления базового форматирования и макета (например, `<strong>`, `<table>`, `<pre>`).
    *   Обратите внимание, что HTML — не стандартизированный формат, поэтому некоторые более специфические возможности, такие как замечания (admonitions) или <a class="reference-link" href="../Note%20Types/Text/Links/Internal%20(reference)%20links.md">внутренние (ссылочные) ссылки</a>, могут не поддерживаться другими приложениями.
    *   Заметки также можно экспортировать как [статический HTML, который можно использовать для веб-публикации](../Advanced%20Usage/Sharing/Exporting%20static%20HTML%20for%20web%20publishing.md).
*   <a class="reference-link" href="Import%20%26%20Export/Markdown.md">Markdown</a>
    *   Большая часть форматирования сохраняется, см. <a class="reference-link" href="Import%20%26%20Export/Markdown/Supported%20syntax.md">Поддерживаемый синтаксис</a>.
*   OPML (Outliner Interchange Format)
    *   Поддерживает как OPML v1.0 для простого текста, так и v2.0 с поддержкой HTML.

Чтобы импортировать из других приложений, таких как OneNote, Notion и других, см. <a class="reference-link" href="Import%20%26%20Export/Importing%20data%20from%20other%20applications.md">Импорт данных из других приложений</a>.

## Максимальный размер импорта

Версии до v0.104.0 имели лимит загрузки 250 МиБ, который можно было обойти через переменную окружения `TRILIUM_NO_UPLOAD_LIMIT`; в v0.104.0 этот лимит был удалён.

Тем не менее, остаётся лимит на максимальный размер **одного элемента** (будь то <a class="reference-link" href="../Note%20Types/File.md">Файл</a>, <a class="reference-link" href="Notes/Attachments.md">Вложение</a> или даже заметка <a class="reference-link" href="../Note%20Types/Text.md">Текст</a>). Лимит составляет примерно 374 МиБ и определяется протоколом <a class="reference-link" href="../Installation%20%26%20Setup/Synchronization.md">Синхронизации</a>. Попытки импортировать такие большие файлы будут отклонены.

При больших импортах или экспортах потребление памяти может взлетать, но останется где-то в районе отметки 2 гигабайта. Проверено на базе данных 2,4 ГБ с ~21 тыс. заметок.

> [!IMPORTANT]
> Для <a class="reference-link" href="../Installation%20%26%20Setup/Desktop%20Installation.md">Установки на компьютер</a> существует два разных механизма импорта:
>
> *   Быстрый импорт из <a class="reference-link" href="UI%20Elements/Note%20Tree.md">Дерева заметок</a>.
> *   Диалог импорта (через правый щелчок в дереве заметок → _Импортировать в заметку_ или из <a class="reference-link" href="UI%20Elements/Note%20menu.md">Меню заметки</a>).
>
> При работе с большими файлами (несколько гигабайт) предпочитайте диалог импорта, так как он имеет специальный механизм, гарантирующий, что файл читается напрямую с диска, а не загружается повторно.

## Экспорт корневой заметки

Корневая заметка — самая верхняя заметка. Её экспорт ведёт себя как у любой другой заметки: щёлкните по ней правой кнопкой в <a class="reference-link" href="UI%20Elements/Note%20Tree.md">Дереве заметок</a> и выберите _Экспортировать_.

Начиная с v0.104.0 при импорте корневой заметки она будет импортирована как дочерняя вашей существующей корневой заметки. Такое поведение гарантирует, что импорт не может изменить или перезаписать ваши существующие заметки.

Вы можете легко переместить заметки на корень с помощью <a class="reference-link" href="UI%20Elements/Note%20Tree/Multiple%20selection.md">Множественного выбора</a> в дереве и удалить избыточную корневую заметку.

> [!TIP]
> Вместо экспорта полных ZIP-архивов (включая корневую заметку) рассмотрите использование [резервных копий](../Installation%20%26%20Setup/Backup.md). Резервные копии всегда содержат всю структуру, а также дополнительную информацию, которой нет в ZIP-экспорте: сохраняют ID заметок, содержат опции/токены и лучше работают с <a class="reference-link" href="Notes/Protected%20Notes.md">Защищёнными заметками</a>.

## Экспорт Руководства пользователя

Встроенное Руководство пользователя можно экспортировать как любую другую заметку: щёлкните правой кнопкой по одной из его страниц или глав в <a class="reference-link" href="UI%20Elements/Note%20Tree.md">Дереве заметок</a> и выберите _Экспортировать_ или используйте <a class="reference-link" href="UI%20Elements/Note%20menu.md">Меню заметки</a> → _Экспортировать заметку_.

*   Экспорт главы с _Эта заметка и все потомки_ записывает картинки и файлы каждой страницы как её вложения. Импорт этого архива создаёт обычную копию, которую можно редактировать, с работающими картинками и ссылками между её страницами.
*   Экспорт одной страницы с _Только эта заметка_ встраивает её картинки в экспортированный файл.
