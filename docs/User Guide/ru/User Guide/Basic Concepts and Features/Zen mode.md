# Режим дзена
![](2_Zen%20mode_image.png)

Снимок экрана режима дзена, активированного в системе Windows 11 с выключенной нативной строкой заголовка и включёнными фоновыми эффектами.

Когда активирован режим дзена (изображён сбоку), большая часть пользовательского интерфейса Trilium скрывается, чтобы можно было сфокусироваться на содержимом, будь то чтение или письмо.

![](1_Zen%20mode_image.png)

Снимок экрана опции режима дзена в глобальном меню.

## Активация и деактивация

Режим дзена можно активировать, открыв глобальное меню и выбрав опцию «Режим дзена»:

Помимо глобального меню, этот режим также можно активировать с помощью сочетания клавиш (которое является <kbd>F9</kbd> начиная с TriliumNext 0.92.5 и <kbd>Alt</kbd>+<kbd>Z</kbd> для более старых версий). Ищите `toggleZenMode` в настройке сочетаний клавиш.

После активации режима дзена все элементы интерфейса приложения будут скрыты, включая глобальное меню. В этом случае режим дзена можно деактивировать либо нажав значок <span class="tn-icon bx bxs-yin-yang"></span> в правом верхнем углу окна, либо снова нажав комбинацию клавиш.

Учтите, что по замыслу активация или деактивация режима дзена применяется только к текущему окну. Перезапуск приложения также отключит режим дзена.

## Перемещение окна

Если «Нативная строка заголовка» активирована, то стандартную строку заголовка операционной системы можно использовать для перетаскивания окна. Если она деактивирована, окно всё равно можно перемещать, перетаскивая мышь по верхней части окна, где находятся заголовки заметок.

Снимок экрана двух заметок бок о бок при активном режиме дзена в Windows 11 с выключенными фоновыми эффектами.

## Разделённые окна и вкладки

Вкладки полностью скрыты, однако всё ещё можно использовать сочетания клавиш, такие как `firstTab` (<kbd>Ctrl</kbd>+<kbd>1</kbd> по умолчанию), `secondTab` (<kbd>Ctrl</kbd>+<kbd>2</kbd> по умолчанию). Есть также более новые сочетания, такие как `activateNextTab` (<kbd>Ctrl</kbd>+<kbd>Tab</kbd>) или `activatePreviousTab` (<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Tab</kbd>), которые позволяют лёгкую навигацию, однако убедитесь, что они настроены правильно в настройках.

Для разделённого вида заметок на момент написания нет сочетаний клавиш, но всё ещё возможно использовать их в режиме дзена, создав разделение при выключенном режиме дзена, а затем повторно активировав его.
