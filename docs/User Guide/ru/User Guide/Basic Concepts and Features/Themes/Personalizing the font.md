# Персонализация шрифта
## Использование разных шрифтов

Trilium поставляется по умолчанию со своим шрифтом (_Inter_), но шрифт можно настроить в <a class="reference-link" href="../UI%20Elements/Options.md">Настройках</a> → _Внешний вид_, отметив _Использовать другие шрифты_ в разделе _Шрифты_.

Шрифт можно персонализировать для следующих областей приложения:

*   Текст интерфейса, для большей части интерфейса (меню, панели инструментов, диалоги).
*   <a class="reference-link" href="../UI%20Elements/Note%20Tree.md">Дерево заметок</a>.
*   Текст документа, для фактического содержимого заметок (особенно для заметок <a class="reference-link" href="../../Note%20Types/Text.md">Текст</a>), включая строки коллекции <a class="reference-link" href="../../Collections/Table.md">Таблица</a>.
*   Моноширинный текст, например для заметок <a class="reference-link" href="../../Note%20Types/Code.md">Код</a> и <a class="reference-link" href="../../Note%20Types/Text/Developer-specific%20formatting/Code%20blocks.md">Блоков кода</a>.

Каждая область также имеет свой собственный _Размер_. Размеры дерева заметок и документа относительны к размеру интерфейса, поэтому изменение размера интерфейса двигает их вместе с ним. Значки, такие как на панели запуска, сохраняют свой размер; чтобы увеличить всё приложение, используйте вместо этого <a class="reference-link" href="../UI%20Elements/Zoom.md">Масштаб</a>.

Список шрифтов содержит следующие элементы:

*   **Общие шрифты**
    *   _Определённый темой_, который использует шрифт, встроенный в текущую [тему](../Themes.md). Например, в теме современного интерфейса по умолчанию шрифт — _Inter_. Это не требует установки шрифта.
    *   _Системный по умолчанию_, который использует комбинацию шрифтов, лучше всего работающую для [десктопного приложения](../../Installation%20%26%20Setup/Desktop%20Installation.md). Например, в Windows будет использоваться _Segoe UI_.
    *   Общие варианты шрифтов для шрифтов с засечками (наподобие _Times New Roman_), без засечек и моноширинных.
*   **Веб-шрифты**, которые появляются в [Установке на сервер](../../Installation%20%26%20Setup/Server%20Installation.md) — это предопределённый список шрифтов, сгруппированный по Sans-serif, serif, monospace и рукописным. Шрифты, не поддерживаемые вашей системой (т.е. не установленные), не отображаются.
*   **Системные шрифты**, которые появляются в [Установке на компьютер](../../Installation%20%26%20Setup/Desktop%20Installation.md). В отличие от серверных шрифтов, которые предопределены, системные шрифты перечисляются из вашей операционной системы. Некоторые установленные шрифты (такие как битмап-версии _GNU Unifont_) не могут отобразить никакой текст; такой шрифт появляется пустым в списке, и его выбор показывает ошибку вместо применения.
*   **Пользовательские шрифты**, позволяющие использовать любой шрифт при условии, что он импортирован в Trilium. Подробности см. в разделе ниже.

Изменения шрифта вступают в силу после перезагрузки; раздел предлагает кнопку _Перезагрузить для применения изменений_, как только что-то было изменено.

## Пользовательские шрифты

Файл шрифта, импортированный в Trilium, может использоваться самим приложением, без написания какого-либо CSS.

### Добавление шрифта

1.  Импортируйте файл шрифта, перетащив его в <a class="reference-link" href="../UI%20Elements/Note%20Tree.md">Дерево заметок</a> или через _Импортировать в заметку_. Распознаются файлы TrueType (`.ttf`), OpenType (`.otf`) и Web Open Font Format (`.woff`, `.woff2`); заметка получает имя шрифта без расширения и помечается значком шрифта (значок «A»).
2.  Выберите результирующую заметку, где отобразится предпросмотр шрифта: строка-образец для ввода собственного текста, ползунок его размера, предпросмотр в нескольких размерах и латинский набор символов.
3.  Включите _В выборе шрифта_ над образцом.
4.  В <a class="reference-link" href="../UI%20Elements/Options.md">Настройках</a> → _Внешний вид_ → _Шрифты_ шрифт теперь предлагается под _Пользовательскими шрифтами_, перед встроенными семействами, и может быть установлен для любой из четырёх областей.

> [!NOTE]
> Файлы Embedded OpenType (`.eot`) и TrueType collections (`.ttc`) не могут быть отрисованы браузером, поэтому они обрабатываются как обычные файлы: без предпросмотра и без записи в выборе.

### Как ведут себя пользовательские шрифты

*   Каждая запись названа по своей заметке, поэтому переименование заметки переименовывает запись. Настройка ссылается на саму заметку, а не на её имя, и продолжает работать при переименовании.
*   Файл шрифта — обычная заметка, поэтому <a class="reference-link" href="../../Installation%20%26%20Setup/Synchronization.md">Синхронизация</a> переносит его на ваши другие устройства. Выбор шрифта не синхронизируется: настройки внешнего вида намеренно хранятся для каждого устройства отдельно, поэтому на другом устройстве шрифт уже есть и его нужно только выбрать заново.
*   Шрифт, хранящийся в [защищённой заметке](../Notes/Protected%20Notes.md), может быть предпросмотрен и использован только пока защищённая сессия открыта.

Для авторов тем шрифт также может быть встроен в CSS темы через <a class="reference-link" href="../../Advanced%20Usage/Custom%20Resource%20Providers.md">Пользовательских поставщиков ресурсов</a> — это путь, по которому идти, когда шрифт должен поставляться с темой, а не выбираться в настройках.

### Скачивание из Google Fonts

Большой выбор шрифтов можно легко получить из Google Fonts следующим образом:

1.  Перейдите на [https://fonts.google.com](https://fonts.google.com).
2.  Найдите нужный шрифт.
3.  Нажмите _Get font_ в правом верхнем углу.
4.  Проверьте, что список шрифтов слева соответствует вашему выбору.
5.  Нажмите _Download all_.
6.  В <a class="reference-link" href="../UI%20Elements/Note%20Tree.md">Дереве заметок</a> создайте заметку для хранения новых шрифтов.
7.  В <a class="reference-link" href="../UI%20Elements/Note%20Tree.md">Дереве заметок</a> перетащите .zip-файл прямо на вновь созданную заметку и следуйте шагам из предыдущего раздела.

## Лигатуры программирования

Некоторые шрифты поддерживают лигатуры программирования, которые превращают комбинации символов, такие как `!=`, в `≠` или `->` в `→` в <a class="reference-link" href="../../Note%20Types/Text/Developer-specific%20formatting/Code%20blocks.md">Блоках кода</a> и заметках <a class="reference-link" href="../../Note%20Types/Code.md">Код</a>.

Это только средство отображения, поэтому копирование текста не затрагивается. Тем не менее эту возможность можно отключить в Trilium, сняв отметку _Лигатуры программирования_ в настройках шрифтов.
