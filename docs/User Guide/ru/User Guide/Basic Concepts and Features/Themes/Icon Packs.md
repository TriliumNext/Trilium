# Наборы значков
<figure class="image image-style-align-right image_resized" style="width:45.14%;"><img style="aspect-ratio:854/649;" src="Icon Packs_image.png" width="854" height="649"></figure>

По умолчанию Trilium поставляется с набором значков Boxicons v2. Начиная с v0.102.0, пользовательские наборы значков позволяют расширить выбор значков для заметок.

Наборы значков специфичны для Trilium, поэтому они должны либо создаваться с нуля (см. ниже), либо импортироваться из ZIP-файла стороннего разработчика.

## Примеры наборов значков

Команда Trilium поддерживает несколько наборов значков, которые не поставляются с Trilium. Эти наборы значков можно найти на официальном сайте на [странице ресурсов](https://triliumnotes.org/resources).

## Импорт существующего набора значков

> [!NOTE]
> **Наборы значков — сторонний контент**
>
> Помимо [примеров наборов значков](https://triliumnotes.org/resources), сопровождающие Trilium не отвечают за актуальность наборов значков. Если у вас проблема с конкретным набором значков, она должна быть сообщена ответственному стороннему разработчику, а не команде Trilium.

Чтобы импортировать набор значков:

1.  По возможности создайте выделенное место в дереве заметок, куда поместить наборы значков.
2.  Щёлкните правой кнопкой по заметке, куда его поместить, и выберите _Импортировать в заметку_.
3.  Снимите отметку _Безопасный импорт_.
4.  Выберите _Импортировать_.
5.  [Обновите приложение](../../Troubleshooting/Refreshing%20the%20application.md).

> [!WARNING]
> Поскольку _Безопасный импорт_ отключён, убедитесь, что вы доверяете источнику, так как он может содержать опасные сторонние скрипты. Один хороший способ проверить, безопасен ли набор значков, — вручную распаковать .zip и изучить содержимое файлов. Наборы значков должны содержать только файл шрифта и JSON-файл. Другие файлы (особенно скрипты) следует считать вредоносными.

## Создание набора значков

Создание набора значков требует некоторых знаний скриптинга вне Trilium для генерации списка значков. Для информации см. <a class="reference-link" href="../../Theme%20development/Creating%20an%20icon%20pack.md">Создание набора значков</a>.

## Использование значка из набора значков

После [обновления приложения](../../Troubleshooting/Refreshing%20the%20application.md) набор значков должен быть включён по умолчанию. Чтобы проверить, просто выберите существующую заметку или создайте новую и попробуйте изменить значок заметки.

Справа от строки поиска в списке значков должна быть кнопка _Фильтр_. Нажатие на неё позволяет фильтровать по набору значков, и вновь импортированный набор значков должен там отображаться.

> [!NOTE]
> Если набор значков отсутствует в этом списке, то, скорее всего, с ним что-то не так.
>
> *   Попробуйте проверить <a class="reference-link" href="../../Troubleshooting/Error%20logs/Backend%20(server)%20logs.md">Журналы сервера</a> на предмет подсказок и убедитесь, что набор значков имеет [метку](../../Advanced%20Usage/Attributes/Labels.md) `#iconPack` с присвоенным ей значением (префиксом).
> *   Наборы значков, которые [защищены](../Notes/Protected%20Notes.md), игнорируются.

## Интеграция с функциональностью публикации и экспорта

Пользовательские наборы значков также поддерживаются возможностью <a class="reference-link" href="../../Advanced%20Usage/Sharing.md">Публикации</a>, где они будут показаны в дереве заметок. Однако чтобы набор значков был виден функции публикации, заметка набора значков также должна быть опубликована.

Если вы используете пользовательскую тему публикации, убедитесь, что она поддерживает `iconPackCss`, иначе значки не покажутся. Образец исходного кода шаблона публикации см. в оригинале.

Пользовательские наборы значков также сохраняются при <a class="reference-link" href="../../Advanced%20Usage/Sharing/Exporting%20static%20HTML%20for%20web%20publishing.md">Экспорте статического HTML для веб-публикации</a>. В этом случае нет требования делать набор значков опубликованным.

## Что происходит, если я удалю набор значков

Если набор значков удалён или отключён (путём удаления или изменения его метки `#iconPack`), все заметки, использующие этот набор значков, будут показаны в <a class="reference-link" href="../UI%20Elements/Note%20Tree.md">Дереве заметок</a> без значка. Это не вызовет никаких проблем, кроме странного вида.

Решение — заменить значки чем-то другим; попробуйте использовать <a class="reference-link" href="../Navigation/Search.md">Поиск</a>, который поддерживает массовые действия, чтобы опознать заметки с теперь удалённым набором значков (поискав префикс) и изменить или удалить их `iconClass`.
