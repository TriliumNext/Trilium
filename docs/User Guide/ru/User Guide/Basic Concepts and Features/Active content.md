# Активное содержимое
_Активное содержимое_ — общее название мощных возможностей в Trilium, начиная от настройки интерфейса и заканчивая продвинутым скриптингом, который может изменять ваши заметки или даже ваш компьютер.

## Безопасный импорт

Проблема безопасности активного содержимого особенно актуальна, когда оно поступает из сторонних источников, например скачано с сайта и затем импортировано в Trilium.

При [импорте](Import%20%26%20Export.md) в Trilium по умолчанию активен _безопасный режим_, который пытается предотвратить выполнение недоверенного кода. Например, [пользовательскому виджету](../Scripting/Frontend%20Basics/Custom%20Widgets.md) для работы нужна [метка](../Advanced%20Usage/Attributes/Labels.md) `#widget`; безопасный импорт работает, переименовывая эту метку в `#disabled:widget`.

Это применяется к каждому атрибуту, создаваемому импортом: как к тем, что в экспорте Trilium .zip, так и к тем, что созданы из свойств других форматов (таких как YAML front matter Markdown-файла, тег Evernote или свойство Notion, Anytype или Obsidian).

## Безопасный режим

Иногда активное содержимое может вызывать проблемы с интерфейсом или сервером, мешая им нормально работать. <a class="reference-link" href="../Advanced%20Usage/Safe%20mode.md">Безопасный режим</a> позволяет запустить Trilium так, что активное содержимое не загружается по умолчанию при запуске, позволяя пользователю исправить проблемные скрипты или виджеты.

## Типы активного содержимого

Это типы активного содержимого в Trilium вместе с несколькими примерами того, что недоверенное содержимое такого типа может вызвать:

| Имя | Отключается при безопасном [импорте](Import%20%26%20Export.md) | Описание | Потенциальные риски недоверенного кода |
| --- | --- | --- | --- |
| [Клиентские скрипты](../Scripting/Frontend%20Basics.md) | Да | Позволяют выполнять произвольный код на клиенте (интерфейсе) Trilium, что может изменить пользовательский интерфейс. | Злонамеренный скрипт может выполнить серверный код, получить доступ к незашифрованным заметкам или изменить их содержимое. |
| <a class="reference-link" href="../Scripting/Frontend%20Basics/Custom%20Widgets.md">Пользовательские виджеты</a> | Да | Могут добавлять новые возможности интерфейса в Trilium, например добавляя новый раздел в <a class="reference-link" href="UI%20Elements/Right%20Sidebar.md">Правую боковую панель</a>. | Интерфейс может быть изменен так, что его можно использовать для извлечения чувствительной информации, или он может просто вызвать падение приложения. |
| <a class="reference-link" href="../Scripting/Backend%20scripts.md">Серверные скрипты</a> | Да | Могут запускать пользовательский код на сервере Trilium (среда Node.js) с полным доступом к заметкам и базе данных. | Имеют доступ ко всем незашифрованным заметкам, а с полным доступом к базе данных могут полностью уничтожить данные. Также имеют доступ к выполнению других приложений или изменению файлов и папок на сервере). |
| <a class="reference-link" href="../Note%20Types/Web%20View.md">Веб-представление</a> | Да | Отображает веб-сайт внутри заметки. | Может указывать на фишинговый сайт, который может собирать данные (например, на странице входа). |
| <a class="reference-link" href="../Note%20Types/Render%20Note.md">Render Note</a> | Да | Отображает пользовательский контент внутри заметки, такой как дашборд или новый редактор, официально не поддерживаемый Trilium. | Может влиять на интерфейс аналогично клиентским скриптам или пользовательским виджетам, так как скрипты не полностью инкапсулированы, или могут вести себя как веб-представление, собирая введённые пользователем данные. |
| <a class="reference-link" href="../Theme%20development/Custom%20app-wide%20CSS.md">Пользовательский CSS для всего приложения</a> | Нет | Может изменять макет и стиль интерфейса с помощью CSS, применяемого независимо от темы. | Как правило, менее проблематичен, чем остальное активное содержимое, но плохо написанный CSS может повлиять на макет приложения, потребовав использования <a class="reference-link" href="../Advanced%20Usage/Safe%20mode.md">Безопасного режима</a>, чтобы иметь возможность пользоваться приложением. |
| [Пользовательские темы](../Theme%20development) | Нет | Может изменить стиль всего интерфейса. | Аналогично пользовательскому CSS для всего приложения. |
| <a class="reference-link" href="Themes/Icon%20Packs.md">Наборы значков</a> | Нет | Вводит новые значки, которые можно использовать для заметок. | Как правило, более изолированы и менее склонны к проблемам, но могут вызывать проблемы с производительностью (например, если в наборе значков миллионы значков). |

## Значок активного содержимого

Если заметка считается содержащей активное содержимое, в области <a class="reference-link" href="Notes/Note%20badges.md">Значков заметки</a> показывается значок. Щелчок по значку раскрывает меню с различными опциями, относящимися к этому типу содержимого, например открыть документацию или настроить выполнение скриптов.

Для некоторых типов активного содержимого, таких как серверные скрипты с пользовательскими условиями запуска, появляется кнопка-переключатель. Это позволяет легко отключать скрипты или виджеты, а также повторно включать их, если импорт был сделан с активным безопасным режимом.
