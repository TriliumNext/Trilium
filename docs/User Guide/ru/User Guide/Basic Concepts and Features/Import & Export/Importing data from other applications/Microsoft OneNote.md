# Microsoft OneNote
Trilium позволяет импортировать из OneNote. В настоящее время поддерживается только механизм через Microsoft Graph API, который требует аутентификации в браузере, чтобы Trilium мог получить заметки.

## Процесс импорта

1.  В <a class="reference-link" href="../../UI%20Elements/Note%20Tree.md">Дереве заметок</a> щёлкните правой кнопкой и выберите _Импортировать в заметку_.
2.  В разделе _Импорт из_ выберите <span class="tn-icon tn-brand tn-brand-onenote"></span> _OneNote_.
3.  Нажмите кнопку _Подключить_:
    1.  В десктопном приложении вы будете перенаправлены на экран аутентификации Microsoft, где сможете войти в свою учётную запись.
    2.  В веб-приложении процесс немного сложнее, так как требуется скопировать код в буфер обмена, перейти по ссылке, вставить код, а затем снова войти.
4.  После успешного подключения вы должны увидеть список разделов, доступных для импорта. Просто отметьте те, которые нужно импортировать, и нажмите кнопку _Импортировать выбранные_.
5.  Дождитесь завершения импорта.

## Поддерживаемые возможности

Следующие возможности сохраняются Trilium в процессе импорта:

*   Базовое форматирование (полужирный, курсив, подчёркивание, зачёркивание, подстрочный, надстрочный, размеры шрифта, заголовки, цвета, выделения).
    *   Чёрный цвет текста намеренно удаляется, чтобы он работал в тёмных темах.
*   Встроенный код определяется и форматируется автоматически. Абзацы, использующие стиль Code, также конвертируются в <a class="reference-link" href="../../../Note%20Types/Text/Developer-specific%20formatting/Code%20blocks.md">Блоки кода</a>.
    *   К сожалению, отступы кода могут быть потеряны, так как этой информации просто нет в данных от Microsoft API.
*   <a class="reference-link" href="../../../Note%20Types/Text/Lists.md">Списки</a> с различными типами маркеров.
*   <a class="reference-link" href="../../../Note%20Types/Text/Tables.md">Таблицы</a>
    *   Фоны ячеек сохраняются, включая попытку коррекции оттенка, так как цвета, возвращаемые Graph API, иногда неверны.
    *   Ширины ячеек также сохраняются пропорционально; единственное отличие в том, что таблицы в Trilium имеют ширину в процентах, а не фиксированные размеры в пикселях.
*   Изображения и <a class="reference-link" href="../../Notes/Attachments.md">Вложения</a>.
    *   Вырезки экрана также корректно поддерживаются начиная с v0.104.1, показывая их временную метку в виде подписи к рисунку.
*   Списки дел (to-do)
*   Рисунки от руки сохраняются и отображаются как SVG-изображение внутри заметки
    *   Цвет OneNote по умолчанию (чёрный) особенный, так как он также отображается белым для тёмных тем. Начиная с v0.104.1, это также поддерживается с помощью специальной SVG-подстройки, которая реагирует на светлые/тёмные темы.
*   Ссылки между другими импортированными страницами конвертируются в <a class="reference-link" href="../../../Note%20Types/Text/Links/Internal%20(reference)%20links.md">внутренние (ссылочные) ссылки</a>, если текст ссылки совпадает с именем страницы, или в обычные ссылки в противном случае. Если страницы не являются частью импорта, сохраняется исходная ссылка `onenote:`.
*   Теги (кроме списков дел) сохраняются, конвертируясь в [встроенные значки](../../../Note%20Types/Text/Insert%20buttons/Icons.md), которые можно искать по имени значка и перекрашивать как любой другой значок. Некоторые значки превращаются в эмодзи.

О структуре заметок:

*   Порядок страниц внутри раздела сохраняется.
*   Подстраницы и группы разделов сохраняются за счёт вложения заметок в иерархическую структуру.
*   Даты создания и изменения как заметок, так и разделов сохраняются. Порядок разделов или групп разделов не сохраняется (см. ограничения).

## Управление ошибками и отчётность

Импортёр OneNote использует Microsoft Graph API, который обрабатывает HTML-экспорт (который мы затем постобрабатываем для использования в Trilium). Сам Graph API должен обработать страницы OneNote перед отправкой их нам, и поэтому это длительная операция, прямо пропорциональная количеству заметок и сложности/размеру заметок.

Graph API ограничивает доступ, если обнаруживает слишком много операций. Импортёр это учитывает, но иногда это означает, что большую часть времени занимает ожидание разблокировки доступа Graph API, а не собственно импорт данных.

Кроме того, некоторые страницы могут завершиться ошибкой на уровне Graph API из-за внутреннего таймаута с их стороны или других проблем. Trilium попытается повторно запросить страницы, чтобы избежать этого, но иногда страницы не удаётся получить даже после нескольких повторных попыток. В этом случае импортёр всё равно создаст соответствующую заметку в Trilium, но с отчётом об ошибке вместо содержимого. Это сохраняет <a class="reference-link" href="../../../Note%20Types/Text/Links/Internal%20(reference)%20links.md">внутренние (ссылочные) ссылки</a> и упрощает опознание и ручное исправление страниц, завершившихся ошибкой.

В конце импорта заметка верхнего уровня с именем _Импорт OneNote_ будет содержать информацию о том, как прошёл импорт:

*   Количество импортированных заметок;
*   Процент успеха;
*   Список заметок, которые не удалось импортировать, а также причина сбоя;
*   Страницы, изображения/вложения которых не удалось скачать;
*   Сколько времени импорт ждал устранения ограничений.

Чтобы избежать случаев, когда импорт фундаментально сломан (например, истёкший вход), импорт завершится с ошибкой, если не удастся импортировать 6 страниц подряд.

## Атрибуты

Страницы, импортированные из OneNote, имеют несколько встроенных [меток](../../../Advanced%20Usage/Attributes/Labels.md):

*   `oneNotePageId` — с соответствующим ID страницы в OneNote. Его можно использовать для опознания исходной страницы OneNote. Trilium в настоящий момент никак его не использует.
*   `oneNoteImportFailed` — присваивается заметкам, которые не удалось импортировать. Её можно использовать для быстрого <a class="reference-link" href="../../Navigation/Search.md">Поиска</a> неудачных заметок.

## Ограничения

### О свободной структуре OneNote

OneNote принципиально отличается от Trilium структурой, так как позволяет рисунку от руки сосуществовать с текстом, а текстовые блоки можно размещать в любом месте документа (например, частый случай использования — колонки). У Trilium есть механизм потока документа для заметок <a class="reference-link" href="../../../Note%20Types/Text.md">Текст</a>, что означает, что их нельзя свободно позиционировать.

Чтобы справиться с этим различием, Trilium уплощает текстовую структуру в обычные абзацы. Абзацы будут упорядочены визуально на основе исходного положения текстовых блоков, но их горизонтальное положение не сохраняется. Параллельный текст, такой как колонки, может отображаться чередующимся, что может вызвать проблемы.

Кроме того, рисунок в OneNote может чередоваться с текстовыми блоками. Текстовые заметки в Trilium не позволяют такую возможность, поэтому весь рисунок будет показан в конце. Для некоторых случаев (например, диаграмм) это сработает нормально, но если у вас есть выделения или другие зависящие от текста рисунки, они будут показаны не по порядку.

> [!NOTE]
> Планируется поддержка заметок с большим количеством рисунков, чередующихся с текстовыми блоками, путём конвертации их в <a class="reference-link" href="../../../Note%20Types/Canvas.md">Холст</a>.

### Защищённые паролем разделы

OneNote поддерживает шифрование на уровне раздела; при импорте записной книжки, содержащей такие разделы с защитой паролем, Trilium не сможет прочитать содержимое защищённых паролем разделов, поэтому они будут отображаться пустыми. Это не ограничение Trilium — информация просто недоступна из источника (Graph API).

Сам раздел сохраняется для справки, и все разделы, которые не удалось импортировать, будут показаны в отчёте (заметка верхнего уровня с именем _Импорт OneNote_).

Чтобы снять защиту раздела в OneNote Desktop, щёлкните правой кнопкой по защищённому разделу → _Password Protect This Section_ и нажмите _Remove Password_, затем выполните синхронизацию. Затем повторно импортируйте только защищённые разделы или удалите всё и начните импорт с нуля.

## Другие ограничения

Следующие известные ограничения обусловлены тем, как информация поступает из импорта (Microsoft Graph API), что означает, что их нельзя исправить.

*   Порядок разделов (и групп разделов) недоступен; разделы упорядочены по дате создания.
*   История версий.
*   Отступы абзацев, а также отступы блоков кода.
*   Цвета разделов.
*   Рисунки внутри заголовков; заголовок может отображаться неполным или «Без названия».

## Сообщение о проблемах

При импорте заметок вы можете обнаружить, что некоторый текст отображается некорректно или структура не сохраняется правильно. Пока эта проблема не является фундаментальной (как проблема с неточным сохранением рисунка от руки), её стоит [сообщить](../../../Troubleshooting/Reporting%20issues.md).

При сообщении обязательно предоставьте следующую информацию:

*   Импортируйте раздел заново, отметив чекбокс отладки перед импортом. Это сохраняет исходный документ (и данные рисунка от руки, если есть) в том виде, в каком он пришёл из облачного API OneNote, чтобы его можно было использовать для сравнения.
*   Экспортируйте только затронутую страницу как ZIP, следя за тем, чтобы случайно не раскрыть чувствительную информацию.
*   Сделайте снимки экрана того, как заметка выглядела в OneNote и как она оказалась в Trilium.
*   Приложите ZIP и снимки экрана к отчёту о проблеме.
