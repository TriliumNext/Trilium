# Notion
Trilium может импортировать ZIP-экспорты из Notion, сохраняя структуру и форматирование.

## Процесс импорта

В Notion есть два способа экспорта данных:

*   Чтобы экспортировать одну страницу (и опционально её подстраницы):
    *   Выберите страницу для экспорта.
    *   Нажмите кнопку \[…\] в правом верхнем углу окна и выберите _Экспорт_.
    *   Убедитесь, что заданы следующие опции:
        *   Export format: HTML
        *   Page content: Everything
        *   Include subpages: On
        *   Create folders for subpages: On
    *   Нажмите кнопку Экспорт.
    *   Дождитесь завершения скачивания.
*   Чтобы экспортировать всё рабочее пространство, нажмите на значок вашего имени пользователя в левом верхнем углу и выберите _Settings_.
    *   В левом разделе найдите категорию _Workspace_ и выберите _General_.
    *   На странице настроек _General_ найдите раздел _Export_ и нажмите кнопку _Export_, соответствующую _Workspace content_.
    *   Убедитесь, что заданы следующие опции:
        *   Export format: HTML
        *   Page content: Everything
        *   Include subpages: On
        *   Create folders for subpages: On
    *   Нажмите кнопку Экспорт.
    *   Дождитесь завершения скачивания. В зависимости от размера вашего рабочего пространства это может занять время. Если это займёт слишком долго, вы получите ссылку для скачивания по электронной почте.

В Trilium Notes:

1.  В <a class="reference-link" href="../../UI%20Elements/Note%20Tree.md">Дереве заметок</a> щёлкните правой кнопкой и выберите _Импортировать в заметку_ (<span class="tn-icon bx bx-import"></span>).
2.  В разделе _Импорт из_ выберите <span class="tn-icon tn-brand tn-brand-notion"></span> _Notion_.
3.  Загрузите ZIP, полученный на предыдущем шаге.

## Поддерживаемые возможности

Следующие возможности сохраняются Trilium в процессе импорта:

*   Базовое форматирование (полужирный, курсив, подчёркивание, зачёркивание, заголовки, цвета, выделения).
*   <a class="reference-link" href="../../../Note%20Types/Text/Lists.md">Списки</a>
*   Списки дел (to-do)
*   <a class="reference-link" href="../../../Note%20Types/Text/Images.md">Изображения</a> и <a class="reference-link" href="../../Notes/Attachments.md">Вложения</a>.
*   Сворачиваемые разделы (toggles)
    *   Вложенные сворачиваемые разделы также поддерживаются.
    *   Заголовки-сворачиваемые теряют свою кнопку сворачивания и становятся обычными заголовками.
*   <a class="reference-link" href="../../../Note%20Types/Text/Math%20Equations.md">Математические формулы</a> (встроенные или блочные)
*   <a class="reference-link" href="../../../Note%20Types/Text/Link%20Previews.md">Превью ссылок</a>
    *   Значок и изображение ссылок нужно получать онлайн, так как экспорты не содержат изображений. Эта операция выполняется только если включена опция _Скачивать изображения автоматически_ в <a class="reference-link" href="../../UI%20Elements/Options.md">Настройках</a> → _Медиа_.
*   <a class="reference-link" href="../../../Note%20Types/Text/Developer-specific%20formatting/Code%20blocks.md">Блоки кода</a> с попыткой восстановить язык по мере возможности.
*   <a class="reference-link" href="../../../Note%20Types/Mermaid%20Diagrams.md">Диаграммы Mermaid</a>
*   Ссылки между другими импортированными страницами конвертируются в <a class="reference-link" href="../../../Note%20Types/Text/Links/Internal%20(reference)%20links.md">внутренние (ссылочные) ссылки</a>, если они являются частью того же импорта.
*   Базы данных импортируются как <a class="reference-link" href="../../../Collections.md">Коллекции</a> (см. ниже).
*   [Замечания (admonitions)](../../../Note%20Types/Text/Block%20quotes%20%26%20admonitions.md) сохраняются, включая их эмодзи (добавленные как часть содержимого).
*   Колонки импортируются как прозрачные [таблицы](../../../Note%20Types/Text/Tables.md), сохраняя определение колонок.
*   Блоки оглавления _удаляются_, так как оглавление уже присутствует в боковой панели (см. <a class="reference-link" href="../../../Note%20Types/Text/Table%20of%20contents.md">Оглавление</a>), а также в опубликованных заметках.

## Базы данных

Базы данных Notion импортируются в <a class="reference-link" href="../../../Collections.md">Коллекции</a>, где каждый элемент базы данных сохраняется как страница в коллекции. С помощью [наследуемых](../../../Advanced%20Usage/Attributes/Attribute%20Inheritance.md) <a class="reference-link" href="../../../Advanced%20Usage/Attributes/Promoted%20Attributes.md">Продвигаемых атрибутов</a> большинство свойств страниц в Notion сохраняются импортом.

Результирующей коллекцией будет <a class="reference-link" href="../../../Collections/Table.md">Таблица</a> независимо от исходного вида, в котором была экспортирована база данных. Это связано с тем, что активный вид не сохраняется в экспорте, а табличная коллекция наиболее совместима с Notion.

> [!NOTE]
> **Техническая информация**
>
> Каждое свойство страницы, которое можно сохранить согласно таблице выше, сохраняется как метка или отношение соответствующей заметке (кроме дат создания и изменения, которые сохраняются на уровне заметки).
>
> Чтобы сохранить UX, близкий к Notion, каждое свойство также превращается в <a class="reference-link" href="../../../Advanced%20Usage/Attributes/Promoted%20Attributes.md">Продвигаемые атрибуты</a> на уровне коллекции. Это также делает столбцы видимыми в табличной коллекции. Продвигаемые атрибуты делаются наследуемыми, чтобы они появлялись и при навигации по дочерним заметкам.
>
> Имена меток намеренно преобразуются в `camelCase` для соответствия соглашениям Trilium, но полное имя столбца сохраняется через механизм _Псевдонимов_ продвигаемых атрибутов.

## Ограничения

### Отсутствующие данные из импорта

Следующая информация не сохраняется импортом, так как она недоступна в экспорте и её нельзя восстановить:

*   Порядок страниц и подстраниц.
*   Даты создания/изменения восстанавливаются, только когда страница включает свойства Created time / Last edited time (коллекция или нет); в противном случае используется время импорта.

### Обложки и значок страницы

Значок или эмодзи страницы не сохраняются; у созданных заметок значок по умолчанию. Обложка не импортируется вовсе.

## Сообщение о проблемах

При импорте вашего рабочего пространства Notion вы можете обнаружить проблемы в том, как импортируется заметка; в этом случае рассмотрите возможность [сообщить о них](../../../Troubleshooting/Reporting%20issues.md).

При сообщении о такой проблеме обязательно предоставьте следующую информацию:

*   .zip-экспорт исходной заметки Notion (и дочерних, если применимо). Это позволяет нам воспроизвести проблему.
*   Снимок экрана того, как это выглядело изначально до импорта и как выглядит после импорта.
