# Evernote
Trilium может импортировать файлы ENEX, которые используются Evernote для резервного копирования/экспорта. Один файл ENEX представляет содержимое (заметки и ресурсы) одной записной книжки.

## Процесс импорта

Первый шаг — экспорт данных из Evernote:

*   Чтобы экспортировать одну записную книжку:
    *   На левой боковой панели выберите _Notebooks_.
    *   Если у вас есть стопка записных книжек, разверните её.
    *   Щёлкните правой кнопкой по записной книжке и выберите _Экспортировать записную книжку_.
    *   Убедитесь, что заданы следующие опции:
        *   Формат файла установлен в _ENEX format_.
        *   Все опции в _Экспортировать атрибуты заметок_ отмечены.
*   Чтобы экспортировать несколько заметок (до 100 заметок):
    *   На левой боковой панели выберите _Notes_.
    *   В списке заметок выделяйте отдельные заметки щелчком с <kbd>Ctrl</kbd>. Альтернативно щёлкните по заметке, а затем щёлкните с <kbd>Shift</kbd> по более удалённой заметке, чтобы выбрать все заметки между ними.
    *   Внизу должна появиться плавающая панель с несколькими опциями. Выберите \[…\] → _Экспорт._
    *   Убедитесь, что заданы следующие опции:
        *   Формат файла установлен в _ENEX format_.
        *   Все опции в _Экспортировать атрибуты заметок_ отмечены.
*   Чтобы экспортировать одну заметку:
    *   Выберите заметку.
    *   В правом верхнем углу нажмите кнопку \[…\] и выберите _Экспорт_.
    *   Убедитесь, что заданы следующие опции:
        *   Формат файла установлен в _ENEX format_.
        *   Все опции в _Экспортировать атрибуты заметок_ отмечены.

> [!TIP]
> Для массового экспорта нескольких записных книжек рассмотрите использование стороннего CLI-инструмента [evernote-backup](https://github.com/vzhd1701/evernote-backup)

Получив файлы ENEX, сделайте следующее для их импорта в Trilium:

1.  В <a class="reference-link" href="../../UI%20Elements/Note%20Tree.md">Дереве заметок</a> щёлкните правой кнопкой и выберите _Импортировать в заметку_.
2.  В разделе _Импорт из_ выберите <span class="tn-icon tn-brand tn-brand-evernote"></span> _Evernote_.
3.  Во время импорта вы увидите сообщение «Импорт выполняется». Если импорт успешен, сообщение изменится на «Импорт успешно завершён», а затем исчезнет.
4.  Мы рекомендуем проверить импортированные заметки и их вложения, чтобы убедиться, что вы не потеряли никаких данных.

## Поддерживаемые возможности

Следующие возможности сохраняются Trilium в процессе импорта:

*   Базовое форматирование (полужирный, курсив, подчёркивание, зачёркивание, цвета, выделения, надстрочный, подстрочный, выравнивание текста, встроенный код).
*   Иерархия заголовков (они сдвигаются, чтобы начинаться с H2, так как H1 зарезервирован для заголовка заметки, см. [Заголовки](../../../Note%20Types/Text/General%20formatting.md))
*   Списки дел (to-do). Новый формат задач сворачивается в стандартные списки дел
*   <a class="reference-link" href="../../../Note%20Types/Text/Images.md">Изображения</a> и <a class="reference-link" href="../../Notes/Attachments.md">Вложения</a>
*   <a class="reference-link" href="../../../Note%20Types/Text/Lists.md">Списки</a> (маркированные или нумерованные)
*   <a class="reference-link" href="../../../Note%20Types/Text/Tables.md">Таблицы</a>
*   Цитаты
*   [Замечания (admonitions)](../../../Note%20Types/Text/Block%20quotes%20%26%20admonitions.md) сохраняются, включая их эмодзи (добавленные как часть содержимого).
*   <a class="reference-link" href="../../../Note%20Types/Text/Developer-specific%20formatting/Code%20blocks.md">Блоки кода</a> с попыткой восстановить язык по мере возможности.
*   <a class="reference-link" href="../../../Note%20Types/Mermaid%20Diagrams.md">Диаграммы Mermaid</a>
*   <a class="reference-link" href="../../../Note%20Types/Text/Math%20Equations.md">Математические формулы</a>
*   Сворачиваемые разделы (toggles)
*   Внешние ссылки
*   Внутренние ссылки переписываются в <a class="reference-link" href="../../../Note%20Types/Text/Links/Internal%20(reference)%20links.md">внутренние (ссылочные) ссылки</a>, если целевая заметка является частью того же импорта.

## Ограничения

*   Лимит размера одного импорта — 250 МБ. Если общий размер ваших файлов больше, вы можете увеличить [лимит загрузки](../../../Installation%20%26%20Setup/Server%20Installation.md) или разделить файлы и запустить импорт необходимое число раз.
*   Все ресурсы (кроме изображений) создаются как вложения заметок.
*   Если у вас есть HTML внутри файлов ENEX, HTML-форматирование может быть сломано или потеряно после импорта в Trilium. См. <a class="reference-link" href="../../../Troubleshooting/Reporting%20issues.md">Сообщение о проблемах</a>.

### Ссылки на другие заметки

Начиная с v0.104.0, импортёр ENEX пытается автоматически воссоздать ссылки на другие заметки, конвертируя их Evernote-специфичные URL в <a class="reference-link" href="../../../Note%20Types/Text/Links/Internal%20(reference)%20links.md">внутренние (ссылочные) ссылки</a> Trilium.

Поскольку формат ENEX не предоставляет уникальный ID заметок, ссылки на заметки определяются по их заголовку.

Ограничения:

*   Только заметки, являющиеся частью того же импорта, будут иметь свои ссылки переписаны в ссылочные, чтобы избежать ссылок на неправильную заметку.
*   Если есть две заметки с одинаковым именем, внутренние ссылки созданы не будут, чтобы не указывать на неправильную заметку.
*   Ссылки, которые не удалось переписать (например, указывающие на отсутствующую/дублированную заметку), будут сохранены с их исходным URL `evernote://`.
*   Это не исправит ссылки на якоря и ссылки на заметки, которые вы переименовали в Evernote после созданения ссылок.

#### Постобработка заметок

> [!TIP]
> Этот скрипт позволяет переписывать ссылки после завершения импорта, а также находить ссылки между двумя разными импортами.

Если вы хотите восстановить внутренние ссылки в Trilium после импорта всех ваших файлов ENEX, вы можете использовать или адаптировать этот пользовательский скрипт: <a class="reference-link" href="Evernote/Process%20internal%20links%20by%20title.js">Process internal links by title</a>

Скрипт делает следующее:

1.  Находит все внутренние ссылки Evernote.
2.  Для каждой проверяет, совпадает ли текст ссылки с заголовком заметки, и если да, заменяет ссылку Evernote внутренней ссылкой Trilium. Если нет, оставляет ссылку Evernote на месте.
3.  Если находит более одной заметки с совпадающим заголовком, оставляет ссылку Evernote на месте.
4.  Выводит результаты в журнал, который вы можете увидеть в соответствующей кодовой заметке в Trilium.

Скрипт имеет следующие ограничения:

*   Он не исправит ссылки на якоря и ссылки на заметки, которые вы переименовали в Evernote после созданения ссылок.
*   Некоторые заголовки заметок могут быть плохо опознаны, даже если они существуют. Это особенно актуально, если заголовок заметки содержит специальные символы. Если это проблематично, рассмотрите <a class="reference-link" href="../../../Troubleshooting/Reporting%20issues.md">Сообщение о проблемах</a>.

## Сообщение о проблемах

При импорте ваших записных книжек Evernote вы можете обнаружить проблемы в том, как импортируется заметка; в этом случае рассмотрите возможность [сообщить о них](../../../Troubleshooting/Reporting%20issues.md).

При сообщении о такой проблеме обязательно предоставьте следующую информацию:

*   `.enex`-экспорт исходной заметки. Это позволяет нам воспроизвести проблему.
*   Снимок экрана того, как это выглядело изначально до импорта и как выглядит после импорта.
