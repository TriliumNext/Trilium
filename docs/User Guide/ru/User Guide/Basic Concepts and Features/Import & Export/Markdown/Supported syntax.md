# Поддерживаемый синтаксис
[GitHub-Flavored Markdown](https://github.github.com/gfm/) — основной синтаксис, которому следует Trilium.

## Изображения

При экспорте изображения обычно сохраняются в базовом синтаксисе Markdown, но будут использовать HTML-синтаксис, если у изображения есть пользовательская ширина. Рисунки (figures) всегда встраиваются как HTML.

## Таблицы

Простые таблицы поддерживаются синтаксисом Markdown. Если таблица слишком сложна или содержит элементы, которые отображались бы как HTML, таблица также отображается как HTML.

## Ссылки

Поддерживаются стандартные Markdown-ссылки.

Внутренние ссылки Trilium (которые отражают заголовок заметки и показывают её значок) встраиваются как HTML, чтобы сохранить информацию при импорте.

<a class="reference-link" href="../../../Note%20Types/Text/Anchors.md">Якоря</a> также сохраняются как HTML, поэтому ссылки на якорь всё ещё ведут к нему после повторного импорта заметки.

## Математические формулы

Поддерживаются как встроенные, так и блочные формулы, использующие синтаксисы `$` и `$$`.

## Замечания (Admonitions)

Синтаксис Markdown для замечаний, поддерживаемый Trilium, — это тот, который использует GitHub, а именно:

```
> [!NOTE]
> This is a note.

> [!TIP]
> This is a tip.

> [!IMPORTANT]
> This is a very important information.

> [!CAUTION]
> This is a caution.
```

В настоящее время нет планов поддерживать альтернативные синтаксисы замечаний, такие как `!!! note`.

## Вкладки (Tabs)

Вкладки используют синтаксис [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/reference/content-tabs/): каждая вкладка начинается со строки `=== "Заголовок"`, за которой следует её содержимое с отступом в четыре пробела. Последовательные вкладки образуют один блок вкладок, а `===!` начинает новый блок сразу после другого:

```
=== "Windows"

    Run the **installer**.

=== "Linux"

    Use the package.

===! "Another block"

    This tab starts a separate tabs block.
```

Вкладки можно вкладывать, делая отступ для внутренних вкладок внутри содержимого вкладки. Заголовок вкладки — простой текст, поэтому его форматирование не сохраняется при экспорте. О том, как работают блоки вкладок в текстовой заметке, см. <a class="reference-link" href="../../../Note%20Types/Text/Content%20tabs.md">Вкладки содержимого</a>.

## Боковые блоки (Aside blocks)

<a class="reference-link" href="../../../Note%20Types/Text/Aside%20blocks.md">Боковые блоки</a> записываются как теги `<aside>` на отдельных строках, с содержимым между ними в Markdown:

```
<aside>

A **side note** at the right of the text.

</aside>
```

Простой тег `<aside>` размещается и окрашивается как вновь вставленный боковой блок: справа, с обтеканием текста вокруг него, на сером фоне. Тег с атрибутами принимает только то, что они задают. Для другого положения добавьте атрибут `data-position` с одним из этих значений:

| Значение | Положение |
| --- | --- |
| `wrap-left` | _Обтекание текста_ → _По левому краю_ |
| `wrap-right` | _Обтекание текста_ → _По правому краю_, по умолчанию |
| `left` | _Разрыв текста_ → _По левому краю_ |
| `center` | _Разрыв текста_ → _По центру_ |
| `right` | _Разрыв текста_ → _По правому краю_ |

Для цвета фона добавьте атрибут `style`, например `style="background-color:#4d99e6"`. Без него тег с атрибутами даёт прозрачный боковой блок.

Экспорт следует тем же правилам, а также сохраняет ширину изменённого размера бокового блока.

Пустая строка после открывающего тега обязательна. Без неё содержимое читается как обычный текст вместо Markdown, и боковой блок занимает полную ширину заметки.

## Викиссылки (Wikilinks)

Базовая поддержка викиссылок добавлена в v0.96.0:

*   `[[foo/bar]]` будет искать файл `bar.md` в каталоге `foo` и превращать его во внутреннюю ссылку.
*   `![[foo/baz.png]]` будет искать файл `baz.png` в каталоге `foo` и превращать его в изображение.

Эта возможность работает только на импорте, то есть она превращает викиссылки в совместимый с Trilium синтаксис, но не будет экспортировать заметки Trilium в Markdown-файлы с этим синтаксисом.

> [!IMPORTANT]
> Путь к страницам в викиссылках разрешается относительно _корня импорта_, а не текущего каталога заметки. Это согласуется с другими платформами, использующими викиссылки, такими как SilverBullet.
>
> Корневой путь импорта определяется следующим образом:
>
> *   Если в архиве на корневом уровне есть один каталог, то этот каталог считается корнем.
> *   Если на корневом уровне есть несколько файлов и каталогов, то корнем считается корень архива (содержащий все эти элементы).

## Выделения

Фоновые выделения поддерживаются двумя способами:

*   Markdown-расширение `==`, поддерживаемое другими Markdown-приложениями, такими как Obsidian:

    ```
    ==highlighted==
    ```
*   Каноническое HTML-представление выделений, как поддерживается Trilium:

    ```html
    <span style="background-color:hsl(0,0%,100%);">Highlighted</span>
    ```

При использовании жёлтого выделения импорт/экспорт предпочитает синтаксис `==`, тогда как в остальных случаях используется каноническое HTML-представление.
