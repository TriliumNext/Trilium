# ИИ
Trilium может подключаться к языковой модели и использовать её как помощника, работающего прямо с вашими заметками: задавайте вопросы о заметке, которую читаете, просите черновить или перестраивать содержимое или писать скрипты и виджеты.

По умолчанию интеграция выключена и ничего не делает, пока вы её не включите и не настроите провайдера; собственной модели в Trilium нет. Выбранный провайдер определяет, как путешествуют ваши заметки: облачный API с оплатой за использование, уже оплаченная подписка или модель на собственном оборудовании — в последнем случае ничего не покидает машину. См. <a class="reference-link" href="AI/Providers.md">Провайдеры</a>, чтобы узнать, что влечёт каждый вариант, и <a class="reference-link" href="AI/Privacy.md">Конфиденциальность</a> — что именно отправляется.

После включения помощник доступен:

*   Как отдельный тип заметки: может читать и изменять заметки через инструменты, которые можно отключать для каждого диалога, если хотите, чтобы ИИ видел только то, что вы набираете.
*   Панель в правой боковой панели — работает как тип заметки, но с дополнительным доступом к текущей заметке.
*   <a class="reference-link" href="Note%20Types/Text/In-editor%20AI%20assistant.md">Встроенный ИИ-ассистент в редакторе</a> со встроенными действиями над выделенным текстом (проверка, резюмирование) и <a class="reference-link" href="Note%20Types/Text/In-editor%20AI%20assistant/Custom%20AI%20quick%20actions.md">пользовательскими быстрыми действиями ИИ</a>.

## Основные возможности

*   Чат-интерфейс с потоковой передачей сообщений.
*   Передача ИИ контекста текущей заметки.
*   Инструменты для изменения содержимого заметок, создания новых заметок и т.д.
*   Статистика использования контекстного окна и стоимости каждого сообщения.
*   Вложения для мультимодального чата (изображения, текстовые файлы, PDF).
*   Опциональный MCP для доступа внешних чат-инструментов (например, Claude Code) к заметкам в Trilium.

## Примеры использования

*   Создание любых <a class="reference-link" href="Scripting/Frontend%20Basics/Custom%20Widgets.md">пользовательских виджетов</a>.
*   Простое создание <a class="reference-link" href="Note%20Types/Render%20Note.md">Render Note</a>, например: _Создай render note, в котором можно играть в крестики-нолики. Обязательно используй Preact вместо устаревшего jQuery._
*   Создание виджетов для <a class="reference-link" href="Collections/Dashboard.md">панели мониторинга (Dashboard)</a>: калькулятор, секундомер, таймер помодоро.

> [!NOTE]
> Claude Sonnet известен тем, что создаёт очень хорошие клиентские и серверные скрипты с минимальными указаниями, поскольку ИИ обучен их производить.

## Включение интеграции ИИ

Чтобы включить интеграцию ИИ, откройте <a class="reference-link" href="Basic%20Concepts%20and%20Features/UI%20Elements/Options.md">Настройки</a> → _AI / LLM_ и нажмите переключатель в правом верхнем углу диалога, затем настройте провайдера.

## Создание нового чата

Есть два интерфейса чата:

*   В боковой панели.
*   Отдельный тип заметки.

### Интерфейс боковой панели

### Отдельный тип заметки

Отдельная заметка-чат похожа на интерфейс боковой панели, но длинные диалоги в ней удобнее читать.

В отличие от боковой панели, ИИ не будет знать, в какой заметке находится.

### Шаблоны

Заметки-чаты можно назначать <a class="reference-link" href="Advanced%20Usage/Templates.md">шаблонами</a> для удобного повторного использования. Вся история диалога сохраняется, что даёт базовую специализацию LLM: существующий чат работает как системный промпт.

### Выбор модели

Когда провайдер настроен в <a class="reference-link" href="Basic%20Concepts%20and%20Features/UI%20Elements/Options.md">Настройках</a>, следующий шаг — выбрать модели, доступные для чата.

Модели запрашиваются у провайдера динамически, только когда список выбора моделей виден. Чтобы изменить список моделей, нажмите кнопку _Изменить_ в поле выбора модели.

Если модели не удаётся получить, список показывает причину (например, отказ в соединении или неверный API-ключ). Чтобы повторить после устранения причины (например, запуска локального сервера), нажмите _Повторить_.

Информация о ценах отображается для известных моделей. Информация о ценах (цена за миллион токенов) встроена в приложение (по данным LiteLLM) и обновляется вместе с новыми версиями Trilium. Локальные провайдеры считаются бесплатными, а для пользовательских endpoints информация о ценах недоступна.

## Возможности

### Поиск в интернете

ИИ может при необходимости искать информацию в интернете по заданной теме.

Источник поиска выбирается в подменю _Поиск в интернете_ меню <span class="tn-icon bx bx-shield-quarter"></span>_Инструменты_ рядом с выбором модели в нижней части чата; строка этого меню показывает используемый источник:

*   _Отключён_ выключает поиск в интернете для этого чата.
*   _Встроенный поиск модели_ (по умолчанию) позволяет модели искать через поиск её провайдера. Встроенный поиск есть у моделей Anthropic, OpenAI, Google Gemini и DeepSeek, а также у Claude Code, Google Antigravity и OpenAI Codex. У OpenRouter, Ollama, LM Studio и пользовательских endpoints его нет, поэтому для их моделей этот вариант отключён. Поиск DeepSeek тарифицируется за каждый поиск на вашем аккаунте DeepSeek и работает только с родным endpoint DeepSeek, а не с пользовательским base URL.
*   Поисковый провайдер (Brave Search, Tavily, Exa, Serper, Perplexity или SearXNG) выполняет поиск через этот сервис независимо от отвечающей модели. Поисковые провайдеры добавляются в разделе _Поисковые провайдеры_ настроек ИИ, который открывает пункт _Управление поисковыми провайдерами_ внизу подменю. Браузерная версия не может использовать Brave Search, Exa и Perplexity — эти сервисы отклоняют запросы со страниц, поэтому там они отображаются отключёнными.

После ввода параметров подключения добавление поискового провайдера выполняет тестовый поиск и показывает первые результаты или причину сбоя (например, отказ в соединении или неверный API-ключ). _Повторить_ запускает тест заново; _Добавить в любом случае_ добавляет провайдера несмотря на сбой, что полезно, когда сервис ещё не запущен. При изменении поискового провайдера тест запускается заново, только если изменились его API-ключ или адрес.

Чтобы использовать SearXNG, включите его JSON-вывод, добавив `json` в форматы поиска в `settings.yml` инстанса. По умолчанию SearXNG отключает JSON, и без него каждый поиск завершается ошибкой.

```yaml
search:
  formats:
    - html
    - json
```

SearXNG не использует API-ключи, поэтому оставьте поле ключа пустым. Заполняйте его, только если ваш инстанс находится за прокси, требующим токен; Trilium отправляет его как bearer-токен в заголовке `Authorization`.

Включён ли поиск в интернете, хранится для каждого чата; источник поиска общий для всех чатов. Вариант, недоступный текущей модели, остаётся в меню отключённым; наведите курсор на значок <span class="tn-icon bx bx-info-circle"></span> рядом с ним, чтобы узнать причину. Claude Code, GitHub Copilot, Google Antigravity и OpenAI Codex запускают собственные инструменты, поэтому не могут использовать поисковый провайдер.

В чате поиск через поискового провайдера показывает логотип провайдера в начале своей строки вместо значка лупы <span class="tn-icon bx bx-search"></span>; наведите курсор на логотип, чтобы увидеть имя провайдера.

С поисковым провайдером модель может также читать найденные страницы или переданную вами ссылку как текст: Trilium сам загружает страницу и передаёт модели до первых 20 000 символов. Адреса на вашей машине или сети отклоняются. В браузерной версии большинство сайтов не разрешают такое чтение, поэтому там оно обычно не удаётся.

### Рассуждение (Thinking)

Некоторые модели рассуждают перед ответом. Пока модель думает, её рассуждение показывается полностью под индикатором; по завершении оно сворачивается в строку _Процесс рассуждения_ над ответом.

Объём рассуждения задаётся для каждого чата одним из двух способов в зависимости от модели:

*   У большинства моделей есть кнопка <span class="tn-icon bx bx-brain"></span>_Расширенное рассуждение_ рядом с кнопкой <span class="tn-icon bx bx-shield-quarter"></span>_Инструменты_.
*   У моделей с несколькими уровнями рассуждения (DeepSeek V4, рассуждающие модели OpenRouter, OpenAI Codex, Antigravity) рядом с выбором модели есть раскрывающийся список усилия рассуждения <span class="tn-icon bx bx-brain"></span>. _Нет_, где предлагается, выключает рассуждение; более высокие уровни дают лучшие ответы на сложные вопросы, но занимают больше времени и стоят дороже.

> [!NOTE]
> Раскрывающийся список усилия появляется, только когда Trilium знает уровни модели. Для провайдера DeepSeek, настроенного в более ранней версии Trilium, отредактируйте провайдера в поле выбора модели и один раз нажмите _Сохранить_.

### Доступ к заметкам (инструменты)

Инструменты позволяют агентному ИИ понимать заметки и работать с ними прямо в вашем инстансе Trilium.

Эта возможность включена по умолчанию. Чтобы отключить её, нажмите кнопку <span class="tn-icon bx bx-shield-quarter"></span>_Инструменты_ рядом с выбором модели в нижней части чата и выключите _Доступ к заметкам_. Кнопка _Инструменты_ подсвечивается, пока включён доступ к заметкам или поиск в интернете.

Несколько инструментов, которые Trilium предоставляет LLM:

*   На уровне заметки:
    *   Поиск заметок.
    *   Получение метаданных или содержимого заметки.
    *   Редактирование заметки
        *   Есть несколько механизмов редактирования заметки LLM: полная перезапись, поиск/замена фрагмента текста или добавление в конец.
        *   При перезаписи заметки LLM может также изменить её тип (например, из текстовой в код) или язык кодовой заметки, переписав содержимое соответствующим образом.
        *   При любом изменении ИИ сохраняется [ревизия](Basic%20Concepts%20and%20Features/Notes/Note%20Revisions.md), позволяющая откатить нежелательные правки.
    *   Создание новой заметки
        *   Попросив о рисунке, LLM может создать заметку с изображением SVG или превратить существующую заметку в таковую. Он может писать только изображения SVG, не другие форматы вроде PNG.
    *   Переименование или удаление заметки.
*   На уровне атрибутов:
    *   Получение полного списка атрибутов или конкретного атрибута.
    *   Установка значения атрибута или добавление ещё одного значения к существующим (например, второй `#tag`). Когда установка значения заменяет существующее, ИИ сообщает, какое значение заменил.
        *   Атрибут, запускающий код, такой как `#run`, `#widget` или `~renderNote`, сохраняется с префиксом `disabled:` (например, `#disabled:widget`), как при безопасном импорте (см. <a class="reference-link" href="Basic%20Concepts%20and%20Features/Active%20content.md">Активное содержимое</a>). Если у заметки этот атрибут был включён, а ИИ устанавливает значение, а не добавляет его, ИИ удаляет включённый вариант, чтобы ничего не выполнялось, пока вы не включите новое значение. ИИ сообщает, о какой заметке идёт речь; проверьте код, затем включите его переключателем рядом со значком активного содержимого возле заголовка заметки или, для <a class="reference-link" href="Note%20Types/Render%20Note.md">Render Note</a>, кнопкой _Включить render note_ в заметке.
    *   Удаление атрибута.
*   На уровне дерева:
    *   Получение прямых дочерних заметок.
    *   Получение всего поддерева заметки.
    *   Перемещение или клонирование заметки в другое место.
*   Для <a class="reference-link" href="Basic%20Concepts%20and%20Features/Notes/Attachments.md">Вложений</a>:
    *   Получение метаданных вложения.
    *   Получение содержимого вложения.
*   Навыки (skills, см. отдельный раздел).

Каждый использованный ИИ инструмент появляется в чате строкой с именем инструмента и заметкой или запросом, над которыми он работал; переименованная заметка показывает прежний заголовок зачёркнутым, удалённая — зачёркнутый заголовок, перемещённая — откуда и куда перемещена, атрибут, который ИИ прочитал, установил, добавил или удалил, — плашкой (зачёркнутой после удаления), вложение — заголовком, заметкой и размером, а прочитанная ИИ веб-страница — ссылкой. Строка раскрывается, только когда есть что прочитать прямо в ней: заметки, найденные поиском, страницы, найденные веб-поиском, значки, найденные поиском значков, тип, атрибуты или начало содержимого прочитанной ИИ заметки, все атрибуты заметки, текст вложения или веб-страницы, страницы руководства пользователя, которые ИИ просмотрел, или его оглавление (оба открываются в панели справки), дочерние или всё поддерево заметки, что ИИ записал в созданную, переписанную или дополненную заметку, изменения правки или причина сбоя инструмента. Строка поиска называет часть дерева, в которой он ограничен, если таковая есть, а также показывает, сколько заметок найдено и сколько совпадений ИИ запросил; каждую перечисленную заметку можно открыть щелчком. Чтобы увидеть, что именно ИИ отправил инструменту и что получил в ответ, наведите курсор на строку и нажмите кнопку <span class="tn-icon bx bx-code-alt"></span> рядом с ней; на сенсорных экранах кнопка показана всегда.

Когда ответ не движется пару секунд, пока ИИ продолжает работу, например читает результат инструмента, под ним появляется строка _Всё ещё работает…_ до следующей части ответа.

#### Подтверждение вызовов инструментов

Перед запуском инструмента чат спрашивает разрешения. Строка инструмента помечена значком <span class="tn-icon bx bxs-hand"></span> и имеет кнопки _Разрешить_ и _Отклонить_. Если вызов изменяет заметку, строка раскрывается на текст, который будет записан, или на изменения правки. Ответ ждёт вашего решения.

*   Чтобы вызов выполнился, нажмите _Разрешить_.
*   Чтобы больше не спрашивать об этом инструменте в текущем чате, откройте меню рядом с _Разрешить_ и выберите всегда разрешать этот инструмент для данного чата. Вызов выполняется, как и остальные ожидающие вызовы этого инструмента и все последующие в этом чате. Другие инструменты продолжают спрашивать, а новый чат спросит снова.
*   Чтобы отказать, нажмите _Отклонить_. ИИ получает сообщение об отказе и продолжает ответ без вызова, который помечается _отклонён_.
*   Остановка ответа отклоняет все ожидающие вызовы.

Чтобы чат снова спрашивал об инструменте, откройте меню <span class="tn-icon bx bx-shield-quarter"></span>_Инструменты_ в нижней части чата и в разделе _Разрешено в этом чате_ нажмите на инструмент. Подменю показывается, когда чат разрешил хотя бы один инструмент.

То, какие вызовы спрашивают, зависит от режима разрешений чата, выбранного в меню <span class="tn-icon bx bx-shield-quarter"></span>_Инструменты_ в пункте _Разрешения_:

*   _Всегда спрашивать_: спрашивает каждый вызов, включая только читающие (поиск заметок, чтение заметки или вложения).
*   _Спрашивать перед изменениями_: только читающие вызовы выполняются сами, а изменяющие ваши заметки (создание, правка, переименование, перемещение или удаление заметки, а также установка, добавление или удаление атрибута) спрашивают.
*   _Не спрашивать_: каждый вызов выполняется без вопросов, включая изменения.

Новый чат начинается в режиме, выбранном последним в любом чате, или в режиме _Спрашивать перед изменениями_, пока вы не выберете иной. Выбор _Не спрашивать_ поэтому переносится и в следующий чат.

Инструмент, разрешённый для чата, выполняется без вопросов в любом режиме. То же касается поиска в поставляемых с Trilium материалах (руководство пользователя, навыки, обучающие ИИ поисковому синтаксису и типам заметок, и значки), поскольку он не читает ваши заметки. Поиск в интернете и чтение веб-страниц тоже никогда не спрашивают: разрешение даёт само включение поиска в интернете в меню _Инструменты_ — независимо от того, ищет модель сама или через поискового провайдера.

> [!NOTE]
> <a class="reference-link" href="AI/Providers/Subscription-based%20providers.md">Провайдеры по подписке</a> (Claude Code, GitHub Copilot, Google Antigravity и OpenAI Codex) спрашивают как любой другой провайдер.

> [!NOTE]
> Большинство разрешённых изменений можно отменить: удалённую заметку можно восстановить, а правку откатить из ревизии. Установку атрибута отменить сложнее, так как у атрибутов нет истории.

> [!NOTE]
> Gemini не может использовать встроенный поиск при включённом доступе к заметкам. Пока доступ включён, вариант встроенного поиска в меню _Инструменты_ отключён и объясняет причину; поисковый провайдер работает при включённом доступе к заметкам.

### Вложения

Начиная с Trilium v0.140.0, <a class="reference-link" href="Basic%20Concepts%20and%20Features/Notes/Attachments.md">Вложения</a> позволяют мультимодальный чат:

*   Растровые изображения (отправляются как vision-ввод, кроме SVG) в форматах: PNG, JPEG, GIF, WebP.
*   PDF, отправляются нативно провайдеру (поддерживают Anthropic, OpenAI и Google).
*   Изображения SVG (отправляются как исходный HTML).
*   Текстовые файлы.

Не каждая модель читает каждый вид вложений: DeepSeek не читает PDF и читает изображения только vision-моделями; OpenAI Codex, GitHub Copilot и Google Antigravity читают изображения, но не PDF. Для такой модели:

*   Кнопка вложения предлагает только поддерживаемые виды, а вставленный или перетащенный нечитаемый файл не прикрепляется.
*   После переключения на такую модель нечитаемое вложение помечается предупреждением <span class="tn-icon bx bx-error"></span>, и сообщение нельзя отправить, пока вложение не удалено или не выбрана другая модель.
*   Вложение, отправленное в более раннем сообщении, доходит до модели только своим именем, например `[прикреплённый файл: report.pdf]`, чтобы она могла сообщить, что не видит содержимого.

Чтобы загрузить вложение:

*   Нажмите кнопку _Прикрепить_ (значок скрепки) под текстовым полем.
*   Вставьте изображение из буфера обмена через Ctrl+V.

После загрузки одного или нескольких вложений они появляются прямо над текстовым полем:

*   У изображений есть небольшая миниатюра для удобного распознавания.
*   Каждое вложение можно удалить кнопкой X.

Щелчок по изображению или PDF — по плашке над текстовым полем или по месту в отправленном сообщении — открывает его в просмотрщике: изображение можно масштабировать и перемещать, PDF читать постранично. Кнопка рядом с кнопкой закрытия просмотрщика открывает исходный файл в новой вкладке браузера. <kbd>Ctrl</kbd>-щелчок вместо этого открывает изображение в новой вкладке браузера, а PDF — как вложение в новой вкладке Trilium.

Когда вложение присутствует, LLM получает инструкцию рассматривать вложение в приоритетном порядке, даже если у неё есть доступ к текущей заметке.

> [!NOTE]
> В настоящее время Trilium не выполняет предварительную обработку вложений (например, <a class="reference-link" href="Advanced%20Usage/Text%20Extraction%20(OCR).md">извлечение текста (OCR)</a>) перед отправкой провайдеру LLM.

### Упоминания

Упоминания — способ вставить ссылки на заметки, отличные от текущей, тем же механизмом, что и <a class="reference-link" href="Note%20Types/Text/Links/Internal%20(reference)%20links.md">внутренние (ссылочные) ссылки</a>. Чтобы сослаться на другую заметку, просто введите @, а затем имя заметки.

Эта возможность наиболее полезна при включённых инструментах заметок, иначе у LLM не будет способа обратиться к указанной заметке.

### Навыки (Skills)

Навыки в Trilium — это специализированные наборы инструкций, которые помогают ИИ быть продуктивнее, понимая, как устроен Trilium.

Эти навыки не загружаются по умолчанию, чтобы не увеличивать расход токенов, но ИИ может загрузить их по требованию, если включены _Инструменты заметок_.

Встроенные навыки:

*   Синтаксис поиска: понимание полного синтаксиса <a class="reference-link" href="Basic%20Concepts%20and%20Features/Navigation/Search.md">Поиска</a>.
*   Серверные скрипты: чтобы писать корректные <a class="reference-link" href="Scripting/Backend%20scripts.md">серверные скрипты</a>.
*   Клиентские скрипты: чтобы писать корректные [клиентские скрипты](Scripting/Frontend%20Basics.md) (базовые скрипты, виджеты, <a class="reference-link" href="Note%20Types/Render%20Note.md">Render Note</a>).
*   Панели мониторинга: построение <a class="reference-link" href="Collections/Dashboard.md">Dashboard</a> и его виджетов, включая интерактивные на основе <a class="reference-link" href="Note%20Types/Render%20Note.md">Render Note</a>.

Когда _Инструменты заметок_ включены, навыки автоматически доступны ИИ, и взаимодействие пользователя не требуется.

> [!NOTE]
> Пользовательские навыки пока не поддерживаются, но планируются.

### MCP

Trilium поставляется со встроенным MCP-сервером, позволяющим внешнему агенту, такому как Claude Code, иметь доступ к вашей базе данных. Подробности см. на отдельной странице <a class="reference-link" href="AI/MCP.md">MCP</a>.

## История

### Удаление в v0.102.0

Начиная с версии v0.102.0, интеграция ИИ/LLM была удалена из ядра Trilium Notes.

Несмотря на значительные усилия, вложенные в разработку этой возможности, долгосрочное сопровождение и поддержка оказались неподъёмными.

При обновлении до v0.102.0 ваши заметки-чаты сохранятся, но вместо специального окна чата они будут превращены в обычную <a class="reference-link" href="Note%20Types/Code.md">кодовую</a> заметку с открывающимся исходным JSON диалога.

### Возвращение в v0.103.0

С учётом недавнего прогресса в области ИИ мы решили дать интеграции LLM ещё один шанс. v0.103.0 представляет полностью новую систему чатов.

Одно из ключевых изменений, приведших к повторной реализации: теперь мы используем библиотеку [Vercel AI](https://github.com/vercel/ai) для управления внутренним механизмом и различиями между провайдерами LLM вместо собственной реализации.
