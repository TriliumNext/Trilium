# v0.103.0: `cheerio` объявлена устаревшей
Библиотека `api.cheerio` объявлена устаревшей и будет удалена в одной из будущих версий.

> [!NOTE]
> `cheerio` была удалена в v0.106.0. Полное руководство по миграции см. в разделе <a class="reference-link" href="v0.106.0%20Removal%20of%20cheerio.md">v0.106.0: Удаление cheerio</a>.

## Причины

Cheerio используется только в API для скриптов, тогда как сервер внутри применяет `node-html-parser` для разбора HTML. Удаление `cheerio` уменьшает размер сборки и затраты на сопровождение.

## Миграция

До (`cheerio`):

```javascript
const $ = api.cheerio.load(html);
const title = $('h1').text();
const links = $('a').map((i, el) => $(el).attr('href')).get();
```

После (`htmlParser`):

```javascript
const root = api.htmlParser.parse(html);
const title = root.querySelector('h1')?.textContent;
const links = root.querySelectorAll('a').map(a => a.getAttribute('href'));
```
