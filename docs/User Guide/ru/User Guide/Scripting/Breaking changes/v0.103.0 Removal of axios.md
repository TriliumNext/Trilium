# v0.103.0: Удаление axios
Библиотека `api.axios` была удалена из серверного API для скриптов.

Скрипты, пытающиеся использовать `api.axios`, теперь будут выбрасывать ошибку с инструкциями по миграции.

## Причины

Axios была помечена как устаревшая как минимум с апреля 2024 года в пользу нативного `fetch()` API, доступного как в браузере, так и в среде Node.js. Спустя два года после объявления устаревшей библиотека была удалена вследствие [компрометации цепочки поставок npm в марте 2026 года](https://www.malwarebytes.com/blog/news/2026/03/axios-supply-chain-attack-chops-away-at-npm-trust), когда злоумышленники опубликовали вредоносные версии, устанавливавшие троян удалённого доступа. Основной разработчик Trilium едва не подвергся компрометации, но благодаря тому, что `pnpm` не доверяет неизвестным post-install скриптам, этого удалось избежать.

## Миграция

Замените вызовы `api.axios` на нативный `fetch()` API.

### Запросы `GET`

До (Axios):

```javascript
const response = await api.axios.get('https://api.example.com/data');
const data = response.data;
```

После (`fetch`):

```javascript
const response = await fetch('https://api.example.com/data');
const data = await response.json();
```

### Запросы `POST`

До (Axios):

```javascript
await api.axios.post('https://api.example.com/data', { key: 'value' });
```

После (fetch):

```javascript
await fetch('https://api.example.com/data', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ key: 'value' })
});
```
