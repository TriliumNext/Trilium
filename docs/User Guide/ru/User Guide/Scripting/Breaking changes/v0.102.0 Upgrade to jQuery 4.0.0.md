# v0.102.0: Обновление до jQuery 4.0.0
В jQuery 4 удалена поддержка устаревших браузеров (таких как IE11), а также ряд API, считающихся устаревшими, например:

> `jQuery.isArray`, `jQuery.parseJSON`, `jQuery.trim`, `jQuery.type`, `jQuery.now`, `jQuery.isNumeric`, `jQuery.isFunction`, `jQuery.isWindow`, `jQuery.camelCase`, `jQuery.nodeName`, `jQuery.cssNumber`, `jQuery.cssProps` и `jQuery.fx.interval`.
> 
> Используйте вместо них нативные аналоги, такие как `Array.isArray()`, `JSON.parse()`, `String.prototype.trim()` и `Date.now()`.

Это может затронуть пользовательские скрипты, если они (или используемые ими сторонние библиотеки jQuery) зависят от устаревших API.

Обратите внимание, что Trilium добавляет полифилы для `jQuery.isArray`, `isFunction` и `isPlainObject`, поскольку они требуются одной из наших зависимостей (автодополнению).

Подробнее читайте в [официальном посте в блоге](https://blog.jquery.com/2026/01/17/jquery-4-0-0/).
