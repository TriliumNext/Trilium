# v0.106.0: Удаление cheerio
Библиотека `api.cheerio` была удалена из серверного API для скриптов.

Скрипты, пытающиеся использовать `api.cheerio`, теперь будут выбрасывать ошибку с инструкциями по миграции.

## Причины

`cheerio` была объявлена устаревшей в v0.103.0 в пользу `api.htmlParser` ([node-html-parser](https://github.com/taoqf/node-fast-html-parser)), которую Trilium уже использует для всего собственного разбора HTML. API для скриптов оставался единственным местом, где всё ещё требовалась `cheerio`.

Поставка обоих парсеров обходилась дорого, поскольку `cheerio` загружалась при запуске на каждой платформе. Она добавляла примерно 1,35 МБ собранного кода к серверной и десктопной сборкам и около 370 КБ к браузерной сборке, где загружалась в воркер базы данных ещё до запуска приложения.

## Миграция

Замените вызовы `api.cheerio` на `api.htmlParser`. Обратите внимание, что `api.htmlParser` возвращает обычные элементы, а не обёрнутую коллекцию, поэтому здесь нет объекта `$` и цепочек вызовов.

### Чтение значений

До (`cheerio`):

```javascript
const $ = api.cheerio.load(html);
const title = $('h1').text();
const links = $('a').map((i, el) => $(el).attr('href')).get();
```

После (`htmlParser`):

```javascript
const root = api.htmlParser.parse(html);
const title = root.querySelector('h1')?.textContent;
const links = root.querySelectorAll('a').map(a => a.getAttribute('href'));
```

### Изменение документа

До (`cheerio`):

```javascript
const $ = api.cheerio.load(html);
$('a').each((i, el) => {
    $(el).attr('href', '#root/' + noteId);
    $(el).addClass('reference-link');
});
note.setContent($('body').html());
```

После (`htmlParser`):

```javascript
const root = api.htmlParser.parse(html);
for (const el of root.querySelectorAll('a')) {
    el.setAttribute('href', '#root/' + noteId);
    el.classList.add('reference-link');
}
note.setContent(root.toString());
```

### Эквивалентные операции

| `cheerio` | `htmlParser` |
| --- | --- |
| `api.cheerio.load(html)` | `api.htmlParser.parse(html)` |
| `$('sel')` | `root.querySelectorAll('sel')` |
| `$('sel').first()` | `root.querySelector('sel')` |
| `$el.text()` | `el.textContent` |
| `$el.html()` | `el.innerHTML` |
| `$el.attr('name')` | `el.getAttribute('name')` |
| `$el.attr('name', value)` | `el.setAttribute('name', value)` |
| `$el.addClass('name')` | `el.classList.add('name')` |
| `$('body').html()` | `root.toString()` |
