# v0.107.0: Удаление старого макета
_Новый макет_ — это серия изменений UI/UX, представленная в v0.101.0, которая существенно перерабатывает существующие элементы интерфейса и добавляет новые. Цель нового макета — осовременить приложение, сделать его более интуитивным и одновременно уменьшить визуальную перегруженность.

Начиная с v0.107.0, старый макет был **полностью удалён**. Эта страница служит руководством по миграции, чтобы лучше понять, что изменилось.

## Новые возможности

*   В нижней части окна появилась новая панель — <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Status%20bar.md">Строка состояния</a>. На ней размещены различные элементы, такие как навигационная цепочка (хлебные крошки), а также информация и настройки текущей заметки, включая [язык содержимого](../../Note%20Types/Text/Content%20language%20%26%20Right-to-left%20support.md) и <a class="reference-link" href="../../Advanced%20Usage/Attributes.md">Атрибуты</a>.
*   Когда создаётся новая пустая <a class="reference-link" href="../../Note%20Types/Text.md">Текстовая</a> заметка, под заголовком появляется <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/Notes/New%20note%20type%20switcher.md">Переключатель типа новой заметки</a>, позволяющий быстро переключиться на другой тип заметки, шаблон или коллекцию.
*   <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/Notes/Note%20badges.md">Значки заметки</a> отображаются справа от заголовка заметки и указывают на такие состояния, как «только для чтения» или опубликованные заметки, а также предоставляют соответствующие действия (временное разрешение редактирования, просмотр опубликованной заметки и т. д.). Они заменяют часть плавающих кнопок.
*   <a class="reference-link" href="#root/_hidden/_options/_optionsTextNotes">Текстовые заметки</a> получили новый встроенный заголовок увеличенного размера с отображением дат создания и изменения, который сворачивается в компактный заголовок при прокрутке.
*   Следующие разделы стали сворачиваемыми и отображаются под [заголовком заметки](../../Basic%20Concepts%20and%20Features/Notes/Title.md):
    *   <a class="reference-link" href="../../Advanced%20Usage/Attributes/Promoted%20Attributes.md">Продвигаемые атрибуты</a>
        *   Сочетание клавиш, ранее использовавшееся для открытия вкладки продвигаемых атрибутов на ленте (которое перестало работать), теперь переназначено на переключение отображения продвигаемых атрибутов.
    *   _Изменённые заметки_ (теперь переименовано в _Заметки, изменённые в этот день_), отображаемые в <a class="reference-link" href="../../Advanced%20Usage/Advanced%20Showcases/Day%20Notes.md">Ежедневных заметках</a>, теперь показываются под заголовком.
        *   Свёрнут раздел или развёрнут, зависит от настройки в <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Options.md">Настройках</a> → Внешний вид.
    *   _Свойства поиска_, отображаемые для полного <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/Navigation/Search.md">Поиска</a> и <a class="reference-link" href="../../Note%20Types/Saved%20Search.md">Сохранённого поиска</a>.
*   <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/Notes/Save%20status%20indicator.md">Индикатор состояния сохранения</a>, который появляется в области <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/Notes/Note%20badges.md">Значков заметки</a> и показывает наличие несохранённых изменений.

## Переход со старого макета

### Удаление ленты

Самое значительное изменение — удаление ленты. Все действия и параметры с ленты были интегрированы в другие части приложения.

Вот где теперь находятся все вкладки, ранее входившие в состав ленты:

*   «Панель форматирования» перемещена в верхнюю часть страницы.
    *   Вместо отдельной панели для каждого разделения экрана теперь используется одна панель форматирования на вкладку. Это даёт больше места для кнопок панели.
*   «Собственные атрибуты» и «Унаследованные атрибуты» объединены и перенесены в область строки состояния (отображаются друг над другом).
*   «Основные свойства» интегрированы в меню <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20menu.md">Меню заметки</a>.
    *   Единственное исключение — выпадающий список выбора языка, который теперь находится в строке состояния (в правом верхнем углу экрана).
*   Вкладки «Файл» и «Изображение»
    *   Кнопки перенесены справа от заголовка заметки в виде отдельных пунктов в <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20menu.md">Меню заметки</a>.
    *   Раздел информации объединён с разделом _Информация о заметке_ в строке состояния.
*   Изменённые заметки
    *   Перенесены под заголовок в сворачиваемую область, а сами заметки отображаются в виде значков/чипов.
    *   Развёрнут раздел или свёрнут, зависит от параметра _Expand “Notes edited on this day” on day notes_ в Настройки → Внешний вид → _Интерфейс пользователя_.
*   Вкладка определения поиска
    *   Перенесена под заголовок в сворачиваемую область.
    *   По умолчанию развёрнута для новых поисков и свёрнута для сохранённых поисков.
*   Карта заметок теперь находится в меню <span class="tn-icon bx bx-dots-horizontal-rounded"></span> действий с заметкой.
    *   Вместо открытия в панели на ленте карта заметок теперь открывается на боковой панели во вкладке <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Right%20Sidebar/Connections%20tab.md">Связи</a>, где её также можно развернуть на весь экран.
*   Вкладка «Информация о заметке» перенесена на небольшую иконку <span class="tn-icon bx bx-info-circle"></span> в строке состояния.
*   Вкладка «Похожие заметки»
    *   Вместо открытия в панели на ленте похожие заметки теперь отображаются на боковой панели во вкладке <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Right%20Sidebar/Connections%20tab.md">Связи</a>.
    *   `similarNotesWidgetDisabled` больше не действует.
*   Вкладка свойств коллекции перенесена под заголовок заметки и сгруппирована в:
    *   Выпадающий список для быстрого переключения представлений.
    *   Отдельные настройки текущего представления в подменю.
*   Некоторые небольшие вкладки ленты преобразованы в значки, отображаемые рядом с заголовком заметки в области навигационной цепочки:
    *   Индикатор исходного URL для сохранённых веб-страниц (`#pageUrl`).
    *   Кнопки запуска SQL и скриптов <span class="tn-icon bx bx-play"></span>.

> [!NOTE]
> Сочетания клавиш ленты (например, `toggleRibbonTabClassicEditor`) были переназначены и переименованы (_Focus Formatting Toolbar_, _Toggle Owned Attributes_, _Show Note Map_ и т. д.) для работы в новом макете, где они переключают соответствующую панель.

### Удаление плавающих кнопок

Большинство кнопок было перенесено справа от заголовка заметки, в область <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20menu.md">Меню заметки</a>, за исключением следующих:

*   Кнопка редактирования заменена значком <span class="tn-icon bx bx-lock-alt"></span> _Только для чтения_ рядом с заголовком заметки, нажатие на который временно делает заметку доступной для редактирования.
*   _Обратные ссылки_ теперь отображаются на боковой панели во вкладке <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Right%20Sidebar/Connections%20tab.md">Связи</a>.
    *   Кроме того, счётчик обратных ссылок отображается в строке состояния, и нажатие на него открывает боковую панель на нужном разделе.
*   Кнопки масштабирования карты связей теперь являются частью самой карты связей.
*   Экспорт изображения в PNG/SVG теперь находится в меню действий с заметкой в пункте _Экспортировать как изображение_.

### Изменения боковой панели

Боковая панель (также известная как правая панель) также получила ряд важных изменений.

Прежде всего, в v0.105.0 боковая панель разделена на несколько вкладок с дополнительной функциональностью:

*   <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Right%20Sidebar/Outline%20tab.md">Вкладка «Структура»</a>, объединяющая оглавление и список выделений.
*   <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Right%20Sidebar/Attributes%20tab.md">Вкладка «Атрибуты»</a>, предоставляющая графический способ редактирования меток, связей и определений (продвигаемых) атрибутов.
*   Отдельная <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Right%20Sidebar/AI%20chat%20tab.md">вкладка ИИ-чата</a>.
*   <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Right%20Sidebar/Connections%20tab.md">Вкладка «Связи»</a>, объединяющая карту заметок, пути заметок, обратные ссылки и похожие заметки.

В предыдущей версии боковая панель появлялась контекстно, в зависимости от того, есть ли элементы для отображения. Это вызывало периодические смещения содержимого при переключении между панелями в разделённом режиме. В новом макете боковая панель ведёт себя скорее как панель <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20Tree.md">Дерева заметок</a>, оставаясь видимой, даже если отображать нечего.

В связи с этим:

*   Карточка _Оглавление_ в настройках текстовых заметок (минимальное количество заголовков) удалена. Панель показывает оглавление при любом количестве заголовков.
*   `#toc` / `#toc=show` / `#toc=hide` больше не действуют.
*   `#hideHighlightWidget` больше не действует. Категории выделений по-прежнему задаются глобально через меню <span class="tn-icon bx bx-cog"></span> списка выделений или в настройках текстовых заметок, но их нельзя скрыть для отдельной заметки.

Для переключения боковой панели добавлена новая кнопка <span class="tn-icon bx bx-sidebar bx-flip-horizontal"></span> в правом верхнем углу экрана, рядом с кнопками окна (в Windows и Linux).

Теперь каждый раздел боковой панели (например, «Оглавление», «Список выделений») сворачивается отдельно и запоминает своё состояние.

Некоторые элементы боковой панели также имеют собственное меню в заголовке. Например, фильтр выделений можно настроить прямо из меню <span class="tn-icon bx bx-cog"></span> списка выделений.

Пользовательские виджеты по-прежнему поддерживаются. Для пользовательских скриптов меню <span class="tn-icon bx bx-dots-vertical-rounded"></span> позволяет быстро перейти к соответствующей заметке со скриптом.
