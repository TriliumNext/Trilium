# Серверные импорты
Более старые версии Trilium Notes позволяли использовать импорт модулей CommonJS внутри бэкенд-скриптов, например:

```
const isBetween = require('dayjs/plugin/isBetween')
api.dayjs.extend(isBetween)
```

В более новых версиях импорты Node.js **больше официально не поддерживаются**, поскольку мы добавили сборщик (bundler), который затрудняет повторное использование зависимостей.

Теоретически использовать импорты всё ещё возможно, вручную настроив каталог `node_modules` в директории сервера с помощью `npm` или `pnpm`.
