# Анонимизированная база данных
![](Anonymized%20Database_image.jpg)

В некоторых ситуациях понимание структуры базы данных критически важно для устранения неполадок. Однако делиться реальным файлом [базы данных](../Advanced%20Usage/Database.md) с личными заметками небезопасно. Для решения этой проблемы в Trilium предусмотрена функция анонимизации базы данных. Она доступна через Меню → Настройки → вкладка «Дополнительно» (Menu → Options → Advanced).

Эта функция создаёт копию вашей базы данных, удаляя все конфиденциальные данные. В частности, она удаляет заголовки заметок, содержимое, ревизии, историю и часть несистемных атрибутов, сохраняя при этом общую структуру и метаданные, например даты изменения. После анонимизации база данных проходит [процедуру VACUUM](https://sqlite.org/lang_vacuum.html), чтобы гарантировать отсутствие остатков конфиденциальных данных в файле. Анонимизированная база данных сохраняется в каталоге `anonymized` внутри [каталога данных](../Installation%20%26%20Setup/Data%20directory.md), после чего её можно безопасно прикрепить к отчёту об ошибке.

Создаётся копия документа с удалением всех конфиденциальных данных (на данный момент: заголовков заметок, содержимого, ревизий, истории, некоторых настроек и несистемных атрибутов) при сохранении всей структуры и метаданных (например, даты последнего изменения). После этого для базы данных выполняется [VACUUM](https://sqlite.org/lang_vacuum.html), чтобы в файле документа не осталось устаревших конфиденциальных данных. Итоговый файл сохраняется в каталоге `anonymized` (расположенном в [каталоге данных](../Installation%20%26%20Setup/Data%20directory.md)). Вы можете безопасно приложить его к отчёту об ошибке.

## Анонимизация через командную строку

Если ваша [база данных](../Advanced%20Usage/Database.md) повреждена настолько, что Trilium не может запуститься, процесс анонимизации всё равно можно выполнить через командную строку:

```
node src/anonymize.js
```

Выполните эту команду из каталога, содержащего исходные файлы Trilium (обычно это каталог `resources/app` для настольных сборок).
