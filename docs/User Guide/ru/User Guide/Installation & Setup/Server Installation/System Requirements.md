# Системные требования
*   С помощью Docker сервер можно запускать на устройствах под управлением Windows, Linux и macOS.
*   Нативные бинарные файлы предоставляются для Linux x64 и ARM (`aarch64`).

## Поддержка устаревших платформ ARM

Сборки Docker также поддерживают платформы `linux/arm/v7` и `linux/arm/v8`. Эти платформы считаются устаревшими, поскольку Trilium использует Node.js версии 24, в которой [поддержка этих платформ официально понижена](https://github.com/nodejs/node/commit/6682861d6f) до статуса «экспериментальной».

В результате Trilium вынужден использовать Node.js 22 для этих версий. Как только Node.js 22 перестанет быть совместимой, поддержка `armv7` и `armv8` будет полностью прекращена.

Независимо от поддержки со стороны апстрима, эти платформы поддерживаются по принципу «насколько возможно» (best-effort) и не имеют официальной поддержки от команды разработчиков Trilium. Сообщения об ошибках принимаются, но не рассматриваются в приоритетном порядке; вклад сообщества приветствуется.
