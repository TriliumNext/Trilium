# Сторонний облачный хостинг
В качестве альтернативы [развёртыванию собственного экземпляра Trilium](1.%20Installing%20the%20server) существуют сервисы, предоставляющие готовую поддержку Trilium «из коробки».

> [!IMPORTANT]
> **Отказ от ответственности**: проект Trilium Notes и его сопровождающие не связаны напрямую ни с одним из этих сервисов.
> 
> PikaPods любезно предоставили нам бесплатные кредиты для целей тестирования.

## Провайдеры облачных экземпляров

### PikaPods

1.  Перейдите на [pikapods.com](https://www.pikapods.com) и зарегистрируйтесь.
2.  В разделе «Available Apps» найдите «TriliumNext»  
    и выберите «Run your own».
3.  Следуйте инструкциям на экране, чтобы настроить собственный облачный экземпляр.

PikaPods обычно обновляют свои экземпляры Trilium до последней версии в течение двух недель после выхода нового релиза.

## Соответствие версий с облачным экземпляром

Обратите внимание: после настройки <a class="reference-link" href="../Synchronization.md">синхронизации</a> между облачным экземпляром и [настольными](../Desktop%20Installation.md) клиентами важно, чтобы версии настольного приложения и сервера совпадали.

При настройке облачного экземпляра лучше всего проверить версию сервера, открыв его в веб-браузере и перейдя в раздел _О программе_ (_About_). В идеале и настольное приложение, и сервер должны иметь одинаковую _версию приложения_ (_App version_); однако обычно допустимо обновить настольное приложение до более новой версии, чем на сервере, если у них совпадает _версия синхронизации_ (_Sync version_).

Если _версия синхронизации_ на сервере и в настольном приложении не совпадает, синхронизация работать не будет.
