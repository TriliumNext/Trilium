# Многофакторная аутентификация с помощью TOTP
Многофакторная аутентификация (MFA) — это процесс обеспечения безопасности, при котором для получения доступа к системе, приложению или учётной записи пользователю необходимо предоставить два или более факторов подтверждения. Это добавляет дополнительный уровень защиты поверх обычного пароля.

Требуя более одного способа проверки, MFA помогает снизить риск несанкционированного доступа, даже если кто-то узнал ваш пароль. Настоятельно рекомендуется использовать её для защиты конфиденциальной информации, хранящейся в ваших заметках.

## Связь с OpenID Connect (OIDC)

Многофакторная аутентификация делает вход в Trilium безопаснее, требуя дополнительное подтверждение личности помимо пароля. <a class="reference-link" href="Signing%20in%20with%20OpenID%20Connect.md">Вход с помощью OpenID Connect</a> — это другая концепция, которая делегирует аутентификацию внешнему провайдеру (например, Google или самостоятельно размещённому провайдеру вроде Authelia). Такие провайдеры аутентификации могут предоставлять собственные функции безопасности, например TOTP или ключи доступа (passkeys).

## Одноразовый пароль на основе времени (TOTP)

TOTP (Time-Based One-Time Password) — это функция безопасности, которая генерирует уникальный временный код на вашем устройстве (например, смартфоне), меняющийся каждые 30 секунд. Вы используете этот код вместе с паролем для входа в учётную запись, что значительно усложняет доступ для посторонних.

1.  Перейдите в <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Options.md">Настройки</a> → _Пароль и аутентификация_ (_Password & Auth_).
2.  Убедитесь, что в поле _Способ входа_ (_Sign-in with_) выбран _Локальный пароль_ (_Local password_).
3.  В разделе _Двухфакторная аутентификация_ (_Two-factor authentication_) нажмите _Настроить_ (_Set up_).
4.  Отсканируйте QR-код или введите код вручную в приложении-аутентификаторе.
5.  Введите проверочный код из приложения-аутентификатора, чтобы подтвердить успешность настройки, и нажмите _Проверить и продолжить_ (_Verify & continue_).
6.  Сохраните коды восстановления, затем отметьте подтверждение и нажмите _Завершить настройку_ (_Finish setup_).
7.  После завершения настройки TOTP потребуется повторный вход (после обновления страницы).

## Вход в систему

После включения TOTP страница входа запрашивает код из приложения-аутентификатора в поле _Одноразовый пароль или код восстановления_ (_One-time password or recovery code_) под полем пароля.

Trilium принимает код для текущего 30-секундного интервала, а также для предыдущего и следующего интервалов, поэтому небольшое расхождение часов в любую сторону не мешает входу. Начиная с версии v0.106.0 каждый код принимается только один раз: после успешного входа этот код и любые более старые коды отклоняются, даже пока они ещё действительны.

Неверный одноразовый пароль учитывается в том же лимите неудачных попыток, что и неверный пароль. См. раздел _Защита от подбора пароля (brute-force)_ в статье <a class="reference-link" href="Authentication.md">Аутентификация</a>.

## Подключение устройства к серверу

После включения TOTP подключение нового настольного или мобильного приложения к серверу через <a class="reference-link" href="../Synchronization.md">синхронизацию</a> также запрашивает второй фактор. На экране _Подключение к существующему серверу_ (_Connect to an existing server_) введите одноразовый пароль или код восстановления в поле _Одноразовый пароль или код восстановления_ (_One-time password or recovery code_) под паролем сервера. Без него сервер откажет в настройке синхронизации.

Второй фактор запрашивается только при первом подключении устройства. Уже настроенное устройство продолжает синхронизироваться без него.

> [!NOTE]
> Версии ниже v0.107.0 не запрашивают второй фактор при настройке синхронизации. Обновите настольные и мобильные приложения вместе с сервером, поскольку в старых версиях нет поля для его отправки.

## Получение токена ETAPI с помощью пароля

После включения TOTP получение токена для <a class="reference-link" href="../../Advanced%20Usage/ETAPI%20(REST%20API).md">ETAPI (REST API)</a> через вызов `/auth/login` также требует второго фактора: передайте одноразовый пароль или код восстановления в поле `totpToken` рядом с `password`. Каждый код принимается только один раз.

Для скриптов и инструментов, работающих в автоматическом режиме, создайте токен в разделе <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Options.md">Настройки</a> → _ETAPI_. Такой токен работает независимо от TOTP.

> [!WARNING]
> Версии ниже v0.107.0 выдают токен ETAPI по одному лишь паролю, даже если включён TOTP.

## Коды восстановления

Коды восстановления можно использовать вместо TOTP, если вы потеряете доступ к приложению-аутентификатору. Trilium предоставляет 8 различных кодов восстановления, каждый из которых можно использовать один раз.

Чтобы воспользоваться кодом восстановления, просто войдите со своим паролем и введите код восстановления в качестве кода безопасности.

Начальный набор кодов восстановления генерируется при первой настройке TOTP. Их можно перегенерировать в любой момент, перейдя в <a class="reference-link" href="../../Basic%20Concepts%20and%20Features/UI%20Elements/Options.md">Настройки</a> → _Пароль и аутентификация_ (_Password & Auth_) и нажав кнопку _Перегенерировать коды восстановления_ (_Regenerate recovery codes_). Это создаст новый набор кодов восстановления и одновременно аннулирует предыдущие.
