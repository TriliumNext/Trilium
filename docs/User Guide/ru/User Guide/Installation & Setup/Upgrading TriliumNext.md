# Обновление TriliumNext
В этом документе описаны шаги, необходимые для обновления Trilium до новой версии.

## Как обновить

Trilium не поддерживает встроенное автоматическое обновление; все обновления должны выполняться вручную. Процесс обновления зависит от способа установки:

*   [**Установка сервера через Docker**](Server%20Installation/1.%20Installing%20the%20server/Using%20Docker.md): загрузите новый образ и перезапустите контейнер.
*   **Другие способы установки**: скачайте последнюю версию со [страницы релизов](https://github.com/TriliumNext/Trilium/releases/latest) и замените существующие файлы приложения.

## Совместимость и миграция базы данных

При запуске Trilium автоматически выполнит миграцию [базы данных](../Advanced%20Usage/Database.md) на новую версию. Обратите внимание, что после миграции более старые версии Trilium не смогут прочитать эту базу данных. Если вам понадобится вернуться к предыдущей версии Trilium и её базе данных, вы можете восстановить [резервную копию](Backup.md), созданную перед миграцией.

## Совместимость синхронизации

Протокол [синхронизации](Synchronization.md), используемый в Trilium, имеет версионирование, поэтому все участники кластера синхронизации должны использовать одну и ту же версию протокола. Следовательно, при обновлении до новой версии вам может потребоваться обновить все экземпляры в кластере синхронизации. Изменения версии протокола синхронизации обычно указываются на странице релизов.
