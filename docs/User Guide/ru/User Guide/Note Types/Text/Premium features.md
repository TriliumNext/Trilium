# Премиум-функции
Используемый нами текстовый редактор называется <a class="reference-link" href="../../Advanced%20Usage/Technologies%20used/CKEditor.md">CKEditor</a>. Он имеет ядро с открытым исходным кодом, но также является коммерческим продуктом, предлагающим [премиум-функции](https://ckeditor.com/docs/trial/latest/index.html).

До версии v0.105.0 Trilium использовал следующие премиум-функции в рамках подписанного соглашения между командами CKEditor и Trilium:

*   <a class="reference-link" href="Slash%20Commands.md">Слэш-команды</a>
*   <a class="reference-link" href="Text%20Snippets.md">Текстовые фрагменты</a>
*   <a class="reference-link" href="Format%20Painter.md">Формат по образцу</a>

Начиная с версии v0.105.0, эти функции были полностью переписаны в виде пользовательских плагинов CKEditor под лицензией AGPL-3.0.

## Похожие функции

Существуют некоторые премиум-функции CKEditor, которые похожи на встроенную функциональность Trilium, но на самом деле полностью отличаются:

*   <a class="reference-link" href="In-editor%20AI%20assistant.md">ИИ-ассистент в редакторе</a>
*   <a class="reference-link" href="Math%20Equations.md">Математические формулы</a>, где используется сторонний плагин, адаптированный для Trilium.
