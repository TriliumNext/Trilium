# Markdown-подобное форматирование
Markdown-подобное форматирование позволяет применять базовое оформление, вводя соответствующие конструкции Markdown. Обратите внимание, что это не означает полноценной поддержки Markdown в <a class="reference-link" href="../Text.md">Текстовых</a> заметках — это лишь удобные сокращения.

Для импорта более сложного форматирования в текстовые заметки используйте функцию [_Импорт из Markdown_](Other%20features.md). Для полноценного импорта Markdown-заметок воспользуйтесь специальной функцией [импорта](../../Basic%20Concepts%20and%20Features/Import%20%26%20Export/Markdown.md).

*   Для [заголовков:](General%20formatting.md)
    *   `##` — Заголовок 2 (заголовок первого уровня зарезервирован для названия заметки).
    *   `###` — Заголовок 3
    *   `####` — Заголовок 4
    *   `#####` — Заголовок 5
    *   `######` — Заголовок 6
*   Для <a class="reference-link" href="General%20formatting.md">Общего форматирования</a>:
    *   **Жирный**: введите `**text**` или `__text__`
    *   _Курсив_: введите `*text*` или `_text_`
    *   ~~Зачёркнутый~~: введите `~~text~~`
*   Для <a class="reference-link" href="Lists.md">Списков</a>:
    *   Маркированный список: начните строку с `*` или `-` и пробела;
    *   Нумерованный список: начните строку с `1.` или `1)` и пробела;
    *   Список задач: начните строку с `[ ]` для невыполненного пункта или `[x]` для выполненного.
*   Для [цитат](Block%20quotes%20%26%20admonitions.md) введите `>` и пробел.
*   Для <a class="reference-link" href="Developer-specific%20formatting/Code%20blocks.md">Блоков кода</a> введите ` ``` `.
*   Для [горизонтальной линии](Other%20features.md) введите `---`.
*   Для [примечаний (admonitions)](Block%20quotes%20%26%20admonitions.md):
    *   `!!! note`
    *   `!!! tip`
    *   `!!! important`
    *   `!!! caution`
    *   `!!! warning`
    *   Любой другой текст, начинающийся с `!!!`, создаст блок примечания `note` с этим текстом внутри.
*   Для [эмодзи](Insert%20buttons.md) введите `:` и название эмодзи, чтобы открыть автодополнение.

Если автоформатирование нежелательно, нажмите <kbd>Ctrl</kbd> + <kbd>Z</kbd>, чтобы вернуть текст в исходный вид.
