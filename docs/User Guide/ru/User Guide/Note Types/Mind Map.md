# Mind Map
<figure class="image image-style-align-center"><img style="aspect-ratio:892/675;" src="Mind Map_image.png" width="892" height="675"></figure>

Mind Map позволяет легко набрасывать идеи и хранить их иерархически.

## Терминология

*   **Узел** — отдельная идея, представленная по-разному в зависимости от глубины (заполненный скруглённый прямоугольник для корневой заметки, незаполненные прямоугольники для подидей, только линии для под-подидей).
*   **Корневой узел** — самый верхний узел, от которого происходят все остальные узлы, отображаемый как заполненный прямоугольник. Может быть только один корневой узел.

## Взаимодействие

*   Чтобы создать новый узел на том же уровне, что и текущий, нажмите <kbd>Enter</kbd>, введите нужный текст, а затем снова нажмите <kbd>Enter</kbd> для подтверждения.
*   Аналогично, чтобы создать подузел, нажмите <kbd>Tab</kbd>, введите нужный текст, а затем нажмите <kbd>Enter</kbd>.
*   Чтобы создать родителя, вместо этого используйте <kbd>Ctrl</kbd>+<kbd>Enter</kbd>.
*   Чтобы удалить узел, нажмите <kbd>Delete</kbd>.
*   Чтобы переместить узел вверх или вниз, нажмите <kbd>Page Up</kbd> или <kbd>Page Down</kbd>.
*   Чтобы настроить размер шрифта, цвет текста или фона или добавить ссылку, щёлкните по узлу и используйте плавающую панель, которая появляется справа.
*   Чтобы выбрать одну или несколько заметок, перетащите через карту.
*   Щёлкните правой кнопкой по узлу, чтобы вызвать контекстное меню с опциями, такими как создание новых узлов, фокусировка на конкретной заметке или создание ссылок между ними.
*   Используйте кнопки в левом верхнем углу, чтобы изменить размещение узлов относительно корневого узла (слева, справа или с обеих сторон).
*   В области <a class="reference-link" href="../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20buttons.md">Кнопок заметки</a> можно скопировать [ссылку на изображение](Text/Images/Image%20references.md), нажав кнопку <span class="tn-icon bx bx-copy"></span>, чтобы вставить mind map в текстовую заметку.
*   Из <a class="reference-link" href="../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20menu.md">Меню заметки</a> диаграмму можно экспортировать как SVG (векторный) или PNG (растр), выбрав _Экспортировать как изображение_.
*   Заметку можно установить как [только для чтения](../Basic%20Concepts%20and%20Features/Notes/Read-Only%20Notes.md), что отключит все возможности редактирования.
