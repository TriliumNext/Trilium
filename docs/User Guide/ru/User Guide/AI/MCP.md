# MCP
[Model Context Protocol](https://en.wikipedia.org/wiki/Model_Context_Protocol) позволяет внешним чат-приложениям, таким как Claude Code, иметь доступ к базе данных Trilium.

## Встроенный MCP

v0.103.0 поставляется со встроенным MCP-сервером, который по умолчанию не активен. Чтобы активировать его, откройте <a class="reference-link" href="../Basic%20Concepts%20and%20Features/UI%20Elements/Options.md">Настройки</a> → AI/LLM и включите опцию _MCP-сервер_.

После активации MCP просто добавьте MCP-сервер в вашего ИИ-помощника. Используемый URL отображается в информации _Endpoint URL_ под переключателем MCP.

Поддерживается только HTTP-транспорт, метод `stdio` не поддерживается. Если это критично, рассмотрите сторонние альтернативы, перечисленные ниже.

Инструменты, доступные через MCP, совпадают с инструментами внутреннего чата (см. раздел _Доступ к заметкам_). Заметки с меткой `#excludeFromLlm` скрыты от обоих, см. <a class="reference-link" href="Privacy.md">Конфиденциальность</a>.

### Подтверждение вызовов инструментов

Trilium не запрашивает подтверждения вызовов, которые делает внешний помощник; это остаётся настройкам разрешений самого помощника. Чтобы помочь ему решать, каждый инструмент сообщает помощнику, только ли он читает ваши заметки, только ли добавляет в них (создание заметки, клонирование или добавление в конец) или может что-то перезаписать или удалить (правка, переименование, перемещение или удаление). Помощник, поддерживающий эти подсказки, может выполнять чтение самостоятельно и спрашивать перед изменениями, как это делает _Спрашивать перед изменениями_ в чате Trilium.

### Аутентификация

Чтобы защитить ваши заметки от несанкционированного доступа, MCP-сервер требует аутентификации. Обычно MCP-серверы поддерживают OAuth для аутентификации, но Trilium использует более простой механизм с Bearer-токенами.

Чтобы настроить аутентификацию, сначала создайте <a class="reference-link" href="../Advanced%20Usage/ETAPI%20(REST%20API).md">токен ETAPI (REST API)</a> в <a class="reference-link" href="../Basic%20Concepts%20and%20Features/UI%20Elements/Options.md">Настройках</a> → _ETAPI_. Затем следуйте инструкциям в <a class="reference-link" href="../Basic%20Concepts%20and%20Features/UI%20Elements/Options.md">Настройках</a> → _AI / LLM_, в разделе _Как подключить помощника_ под MCP.
