# Провайдеры
Провайдеры добавляются в разделе _Провайдеры моделей_ настроек ИИ кнопкой _Добавить провайдера моделей_. Каждый перечисляет выбранные для него модели — именно их предлагает чат; провайдер без выбранных моделей не предлагается в чате.

## Облачные провайдеры по API-ключам

В настоящее время поддерживаются следующие облачные провайдеры:

*   <span class="tn-icon tn-brand tn-brand-anthropic"></span> [Anthropic](https://platform.claude.com/settings/workspaces/default/keys)
*   <span class="tn-icon tn-brand tn-brand-openai"></span> OpenAI
*   <span class="tn-icon tn-brand tn-brand-gemini"></span> Gemini
*   <span class="tn-icon tn-brand tn-brand-deepseek"></span> DeepSeek
*   <span class="tn-icon tn-brand tn-brand-openrouter"></span> [OpenRouter](https://openrouter.ai/settings/keys)

Для всех провайдеров нужен API-ключ. Обратите внимание: он оплачивается отдельно от уже имеющейся у вас подписки (например, Claude Pro). Если это может быть проблемой, рассмотрите провайдера по подписке (см. ниже) или внешнее использование через MCP.

Учтите также, что большинство других провайдеров LLM (например, Groq, Mistral, Together) всё же можно использовать в Trilium через пользовательский endpoint, совместимый с OpenAI (см. ниже).

Если вы используете прокси или шлюз, можно также настроить base URL, иначе используется значение по умолчанию.

Для OpenRouter модели тарифицируются на кредиты вашего OpenRouter, а их цены, контекстные окна и поддерживаемые вложения берутся из собственного списка моделей OpenRouter:

*   По умолчанию выбраны модели _Latest_, умеющие использовать инструменты, например _Anthropic: Claude Sonnet Latest_. OpenRouter направляет каждую из них на новейшую модель своей линейки, поэтому выбор остаётся актуальным без редактирования провайдера.
*   У рассуждающих моделей в чате есть раскрывающийся список усилия рассуждения (_Низкое_, _Среднее_ или _Высокое_).
*   _Auto Router_ (`openrouter/auto`) выбирает модель для каждого сообщения. Под каждым ответом чат называет модель, написавшую его; то же происходит при использовании модели _Latest_.
*   Стоимость, показанная под ответом, — это сумма, выставленная OpenRouter за него, а не оценка по указанным ценам.
*   Модели генерации изображений и отложенные варианты _batch_ не перечисляются.
*   Заголовки чатов генерируются моделью _Anthropic: Claude Haiku Latest_.
*   Запросы атрибутируются Trilium на странице активности вашего OpenRouter.

Для Gemini чат без указанной модели использует `gemini-3.8-flash`, а автоматически генерируемые заголовки чатов — `gemini-3.5-flash-lite`. Явно выбранная вами модель используется как есть и на эти умолчания не влияет.

> [!NOTE]
> Мы не планируем поддерживать всех облачных провайдеров, даже если используемая библиотека теоретически это позволяет. Прежде чем открывать PR с поддержкой другого облачного провайдера, обсудите это в [GitHub Discussions](https://github.com/orgs/TriliumNext/discussions).

> [!IMPORTANT]
> См. также раздел <a class="reference-link" href="Privacy.md">Конфиденциальность</a>, чтобы лучше понять, какие данные отправляются облачному провайдеру.

## Провайдеры по подписке

Trilium интегрирует несколько <a class="reference-link" href="Providers/Subscription-based%20providers.md">провайдеров по подписке</a>:

*   <span class="tn-icon tn-brand tn-brand-claude"></span> Claude Code — через повторное использование вашего CLI.
*   <span class="tn-icon tn-brand tn-brand-github-copilot"></span> GitHub Copilot — через повторное использование ACP вашего CLI.
*   <span class="tn-icon tn-brand tn-brand-antigravity"></span> Google Antigravity — загрузкой и настройкой ACP для Trilium.
*   <span class="tn-icon tn-brand tn-brand-codex"></span> OpenAI Codex — через повторное использование вашего CLI через поставляемый с Trilium адаптер ACP.

## Локальные провайдеры / собственный хостинг

Локальные или самостоятельно размещаемые провайдеры — бесплатная альтернатива, уважающая вашу конфиденциальность, но требующая определённого оборудования.

Trilium напрямую поддерживает следующих локальных провайдеров:

=== "<span class="tn-icon tn-brand tn-brand-ollama"></span> Ollama"

    Обычно Ollama работает в фоне, поэтому в Trilium он должен быть сразу usable, пока модели загружены (например, `ollama pull llama3.2`).

=== "<span class="tn-icon tn-brand tn-brand-lmstudio"></span> LM Studio"

    Сервер, совместимый с OpenAI, в установках LM Studio по умолчанию **отключён**. Сначала загрузите нужные модели через графический интерфейс, затем откройте _Settings_ → _Developer_ и включите _Developer mode_. Слева появится новая вкладка _Developer_ с переключателем его запуска.

Даже локальных провайдеров, не поддерживаемых напрямую, можно использовать через пользовательский endpoint (см. ниже).

> [!WARNING]
> При работе с собственноручно размещаемыми LLM-моделями качество ответов может варьироваться в зависимости от обучения и размера модели. Прежде чем [сообщать о проблемах](../Troubleshooting/Reporting%20issues.md) с качеством ответов (например, выдуманные вызовы инструментов), сравните ответ с облачным провайдером (рекомендуется Claude Sonnet).

## Пользовательские endpoints

Если нужный вам облачный (например, Groq, Mistral, Together) или локальный провайдер LLM не перечислен в Trilium, используйте специального провайдера _OpenAI-compatible_ из раздела _Пользовательский endpoint_.

Это позволяет установить base URL на API, совместимый с OpenAI, с необязательным API-ключом, если сервис его требует.

Вводите base URL в точности как его документирует сервис, включая путь версии, например `https://api.groq.com/openai/v1` или `https://open.bigmodel.cn/api/paas/v4`. Только голый хост вроде `http://localhost:8080` дополняется `/v1`.

Endpoint может работать на той же машине, что и Trilium, в другом месте вашей локальной сети или в tailnet Tailscale. Trilium отклоняет link-local адреса (`169.254.0.0/16`) и облачные metadata-endpoints, на которых не обслуживается ни один сервер моделей.

Для пользовательских endpoints цены моделей неизвестны, поэтому стоимость диалога не отображается; это особенно важно для облачных провайдеров.
