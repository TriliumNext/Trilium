# Быстрый старт
## Выбор варианта установки

**Только локально на ПК/ноутбуке** — позволяет запустить один экземпляр на компьютере и хранить заметки локально на этом устройстве.

*   <a class="reference-link" href="Installation%20%26%20Setup/Desktop%20Installation.md">Установка настольной версии</a>

**Сервер с доступом только через веб** — приложение устанавливается на сервер и позволяет работать с ним из любого веб-браузера на любом устройстве, включая мобильные.

1.  <a class="reference-link" href="Installation%20%26%20Setup/Server%20Installation.md">Установка серверной версии</a>
2.  <a class="reference-link" href="Installation%20%26%20Setup/Mobile%20Frontend.md">Мобильный интерфейс</a> (необязательно)
3.  <a class="reference-link" href="Installation%20%26%20Setup/Server%20Installation/Third-party%20cloud%20hosting.md">Сторонний облачный хостинг</a>

**Комбинация сервера и ПК/ноутбука** — установите приложение как на сервер (для веб-доступа и синхронизации данных), так и в виде настольных экземпляров. Это позволяет хранить все данные на сервере и получать к ним доступ либо через веб-браузер, либо через настольное приложение. Настольное приложение будет синхронизировать и хранить данные локально, чтобы вы могли работать с ними в автономном режиме.

1.  <a class="reference-link" href="Installation%20%26%20Setup/Server%20Installation.md">Установка серверной версии</a>
2.  <a class="reference-link" href="Installation%20%26%20Setup/Mobile%20Frontend.md">Мобильный интерфейс</a> (необязательно)
3.  <a class="reference-link" href="Installation%20%26%20Setup/Desktop%20Installation.md">Установка настольной версии</a>
4.  <a class="reference-link" href="Installation%20%26%20Setup/Synchronization.md">Синхронизация</a>
