# Свойства коллекции
<figure class="image"><img style="aspect-ratio:1177/98;" src="Collection Properties_image.png" width="1177" height="98"></figure>

_Свойства коллекции_ — это панель инструментов, отображаемая вверху каждой [заметки-коллекции](../Collections.md).

У свойств коллекции есть:

*   Быстрый выбор типа вида (например, сетка, календарь, доска).
*   Кнопка настроек с:
    *   Настройками текущего вида, например скрытием выходных в календаре.
    *   Общими настройками коллекции, такими как [скрытие дочерних заметок](../Basic%20Concepts%20and%20Features/UI%20Elements/Note%20Tree/Hiding%20the%20subtree.md) или показ [архивных заметок](../Basic%20Concepts%20and%20Features/Notes/Archived%20Notes.md).
*   Специфичные взаимодействия для текущего вида, например кнопки разворачивания и сворачивания в виде списка или выбор месяца и переключатель вида для календаря.
