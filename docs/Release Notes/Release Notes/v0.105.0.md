## 💡 Key highlights

1.  Added native flashcards with FSRS scheduling:
    1.  Turn any note into a flashcard while keeping normal note editing.
    2.  Review cards with Again, Hard, Good, and Easy ratings plus server-authoritative preview intervals.
    3.  Use cloze deletions through `{{cN::text}}` syntax and the rich-text editor toolbar button.
    4.  Organize cards into note-backed decks, filtered decks, and leech review queues.
    5.  Track due counts, retention, rating totals, lapses, and a seven-day due forecast.
2.  Added flashcard portability:
    1.  Import Anki `.apkg` packages, including rendered card templates, referenced media, current scheduling state, and bounded review history.
    2.  Export Trilium flashcards as Anki-compatible `.apkg` packages with decks, cards, media, scheduling state, and review logs.
    3.  Export and import Trilium JSON scheduling data without duplicating note content.

## ✨ Improvements

1.  Added flashcard actions to note menus, global menu, launcher, keyboard commands, and mobile-friendly review flows.
2.  Added manual due-date rescheduling and drag scheduling from the forecast chart.
3.  Added optimistic conflict handling so concurrent reviews from multiple devices cannot silently overwrite newer scheduling state.
4.  Added protected-note handling so locked flashcard sources do not leak front or back content in review APIs.

## 📖 Documentation

1.  Added developer documentation for the flashcard data model, scheduling flow, review UI, portability, privacy, and test scope.
2.  Added third-party notices for flashcard scheduling and Anki package support dependencies.

## 🛠️ Technical updates

1.  Added synchronized `flashcards` and `flashcard_reviews` entities with additive migrations.
2.  Added cross-runtime isolated SQLite readers and writers for Anki import/export in server and standalone runtimes.
3.  Added tests for flashcard APIs, FSRS scheduling, sync behavior, client review flow, Anki import/export, and migrations.

## ⚠️ Upgrade notes

1.  Flashcard migrations are one-way. Keep a pre-upgrade backup if you might need to downgrade to a release without flashcard tables.
2.  Future reviews after Anki import use Trilium's FSRS scheduler, not Anki's scheduler.
