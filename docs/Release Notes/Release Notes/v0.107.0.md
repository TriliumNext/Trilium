## 💡 Key highlights

*   The Docker image has been reworked so that it can run as a non-root user. Look for the corresponding section in the [Docker setup documentation](https://docs.triliumnotes.org/user-guide/setup/server/installation/docker). ([#5790](https://github.com/TriliumNext/Trilium/issues/5790))
*   LLM
    *   ChatGPT Codex subscriptions can now be used for Trilium's AI integration. There's also a free plan.
    *   [🔍️ **Use custom search engines**  ](https://github.com/TriliumNext/Trilium/pull/11878)
        Especially useful for local LLM usage or even cloud providers that don't have a builtin search (DeepSeek): cloud ones (Brave Search, Tavily, Exa, Serper, Perplexity) and SearXNG as a self-hosted solution.
    *   [**🛡️ Permissions for AI tool calls**  ](https://github.com/TriliumNext/Trilium/pull/12116)
        Before the AI reads or changes your notes, the chat shows what it is about to do, and you can allow or deny it. If you trust a tool, you can allow it for the rest of the chat. The Tools menu also has three modes: always ask, ask only before changes, or never ask. This works with both API keys and subscription providers such as Claude Code, Codex, GitHub Copilot and Antigravity.
*   The contextual menu has been rewritten from scratch, bring in some benefits such as [keyboard navigation](https://github.com/TriliumNext/Trilium/issues/1166), better accessibility and fixing issues such as [clipping](https://github.com/TriliumNext/Trilium/issues/5294). The note tree menu has also been compacted a bit to reduce mental overload. ([#5493](https://github.com/TriliumNext/Trilium/issues/5493), [#11896](https://github.com/TriliumNext/Trilium/pull/11896))
*   Text editor
    *   Table context menu: merge selected cells, unmerge, distribute columns, insert or delete many rows and columns ([#11774](https://github.com/TriliumNext/Trilium/pull/11774), [#11786](https://github.com/TriliumNext/Trilium/pull/11786)) by @adoriandoran
    *   Attach files from the editor in one step, embedded inline (PDF, spreadsheets) or inserted as links ([#11795](https://github.com/TriliumNext/Trilium/pull/11795), [#12063](https://github.com/TriliumNext/Trilium/pull/12063)) by @adoriandoran
    *   Drawing canvases inside text notes: sketch in place with Excalidraw, saved with the note, own toolbar ([#11829](https://github.com/TriliumNext/Trilium/pull/11829), [#12063](https://github.com/TriliumNext/Trilium/pull/12063)) by @adoriandoran
    *   [Editable transclusion: edit included text and code notes inside the host note with the full editor](https://github.com/TriliumNext/Trilium/pull/11926) by @adoriandoran
    *   Block references: link to a paragraph, heading, table or range of blocks; opens scrolled to it and highlighted ([#11925](https://github.com/TriliumNext/Trilium/pull/11925), [#12069](https://github.com/TriliumNext/Trilium/pull/12069), [#12399](https://github.com/TriliumNext/Trilium/pull/12399)) by @adoriandoran
    *   [Live excerpts: quote blocks of another note, kept in sync and editable in place, saved back to the source](https://github.com/TriliumNext/Trilium/pull/11925) by @adoriandoran
    *   Multicolumn layouts: 2 to 4 columns, six width presets, stacked on narrow screens, kept in share, print, export ([#11958](https://github.com/TriliumNext/Trilium/pull/11958), [#11982](https://github.com/TriliumNext/Trilium/pull/11982)) by @adoriandoran
    *   One link dialog for web links, note links, anchors and link previews, shown as a popover at the cursor ([#12358](https://github.com/TriliumNext/Trilium/pull/12358), [#12467](https://github.com/TriliumNext/Trilium/pull/12467)) by @adoriandoran
*   [The note autocomplete has been rewritten from scratch](https://github.com/TriliumNext/Trilium/issues/5134) with a modernized design, the command palette, link/relation pickers, @-mentions in text notes and Markdown notes and attribute value suggestions. ([#11833](https://github.com/TriliumNext/Trilium/pull/11833))
*   [PDF: copy a reference link that brings you to a page or an annotation.](https://github.com/TriliumNext/Trilium/issues/8635)
*   The relation map has been modernized, with a nicer design for the cards (displaying icons and respecting the note colors) and relations. Clicking on a note no longer closes the map and instead opens a panel to the side and the creation process has also been improved.
*   [Redesigned the mobile layout for iOS with an iOS 26-inspired design.](https://github.com/TriliumNext/Trilium/pull/12263)
*   [Both the iOS and Android mobile versions now have a new navigation system that works without a sidebar.](https://github.com/TriliumNext/Trilium/pull/12279)
*   [The presentation collection got a refresh](https://github.com/TriliumNext/Trilium/pull/12356)
    *   Slides keep a 16:9 shape and fit their content as the pane changes.
    *   Web view notes can show their pages as presentation slides.
    *   Board and table collections can fill a slide with their cards or rows.
    *   Text and canvas slides can be edited directly in the presentation.
    *   A slide sidebar lets presenters navigate and change the deck.
    *   Canvas and code previews follow the page's color scheme and saved content.
    *   Shared overlay controls can show menus and shortcuts in a consistent style.

## 🚨 Breaking changes

*   The old layout has been removed. It's been almost a year since the new layout was introduced and we believe it has been polished enough to see day-to-day use. For more information, see the [corresponding GitHub Discussions post](https://github.com/orgs/TriliumNext/discussions/11891).
*   Multi-level `#sorted` values introduced in v0.106.0 must now write labels with `#`, as search's `orderBy` does: `#sorted="priority desc, dueDate"` becomes `#sorted="#priority desc, #dueDate"`. Values without `#` fall back to sorting by title. A single name (`#sorted=myOrder`) and property-only values (`dateModified desc, title`) are unaffected. See [Sorting Notes](https://docs.triliumnotes.org/user-guide/concepts/notes/sorting).
*   `POST /etapi/auth/login` now requires a code if TOTP is enabled. Check the API documentation for more information.
